# 领域 pattern 评分协议

使用本仓库已有 patterns/main 与 patterns/sub。索引见 [PATTERN_INDEX](scoring/PATTERN_INDEX.md)，具体记录见 [SCORE_SPEC](scoring/SCORE_SPEC.md) 第 4、5 节。

每篇由论文实际操作匹配相关领域卡，读取最相关卡的适用条件、成功条件、失败模式与审稿期望，选 1–3 条判据对照论文证据。四轴只是汇总，不以通用印象替代领域判据。

原 15＋31 不作运行输入；不输出原主卡/子卡字段。无适配记 unassigned，有材料疑问记 uncertain，不强制分类或因此扣分。已有卡不为本次评分修改；需要新增的机制另记线索，不阻塞批次。
