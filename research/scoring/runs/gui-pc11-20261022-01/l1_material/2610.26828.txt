title: Agent World Model in the Wild: Computer-Use Agent Environment Synthesis
source: https://arxiv.org/abs/2610.26828

§Abstract
Agent learning is shifting from learning from human data toward learning through interaction with the world. However, scaling such learning directly in real-world computer systems is challenging and can introduce substantial security risks. We therefore propose Agent World Model in the Wild (WildAWM), a scalable pipeline for synthesizing controllable environments and tasks for training general computer-use agents (CUAs). Whereas existing approaches typically specialize in a single agent interaction interface, we construct executable environments that jointly support graphical user interfaces, model context protocol services, and command-line interfaces, allowing agents to flexibly combine visual interaction, tool use, and code execution. WildAWM is entirely powered by open-source models, demonstrating that high-quality computer-use environments can be generated without proprietary frontier models. Beyond environments, we address three recurring challenges in task synthesis: ensuring solvability, maintaining sufficient difficulty, and producing reliable verifiers, by introducing execution-based quality gates that combine heterogeneous agent rollouts, cross-judge consistency checks, and counterfactual probes of judgment robustness. The resulting pipeline synthesizes 341 long-horizon environment-task pairs that can require over 100 agent steps to solve and remain challenging even for frontier models, with GPT-6-Astra solving only 60% of them. We train two Qwen models of different sizes exclusively in these synthetic worlds. Both models achieve substantial gains across 8 out-of-distribution benchmarks spanning web, claw, and computer-use agents, demonstrating that learning in WildAWM's synthesized worlds generalizes broadly to unseen computer-use tasks. The code is publicly available at https://github.com/MSR-Orchard/WildAWM.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language model (LLM) powered agents are shifting from learning from humans to learning from the world ( Silver & Sutton, 2025 ) . Early agents learned from human data, which are expensive to collect and limited by demonstrator’s ability. Recent agents instead gain much of their capability through reinforcement learning (RL) in executable environments ( Team et al., 2026 ; Zeng et al., 2026 ; Xu et al., 2026 ) , making environment supply a key bottleneck. However, training directly in the real world is costly and risky: states are hard to reset, online services change over time, and exploratory actions may have unintended consequences. Manually built environments restore control and verifiability ( Yao et al., 2024 ; Zhou et al., 2024 ; Xie et al., 2024 ) , but remain expensive and hard to scale. Synthetic environments and tasks offer a path to controllable, large-scale online RL. Computer-Use Agents (CUAs) represent a broad setting for environment synthesis, as they operate across applications, websites, and local files on a personal computer. A single task may be completed through graphical user interface (GUI) interaction, command-line interface (CLI) operations, or calls to model context protocol (MCP) servers, making interface selection and coordination an important capability. Existing synthesis pipelines often target individual interaction modes, including browser use ( Zhou, 2026 ; Wu et al., 2026 ) , tool calling ( Du et al., 2026 ; Wang et al., 2026d ) , and terminal workflows ( Li et al., 2026 ; Zhu et al., 2026 ) . Prior CUA work, however, often focuses primarily on GUI interaction ( Aggarwal et al., 2026 ; Wang et al., 2026a ) . In this paper, we adopt a broader view of computer use spanning common interfaces on a personal computer, since real computer-use tasks are defined by what can be accomplished rather than by a single interaction modality. Synthesizing environments and tasks for this broader CUA setting introduces challenges beyond prior synthesis work. Existing approaches often synthesize visually simplified applications and build each application as an isolated environment. In contrast, realistic computer use spans a connected digital workspace in which websites, applications, MCP services, and local files coexist within an executable personal computer environment. Meanwhile, synthesized tasks should be solvable under the synthesized environment state, sufficiently challenging to provide useful learning signals, and paired with reliable verifiers to distinguish successful completion from incorrect outcomes, all without relying on simplistic assumptions such as “a frontier model is necessarily correct.” To address these challenges, we propose WildAWM , a scalable synthesis pipeline for general CUAs. Starting from user personas and daily activities, WildAWM constructs executable personal-computer environments with websites, MCP services, and local files, then synthesizes cross-agent interface (XAI) tasks grounded in these worlds. We introduce execution-based multi-agent quality gates, where heterogeneous agents from different models and harnesses execute each task, providing evidence of solvability, difficulty, and judge consistency. To further test verifier robustness, we exploit LLM sycophancy ( Sharma et al., 2024 ) through counterfactual probes with deliberately incorrect outcome feedback. The resulting environments, tasks, and verifiers provide executable worlds and rewards for agentic RL. Notably, WildAWM uses open-source models throughout synthesis, whereas existing works often rely on proprietary models ( Aggarwal et al., 2026 ; Zhou, 2026 ; Wang et al., 2026a ) . This improves reproducibility, transparency, and accessibility, while showing that open-source models alone can synthesize high-quality environments and challenging tasks for general CUA training. Using WildAWM , we synthesize 341 environment–task pairs, each requiring at least three interface types, with long-horizon workflows that may require over 100 agent steps, and even frontier model GPT-6-Astra ( OpenAI, 2026c ) solves only about 60%. We further perform online RL on two Qwen models, Qwen3.6-35B-A3B ( Qwen Team, 2026 ) and Qwen3.5-4B ( Team, 2026 ) , using OpenCode CLI harness ( anomalyco, 2025 ) equipped with GUI and MCP tools, and find that training exclusively in these synthetic worlds yields substantial gains across all eight out-of-distribution (OOD) benchmarks spanning web, claw, and computer-use agents.
