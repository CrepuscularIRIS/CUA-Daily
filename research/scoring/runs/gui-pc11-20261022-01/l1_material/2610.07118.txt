title: AMBER: Training Long-Horizon Web Agents through Append-Only Memory
source: https://arxiv.org/abs/2610.07118

§Abstract
Modern language-model agents increasingly interact with external environments over long-horizon, multi-step trajectories, where the accumulated interaction history can quickly exceed practical context budgets. To ensure reliability, agents must maintain factual information over long horizons, remember execution errors and corrective feedback, and track progress across actions. Several approaches have been proposed to achieve this without the need for maintaining the entire execution history in context, such as using the reasoning and action history, learning to maintain a fixed-size memory through an overwrite mechanism, and periodic summarization. Although overwrite memory can in principle retain anything an append-only memory can, it must learn to carry each fact through every subsequent rewrite, which is difficult to learn from sparse outcome rewards; for interactive applications like web agents, we find that trained overwrite memories delete key information required by the trajectory, as well as corrective feedback received from the environment. We introduce AMBER (Append-only Memory Bank for Evidence Retention) - a simple and scalable framework where an agent jointly learns to reason, act, and write free-form memory, while an append-only rule guarantees retention by construction. This allows AMBER to be trained end-to-end with reinforcement learning from outcome rewards without the need for extensive curated SFT data. On WebArena Lite, AMBER improves average success over overwrite-based memory by 4.09 percentage points, increases the fraction of tasks solved in five repeated runs by 4.8 percentage points, and matches an overwrite baseline trained on substantially more expensive curated supervision. AMBER achieves these improvements while maintaining a practical token budget, providing a strong balance between context efficiency, task performance, and reliable long-horizon execution.

§Introduction (from cached fulltext; cut at ~9000 chars)
Language models are increasingly used as agents that interact with external environments over long-horizon, multi-step trajectories, including web-based deep research ( OpenAI, 2025 ) , tool use ( Yao et al., 2025 ) , and browser navigation ( Müller & Žunič, 2024 ) . Unlike single-turn tasks, the information required to complete these tasks is often discovered incrementally through interaction and exploration, and is not available upfront. An agent must therefore identify useful information from its observations, track its execution progress, and preserve relevant evidence until it is needed later. This raises a central question for long-horizon agents: once an agent has identified information worth remembering, how should that information be retained across subsequent interactions? The straightforward solution is to condition every decision on the complete interaction history, including previous observations, reasoning, and actions ( Yao et al., 2023 ; Jin et al., 2025 ) . However, this context grows throughout the trajectory and quickly becomes impractical when observations are large. Longer contexts can also make relevant information harder to retrieve reliably ( Liu et al., 2024a ) . Web navigation makes this problem particularly demanding: an agent must collect facts across pages, plan and execute sequences of actions, track completed and pending subgoals, remember failed attempts, recover from mistakes, and use information acquired many steps earlier. To make long-horizon interaction efficient, practical context management strategies approximate the full interaction history using some form of compressed memory . For reliable execution, context management mechanisms must decide what information to write , what previously written information to retain , and what information to surface . Moreover, a useful memory mechanism should be robust to diverse environments and interaction settings. Several methods have been proposed to address this problem, such as retaining reasoning and action histories while discarding past observations ( Wei et al., 2025 ; Gandhi & Neubig, 2025 ) , learning a compact memory that is recursively rewritten at each step ( Zhou et al., 2025 ; Yu et al., 2026 ; Yuan et al., 2025 ) , or using external memory and summarization mechanisms ( Yan et al., 2025 ; Wu et al., 2025 ) . In this paper, we focus on the first two mechanisms, and show that reasoning and action history alone is not sufficient, and an explicit memory is required for reliable long-horizon execution. However, when overwrite memory is trained from outcome rewards, the learned agents lose factual information and corrective feedback, and as a result repeat mistakes . We propose AMBER ( A ppend-only M emory B ank for E vidence R etention), which separates the learned decision of what to write from what to retain . At each interaction step, the agent reasons, acts, and generates a free-form natural-language memory entry, which is appended to a persistent memory bank (Figure 1 ). The policy therefore learns what information is worth recording, while retention is determined by a simple append-only rule. We show that AMBER can be trained jointly to optimize reasoning, action and memory generation in a scalable manner with minimal supervised data followed by end-to-end reinforcement learning from outcome rewards. To ensure scalable training, we develop and describe a rollout architecture capable of large-scale rollouts. On WebArena ( Zhou et al., 2024 ) , AMBER improves the average task success rate over overwrite memory by 4.09 percentage points and increases the fraction of tasks solved in five repeated runs by 4.8 percentage points. We show that AMBER loses less information and repeats fewer execution errors. Moreover, overwrite memory matches AMBER’s performance only when trained on substantially more expensive curated supervision. Together, these results suggest that the gap is one of learnability rather than capacity: the append-only prior makes durable memory easier to learn from weak outcome supervision. Our contributions are summarized as follows, which establish AMBER as a simple, scalable method for training long-horizon web agents that balances task performance, reliability, context efficiency and supervision complexity: • A retention-focused view of learned agent memory. We show that overwrite-style memory can result in loss of key factual information as well as corrective feedback, resulting in agents failing to solve tasks and repeating mistakes. • Append-only learned memory. We introduce AMBER, which learns what information to record while using a deterministic append-only rule. We show that AMBER improves success rate, reliability, information retention, and shows better error correction ability than overwrite memory. While appending increases the context length in theory, we find that over trajectories in WebArena, the context length stays practical. • RL training, rollout architecture, modest supervision.
