title: VerificAgent: Domain-Specific Memory Verification for Scalable Oversight of Aligned Computer-Use Agents
source: https://arxiv.org/abs/2506.02539

§Abstract
Continual memory augmentation lets computer-using agents (CUAs) learn from prior interactions, but unvetted memories can encode domain-inappropriate or unsafe heuristics--spurious rules that drift from user intent and safety constraints. We introduce VerificAgent, a scalable oversight framework that treats persistent memory as an explicit alignment surface. VerificAgent combines (1) an expert-curated seed of domain knowledge, (2) iterative, trajectory-based memory growth during training, and (3) a post-hoc human fact-checking pass to sanitize accumulated memories before deployment. Evaluated on OSWorld productivity tasks and additional adversarial stress tests, VerificAgent improves task reliability, reduces hallucination-induced failures, and preserves interpretable, auditable guidance--without additional model fine-tuning. By letting humans correct high-impact errors once, the verified memory acts as a frozen safety contract that future agent actions must satisfy. Our results suggest that domain-scoped, human-verified memory offers a scalable oversight mechanism for CUAs, complementing broader alignment strategies by limiting silent policy drift and anchoring agent behavior to the norms and safety constraints of the target domain.

§Introduction (from cached fulltext; cut at ~9000 chars)
Autonomous computer-using agents (CUAs) have the potential to transform how users interact with software by delegating routine digital tasks to AI. Recent advances in large language models (LLMs) with multimodal capabilities have enabled agents that can interpret and manipulate graphical user interfaces (GUIs) much like a human operator. For example, OpenAI’s Operator system is trained to read screen content and perform clicks, typing, and other GUI actions without relying on application-specific APIs [ 1 ] . This generality allows a single model to work across web and desktop applications. However, while such agents demonstrate impressive versatility, they still struggle with complex, domain-specific tasks. In particular, office productivity applications (e.g., Microsoft Word and PowerPoint) pose a significant challenge for current CUAs, which have been primarily trained on web browsing and simple tool use rather than the intricacies of Office software. Benchmark evaluations underscore this gap. OSWorld [ 2 ] provides a realistic operating system environment with tasks spanning real-world apps, and reports that state-of-the-art agents solve only about 12% of tasks overall, far below human performance ( \approx 72 %). Even with subsequent improvements—OpenAI’s CUA model reached 38% success on OSWorld’s full task suite—performance on Office-specific tasks remains around 25% success in the best models [ 3 , 1 ] . In practice, current agents often fail at fine-grained Office operations like precise text formatting or slide manipulation, which require remembering complex instructions and adapting to detailed interface layouts. This motivates the need for methods that can boost the task efficiency of CUAs in such complex domains. Recent work has shown that augmenting LLM agents with persistent memory can substantially improve multi-step task adaptation and planning [ 4 , 5 ] . However, these methods do not guard against the gradual accumulation of spurious or hallucinated entries, which can mislead downstream decision-making [ 6 ] . Unvetted memories can encode latent policies that violate user intent or safety constraints, so verification becomes a form of scalable oversight. From a theoretical standpoint, verification is often easier than generation—checking a candidate solution requires fewer resources than constructing one—and this distinction carries over to LLMs: empirical studies find that models verify or critique outputs more reliably than they generate them from scratch [ 7 , 8 ] . Practical frameworks like LLM-Cite demonstrate that fact verification can be performed cheaply and efficiently by generating citation URLs and then validating claims against retrieved documents, reducing verification cost by over an order of magnitude compared to full generative pipelines [ 9 ] . Similarly, tools such as SymGen provide direct, in-context citations that speed human validation of model outputs by presenting source evidence alongside responses [ 10 ] . Moreover, in domains where no structured knowledge base exists, a lightweight human review of distilled memory entries can still be carried out with minimal effort, ensuring reliability without major overhead. Despite these advances in rapid verification, memory-based agents have largely overlooked the need to sanitize their learned memory stores. No prior system integrates a post-hoc fact-checking pass to prune or correct hallucinated memory entries before inference in a production environment. From an alignment perspective, memory-augmented agents face a distinct risk: they may internalize hallucinated ‘policies’ that deviate from user values and safety constraints. Our central question is how to ensure that an agent’s persistent memory remains accurate and value-consistent as capabilities scale. We treat memory verification as a form of scalable oversight: humans correct high-impact errors once, then freeze these corrections to guide future behaviors. In this work, we cast persistent agent memory as both a capability enabler and a latent alignment threat: without safeguards, agents may internalize spurious rules that induce unsafe or incorrect behaviors. VerificAgent addresses this by combining expert-seeded priors, iterative memory growth, and a human-in-the-loop sanitization step, yielding a scalable oversight pipeline that aligns the agent’s learned heuristics with domain-specific safety constraints. Our key contributions are: 1. VerificAgent : scalable oversight that boosts capability and safety . We introduce a two-stage “generate-then-freeze” pipeline that turns persistent memory from an alignment liability into an asset—nearly doubling task success on the OSWorld Office benchmark while cutting harmful actions, without any extra model training. 2. Alignment-centric evaluation suite for GUI agents .
