title: CUAWright: A Minimal Unified Interface for Digital Agents
source: https://arxiv.org/abs/2610.04116

§Abstract
The prevailing approach to computer-use agents couples a model with a domain-specific harness: a browser or desktop environment equipped with human engineered tools that are fixed before task execution. As models' coding capabilities improve, the GUI native and static harness prevents them from direct programmatic operation on system state, as well as flexible construction of tools. To this end, we introduce CUAWright, a minimal terminal harness of roughly 3K lines of code that uses bash commands as its sole action interface, and a file system as its evolvable space for dynamically creating tools and managing the context. We conduct comprehensive experiments across a wide range of digital tasks, and demonstrate that by giving the agent a minimal, programmable interface, it achieves substantially stronger results compared to their GUI or hybrid CLI interface across a wide range of tasks. On OSWorld 2.0, CUAWright delivers a 33.2% relative improvement in partial reward while reducing estimated cost by 37.5% compared with the published GPT-5.5 baseline. On Online-Mind2Web and the long horizon Odysseys benchmark, CUAWright substantially outperforms GUI native harness by 4.7% and 44.0% in success rate, respectively. Furthermore, we found the gains extend to CAD applications that require accurate visual understanding and CLI interaction: on CADGenBench and BenchCAD, our unified harness yields 8.1%-41.6% relative improvements over other CLI based harnesses with GPT-5.5. Together, these results suggest digital environments are far more programmable than their GUI interfaces imply, and a minimal terminal-focused harness is the key for better performance and efficiency.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-use agents have advanced rapidly across different domains and tasks. Web agents can observe screenshots or DOM tree of web pages at each step, and select the next elements or predict pixel coordinates to operate on directly ( Deng et al., 2023 ; Zhou et al., 2024 ; He et al., 2024 ; Zheng et al., 2024 ; Hong et al., 2024 ; Pahuja et al., 2025 ; Shi et al., 2025 ; Gupta et al., 2026 ; Awadallah et al., 2026 ) . Similarly, desktop agents can use softwares in the environments through screenshots and low-level mouse and keyboard actions like humans ( Xie et al., 2024 ; Bonatti et al., 2024 ; Qin et al., 2025 ; Agashe et al., 2025 ; Lu et al., 2026 ) . However, solving computer-use tasks through stepwise screenshot or accessibility observations and low level actions is limiting since the screenshot exposes limited information of the environment state. And primitive actions associated with keyboard and mouse movements constrains the agent from direct and programmatic access to the underlying system state. More recent works explored hybrid interfaces that delegate GUI operation and code action through different sub-agents ( Song et al., 2026 ; Zhong et al., 2026 ) or explicitly define a tool to execute code against the environment ( Parikh et al., 2026 ) . However, they are domain-specific and GUI centric, where agents are restricted to a fixed set of predefined tools. To address the above challenges, we propose a terminal native harness in which every model action is a terminal command. As shown in Figure 2 , at each step the agent model predicts an action in a command line interface to engage with the underlying execution environment, which consists of a runtime, a file system and an expandable set of tools and libraries. In particular, a browser task is driven by agent generated code written against the debugging protocol ( Microsoft, 2025 ) ; a desktop task is driven naturally through terminal command, CLI tools, or directly editing the source file. When a surface genuinely prevents programmatic control, the agent uses keyboard and mouse actions through xdotool/pyautogui command. Therefore CUAWright features: 1) a single terminal action space that is universal, allowing agent to interact with both system state and keyboard and mouse actions, and 2) direct and programmatic access to file system that the agent can use to manage its context, and craft new tools through writing, testing and executing program files using terminal commands. Further, in contrast to GUI native and hybrid harnesses which append a screenshot at every step, CUAWright’s default observation is terminal output, and the agent captures a screenshot on demand. We summarize our contributions into the following: • We introduce CUAWright, a minimal harness in which agents perform web and desktop tasks solely through terminal commands, and use file system for context management and new tool creation. • We evaluate CUAWright across live and long-horizon web, desktop, and computer aided design (CAD) tasks, and show that terminal-centric interaction is effective, efficient, and substantially more robust than GUI native or hybrid interaction. • We conduct extensive ablation studies between single agent and multi-agent settings when using terminal native harness, and demonstrate that the file system is crucial for the performance. Detailed analysis shows emergent behaviors of frontier models crafting its own creative tools and reuse them within the task.
