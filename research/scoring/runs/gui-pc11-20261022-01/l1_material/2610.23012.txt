arxiv: 2610.23012 (2610.23012v1)
title: Adaptation of Computer Use Agents to New Software with User Manuals
source: https://arxiv.org/abs/2610.23012

§Abstract
Recent advances in multimodal foundation models have significantly improved the ability to operate real-world software through graphical user interfaces (GUIs) using visual observations and natural language instructions. However, maintaining strong performance on unseen applications remains challenging, as practical tasks often require long-horizon procedural knowledge and application-specific operation patterns. In addition, constructing executable tasks and collecting corresponding trajectories for training still heavily rely on human-annotated data, incurring substantial cost. In this paper, we propose MAGE (Manual-augmented computer use AGent Execution and learning), a framework that leverages user manuals as a scalable source of procedural knowledge to improve both inference and training. During execution, MAGE retrieves task-relevant manual content and uses a planner to generate explicit procedural guidance for CUAs. To further account for the discrepancies between manuals and actual GUI environments, such as version differences or user settings, MAGE also adapts the agent policy through environment interaction. During training, MAGE converts manuals into executable task-plan pairs and uses the plans to guide environment rollouts toward task-relevant states; the resulting trajectories are then used to optimize the policy without human-authored demonstrations. This unified design enables effective utilization of manuals for both task execution and training, reducing reliance on human-authored training data. Experimental results across six applications demonstrate improvements in task success rates over strong baselines, highlighting the effectiveness of manual-guided planning and policy adaptation in new software environments. We provide the code and reproduction scripts at https://github.com/ku-autoai/MAGE.

§Introduction (from cached fulltext; cut at ~9000 chars)
Recent advances in multimodal vision-language models (VLMs) ( Yin et al., 2024 ) have enabled Computer Use Agents (CUAs) ( Zhang et al., 2024 ; Lin et al., 2024 ; Qin et al., 2025 ; Wang et al., 2025 ) to operate software from visual observations and natural language instructions. Unlike conventional automation methods that rely on APIs or HTML structures, these agents interact directly with graphical user interfaces (GUIs) in a human-like manner. This enables CUAs to perform various tasks across diverse software environments. However, existing CUAs require additional training to maintain high performance on unfamiliar applications since each application has its own interface and functionalities. Existing adaptation ( Qin et al., 2025 ; Zhang et al., 2025a ; Yuan et al., 2025 ) typically relies on costly human annotations to define diverse executable tasks and collect corresponding action trajectories. Although reinforcement learning ( Sutton et al., 1998 ; Silver and Sutton, 2025 ; Shao et al., 2024 ) can reduce the need for human demonstrations, GUI tasks are inherently long-horizon: agents should sequentially uncover available options through clicks, menus, and dialogs rather than observing all relevant information at once. This makes it difficult to obtain sufficient successful trajectories, limiting the training signals required to improve the agent policy. To address these limitations, we leverage user manuals as a source of procedural supervision. Manuals describe application functionalities and the procedures required to execute them, including functions hidden behind menus, dialogs, and toolbars. By exposing access routes to such functions, manuals can reduce unguided exploration in long-horizon GUI tasks. Prior approaches have also leveraged external knowledge, such as web tutorials and past interaction experiences, to guide GUI agents ( Xu et al., 2025a ; Agashe et al., 2025 ) . However, providing external knowledge only during execution does not directly address the challenge of collecting successful trajectories for policy adaptation. Moreover, manuals may be abstract or differ from actual GUI environments due to software versions, user settings, or access permissions. Thus, agents must ground procedural guidance through environment interaction and learn which actions succeed in the current GUI state. Based on this observation, we propose MAGE (Manual-augmented computer use AG ent E xecution and learning), a unified framework that leverages user manuals to improve both execution-time planning and training-time policy optimization. During execution, MAGE retrieves task-relevant manual content and uses a planner to generate task-specific procedural plans that guide CUAs. During training, it automatically generates diverse executable tasks and corresponding plans from user manuals. Rather than treating generated plans as expert demonstrations, MAGE evaluates the collected trajectories and optimizes the agent policy using Group Relative Policy Optimization (GRPO). This joint use of manuals for planning and policy learning enables application-specific adaptation without human-authored demonstrations or step-level action annotations. Our main contributions are summarized as follows. • We propose MAGE, a unified framework that uses user manuals as procedural supervision for both execution-time planning and training-time policy learning, combining a planner with CUAs. • We introduce retrieval-augmented planning, which retrieves task-relevant manual content and generates procedural plans to guide long-horizon GUI execution. • We develop a manual-derived training method that constructs task-plan pairs and optimizes the policy from the resulting trajectories without human-authored demonstrations or step-level annotations. • We evaluate MAGE across six applications and demonstrate improvements in task success rates over the corresponding baselines, examining the contributions of manual-guided planning and policy optimization.
