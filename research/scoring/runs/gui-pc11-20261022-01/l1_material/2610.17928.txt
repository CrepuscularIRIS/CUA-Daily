title: Learning How to Remember: Memory Modality Selection for GUI Agents
source: https://arxiv.org/abs/2610.17928

§Abstract
Recent advances in vision-language models (VLMs) have substantially improved the capabilities of GUI agents, while memory augmentation has emerged as a promising approach for reusing knowledge from past interactions. However, existing memory augmented GUI agents typically adopt a fixed representation strategy, providing retrieved experience as a static modality. It remains unclear whether a single memory modality is consistently optimal, or how modality preference changes across interaction steps. In this work, we conduct a systematic study of memory modality in VLM based GUI agents. Across GUI benchmarks, we find that the preferred memory representation is strongly step dependent. Motivated by the finding, we introduce \textbf{SwitchMem}, a routing framework that dynamically selects between textual and visual memory representations at each step. Across three GUI benchmarks, SwitchMem outperforms memory augmented baselines that rely on static memory representations. Our findings validate our claim that memory modality is a step dependent decision rather than a fixed design choice. Code and project resources are available at https://txxnrd.github.io/switchmem

§Introduction (from cached fulltext; cut at ~9000 chars)
Recent advances in vision-language models (VLMs) have substantially improved their ability to perceive, reason over, and act upon visual environments ( Xie et al., 2024 ; Gemini Robotics Team et al., 2025 ; Jung et al., 2026 ) . Such progress has enabled graphical user interface (GUI) agents, where VLMs directly interpret screenshots, reason about user instructions, and execute actions across desktop and mobile environments ( Xu et al., 2024 ; Zhang et al., 2025 ; Rawles et al., 2025 ; Qin et al., 2025 ) . Despite these advances, GUI interaction remains challenging: tasks often require long-horizon decision making, and errors made at one step can propagate to subsequent decisions. To learn from prior interactions and reduce repeated errors, recent GUI agents augment the actor with memories constructed from past trajectories, demonstrations, interaction knowledge, and visual observations ( Li et al., 2026b ; Qin et al., 2026 ; Choi et al., 2026 ; Liu et al., 2026 ; Zeng et al., 2026 ) . However, existing systems generally adopt predefined memory representations, presenting retrieved experience solely as text, visual observations, or a fixed combination of both modalities. Once chosen, this representation strategy typically remains unchanged across interaction steps. However, existing GUI memory systems rarely question whether a single representation modality is suitable for every interaction step. Prior work on VLMs suggests that textual and visual representations provide fundamentally different forms of information and that their relative utility depends on the reasoning context. ( Pezeshkpour et al., 2025 ; Yang et al., 2026 ; Long et al., 2026 ; Roh et al., 2026b ) . Text can provide a compact semantic abstraction of visual content, but converting images into language may discard fine-grained information required for downstream reasoning ( Yang et al., 2026 ) . Conversely, visual representations preserve fine-grained spatial and appearance information that textual surrogates may fail to retain ( Yang et al., 2026 ; Jenkins, 2026 ) . However, when the information needed for reasoning can be captured in structured text, textual abstraction can improve performance on complex visual reasoning tasks ( Liu et al., 2023 ; Park et al., 2025 ; Xu et al., 2026 ) . Although these findings highlight the context-dependent role of modality in VLM reasoning, it remains unclear whether the preferred memory modality varies across interaction steps in memory enhanced GUI agents. In this work, we conduct a systematic study of memory modality in VLM based GUI agents. We show that preferred memory modality changes each step, and that the preference is revealed through models internal hidden states. Based on the observations, we introduce SwitchMem , a lightweight router that selects between textual and visual memories at each step. Our contributions are threefold: • We show that the preferred memory modality varies across interaction steps and that fixed modalities lead to suboptimal performance across evaluation settings. • We show that memory modality preference is reflected at the representation level within the agent. Our Directional Chain-of-Embedding (D-CoE) analysis reveals a reproducible Text/Image preference signal that generalizes to unseen GUI trajectories. • Building on this representation-level signal, we propose SwitchMem , a routing framework that adaptively selects between Text and Image memory at each interaction step. Consequently, it consistently outperforms all static memory baselines across evaluation tasks.
