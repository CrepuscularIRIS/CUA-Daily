title: TeleTune: Evolving Agent Skills From Offline Telemetry
source: https://arxiv.org/abs/2610.05437

§Abstract
Computer-use agents need to capture procedural knowledge of how people use software. User telemetry offers a scalable source of this knowledge. However, learning reusable skills from these logs requires addressing three challenges: (1) Goal Underspecification, since logs do not record the goal behind each action; (2) Non-Replayability, since past activity cannot be replayed to evaluate skill updates; and (3) Interleaved Trajectories, since logs may mix several tasks without marking their boundaries. To address these, we introduce TeleTune, a framework for learning a textual skill library from offline logs without recorded goals, cannot be replayed during optimization, and may interleave tasks. TeleTune uses action-prediction errors on logged trajectories to propose library edits and keep only those that improve held-out action-prediction accuracy, which we call skill-guided progress. The learned workflows also enable retrieval of demonstrations that cover the subgoals of a new task. At test time, the agent is provided with the learned library and the workflow-based retrieved demonstrations. Experiments on WorkArena and Online-Mind2Web show that TeleTune outperforms random retrieval, Agent Workflow Memory (AWM), and their combination. We find that the best baseline varies by setting, whereas TeleTune achieves average success rates of 77.1% and 80.6%, respectively, improving over the strongest baseline on each benchmark by 6.7% and 7.7%. Under the heaviest perturbation of the WorkArena training data,TeleTune keeps the highest average success rate at 68.5%, 6.3% above the strongest baseline. Our analyses show (1) skill optimization and workflow-based retrieval are complementary, (2) optimizing on fixed logs costs 5 to 75 times fewer tokens than validating the same edits with live episodes, (3) skill-guided progress tracks the live success rate.

§Introduction (from cached fulltext; cut at ~9000 chars)
Completing a task in an unfamiliar software system requires knowing more than which buttons to click. For example, an agent handling a service request may need to locate the relevant record, check its fields, and follow a local procedure before changing its status. Learning reusable skills from experience offers a way to provide agents with such procedural knowledge ( Wang et al., 2025 ; Ouyang et al., 2026b ; Shinn et al., 2023 ; Wang et al., 2023 ; Zhao et al., 2024 ; Zheng et al., 2025 ) . For agents adapting to an organization’s tools and practices, one source of this experience is user telemetry , the logs of interface states and actions recorded as people use software. These logs capture how users carry out recurring procedures and could help an agent complete similar tasks in the future. However, these logs record ongoing user activity whose goals and task boundaries are implicit, unlike the individual, goal-labeled trajectories used in the skill-learning literature. Learning from this ongoing activity raises three related challenges visualized in Figure 1 (a) and (b): (1) Goal Underspecification: Logs record what a user did, but typically do not record the goal behind each action sequence. The agent must learn from actions whose purpose is implicit in the interface state and preceding history. (2) Non-Replayability: Telemetry records actions taken by real users while completing their own tasks. We cannot expect users to repeat those tasks each time we update a skill library just to help validate it. Nor do logs necessarily preserve a resettable environment in which an agent can try the task with the updated library. We must therefore evaluate skill updates offline from the recorded activity, without the fresh outcome feedback available through live interaction. (3) Interleaved Trajectories: Logs may interleave several tasks without marking their boundaries. A user might interrupt a record update to look up information elsewhere, handle an unrelated request, and then return to the original record. Prior work addresses parts of this setting. AWM and ReasoningBank learn reusable guidance from goal-labeled experience ( Wang et al., 2025 ; Ouyang et al., 2026b ) , while NNetNav and robotic process mining address goal-free exploration and unsegmented logs, respectively ( Murty et al., 2024 ; Leno et al., 2020 ; Leno et al., 2021 ) . None of these approaches addresses all three challenges together, which motivates our question: can an agent learn reusable skills from logs that carry no goals, cannot be replayed to evaluate updates, and interleave several tasks? We illustrate this setting in Figure 1 (c), and introduce Telemetry-Informed Tuning for Agent Skills ( TeleTune ), a framework for learning a reusable textual skill library from offline logs without recorded goals or environment access during optimization. Our central idea is to use the prediction of recorded actions as the learning signal for building and revising the skill library. The library contains (1) workflows , describing procedures shared across task instances, and (2) skills , which guides individual decisions. Both are editable text provided in the prompt of an agent at test time. Like SkillOpt ( Yang et al., 2026 ) , we treat the skill text itself as the object of optimization and keep only edits that improve held-out performance. However, SkillOpt learns from individual tasks with known goals and validates each edit by executing tasks in a live environment. Telemetry offers none of these conditions, since its trajectories do not specify goals, cannot be replayed, and may interleave several tasks. Concretely, TeleTune predicts the next action at each step of a logged trajectory, conditioned on the inferred goal, current library, interface state, and preceding action history. After each prediction, we append the recorded action to the history, so an early error does not derail later steps and every scoreable step contributes to the learning signal. We call the resulting action-prediction accuracy skill-guided progress . An optimizer examines the first prediction error in each trajectory and proposes additions, revisions, or removals to the entries in the library. The edits form one candidate library, which we keep only if it improves skill-guided progress on held-out trajectories. This loop allows us to refine skills using fixed logs without requesting new outcomes from the environment. Skill-guided progress can also serve as an offline proxy for the live success rate : in our WorkArena L1 run, we find that improvements in this metric track improvements in the live success rate ( Figure 3 ). This lets us compare skill libraries using existing trajectories without a live test environment, which is often unavailable for real-world systems. At test time, TeleTune uses the learned workflows to retrieve demonstrations that together cover a new task’s subgoals.
