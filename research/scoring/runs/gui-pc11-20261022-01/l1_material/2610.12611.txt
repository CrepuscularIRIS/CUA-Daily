title: SoftwareGym: Scaling Computer-Use Agent Training with Diverse Synthesized Software Environments
source: https://arxiv.org/abs/2610.12611

§Abstract
Computer-use agents (CUAs) are rapidly improving, yet synthesizing diverse and reliable software environments at scale remains challenging. Native application environments require substantial construction and integration effort, which limits application coverage and increases the risk of application-specific overfitting. Browser-hosted environments provide limited interaction depth and workflow complexity. These limitations motivate SoftwareGym, an automated pipeline for synthesizing GUI software environments with diverse interfaces, executable functionality, and runtime-verified behavior. It generates structurally diverse designs, realizes them as runnable applications, and uses GUI evaluation with iterative repair to ensure functional reliability. Using SoftwareGym, we synthesize 182 applications across twelve categories and achieve a mean GUI task pass rate of 91.5%. We construct SoftwareGym-Bench, a 120-task evaluation suite spanning the same twelve categories, and use trajectories collected from these environments for CUA training. The resulting model improves Pass@3 from 41.39% to 56.97% on the strictly out-of-domain OSWorld benchmark and achieves 40.0% on SoftwareGym-Bench. These results demonstrate the potential of synthesized software environments as scalable and transferable supervision for CUA training.

§Introduction (from cached fulltext; cut at ~9000 chars)
Training capable computer-use agents (CUAs) requires interaction data from executable software environments ( Qin et al., 2025 ) . To support generalization, these environments must provide diverse, realistic, and reliable trajectories. Constructing such environments at scale has therefore become a central bottleneck for CUA training. Current data synthesis either generates tasks and trajectories within existing desktop and mobile applications ( Sun et al., 2025 ; Xie et al., 2026 ; Jung et al., 2026 ) or constructs browser-hosted software environments ( Cao et al., 2026 ; Liu et al., 2026 ) . Native applications preserve realistic states and complex workflows, but the cost of integrating them into reproducible training environments limits application coverage and increases the risk of application-specific overfitting. Browser-hosted environments support scalable deployment and state control, but their shared substrate limits interaction depth and workflow complexity. Existing approaches do not jointly satisfy three requirements for CUA training: interface and interaction diversity to support generalization, functional reliability to produce valid, complex trajectories, and scalability to expand the environment pool with limited engineering effort. Achieving these three requirements introduces three corresponding challenges: interface and interaction diversity is difficult because unconstrained generation within the same software category often converges toward similar layouts and interaction patterns; functional reliability requires every specified function to remain usable through complete GUI workflows; scalability requires these diversity controls and reliability checks to be applied across a large software pool, creating a verification burden that manual development cannot sustain. To address these challenges, we design SoftwareGym , an automated multi-agent pipeline for GUI software synthesis. For diversity, SoftwareGym creates category-level functional specifications and variant-specific interface and interaction designs. For reliability, it combines source-level verification with checkpoint-based GUI evaluation and repair; only applications that complete both source-level and GUI verification enter the software library. For scalability, it automates the complete process with minimal human input, enabling applications to be generated in batches with substantially lower time and monetary costs than manual development. To realize these goals, synthesis proceeds in three stages. The design stage expands minimal human input into a detailed functional specification, diverse UI blueprints, and corresponding interaction schemes. The implementation stage converts each design package into an executable application and verifies its source-level functionality. The evaluation stage executes checkpoint-based GUI tests and guides iterative implementation repair. These stages enable SoftwareGym to produce diverse and functionally reliable software environments with realistic multi-step workflows at scale. Using this pipeline, we construct a large, diverse, and functionally reliable software library in substantially less time and at lower monetary cost than manual development. We synthesize 182 runnable applications across twelve categories, with a mean GUI task pass rate of 91.5%. Figure 1 illustrates their functional depth across representative software categories. We use trajectories collected from these applications to train a model. Without using any OSWorld applications, tasks, or trajectories for training, it improves Pass@3 from 41.39% to 56.97% on OSWorld, demonstrating strong out-of-domain generalization. For complementary evaluation, we evaluate the model on SoftwareGym-Bench, a dedicated 120-task test set spanning the same twelve categories; it achieves 40.0% Pass@3 and outperforms several larger specialized computer-use agents. Our contributions are threefold: (1) We introduce SoftwareGym, an automated environment-synthesis pipeline that produces functionally reliable and structurally diverse software at scale, with substantially lower development time and monetary cost than comparable manually developed applications. (2) We release 182 runnable applications across twelve categories and construct SoftwareGym-Bench, a dedicated 120-task test set spanning the same twelve categories. (3) Through extensive evaluations and ablations, we validate the pipeline’s key components and show that the model trained only on SoftwareGym trajectories improves OSWorld Pass@3 by 15.58 points to 56.97%.
