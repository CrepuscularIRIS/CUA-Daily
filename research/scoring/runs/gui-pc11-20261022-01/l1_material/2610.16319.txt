title: HyWe: Unifying Search and Operation for Real-World Hybrid Web Tasks
source: https://arxiv.org/abs/2610.16319

§Abstract
Real-world hybrid web tasks need both information gathering and page interaction, yet search-based and operation-based agents are developed and evaluated separately. To bridge this gap, we introduce HyWe, a framework that unifies both capabilities within one model and trajectory. Its two modes use dedicated prompts and tool sets to sustain sub-goal execution; explicit switching selects the needed capability, and shared history lets each mode build on the other's findings. To provide demonstrations of these behaviors, we develop HyWeCollector, a fully automatic pipeline that uses task prototypes, four switching patterns, and multi-agent synthesis to produce verified hybrid trajectories. We train HyWe-35B on these demonstrations to unify efficient information gathering and browser interaction in a single 35B web agent. To evaluate hybrid task completion, we introduce HyWeBench: 100 human-written tasks on websites distinct from training, with human-written sub-goal checklists and an outcome-based evaluation pipeline. Hybrid training enables HyWe-35B to achieve 47.0% success on this benchmark, improving on the untrained base model by 19.0 percentage points and outperforming existing search-based and operation-based agents. Even before training, the same base model solves 28.0% of tasks with HyWe, versus 11.0% with all tools under one prompt. Beyond hybrid tasks, HyWe-35B achieves 59.0% and 88.3% success on Online-Mind2Web and WebVoyager, outperforming existing open-source baselines and cutting action cost per successful task by 48.3% and 51.9% compared with Fara-7B.

§Introduction (from cached fulltext; cut at ~9000 chars)
LLM agents have made substantial progress on web tasks, with approaches broadly falling into two groups. (i) Search agents use search and page-reading APIs to gather information efficiently across websites ( OpenAI, 2025 ; Tongyi DeepResearch Team, 2025 ) . (ii) Operation agents observe HTML or screenshots and interact with browsers through clicking and typing ( He et al., 2024 ; Qin et al., 2025 ) . In practice, however, many real-world web tasks are hybrid, and both types of agents struggle to solve them. Figure 1 illustrates a task that requires both finding the Bible verse beginning “ Blessed are the poor in spirit ” and playing its American Sign Language video on Deaf Bible. Search agents quickly find the verse but cannot play the video because their tools lack page interaction; operation agents face long browser navigation to locate it. Existing benchmarks also separate these task types: BrowseComp ( Wei et al., 2025 ) and DeepSearchQA ( Gupta et al., 2026a ) focus on cross-website information gathering, while Online-Mind2Web ( Xue et al., 2025 ) and WebVoyager ( He et al., 2024 ) typically focus on operations within one website, leaving hybrid task completion insufficiently evaluated. To quantify the limitations of existing search and operation agents, we sample real-world tasks from InSTA ( Trabucco et al., 2025 ) and probe capability and efficiency. For capability, the search agent recovers only about 40\% of facts obtained through browser interaction (Section 3.2 ). For efficiency, the search agent solves 29\% of the sampled tasks within four steps, compared with 6\% for the operation agent (Appendix B ). Search agents gather information faster; operation agents use browser actions to achieve required page states or obtain information search cannot provide. To unify these complementary capabilities, we introduce HyWe , a framework for general-purpose web agents that organizes execution around completing sub-goals. An agent should gather enough evidence or complete the required interaction for each sub-goal, while using earlier findings to guide the remaining work. The same model works in a search mode or an operation mode. Mode-specific prompts and isolated tool sets guide evidence gathering, page interaction, and recovery from failed attempts, helping the model focus on the current sub-goal. An explicit switch action makes changing capabilities a deliberate decision: another mode may be needed to finish the current sub-goal or pursue the next one more efficiently. A unified action–observation format and shared history carry earlier findings forward so subsequent work builds on existing progress. Together, these designs help the agent complete sub-goals and choose when to change modes. Compared to exposing all tools under one prompt, our framework improves information and operation sub-goal completion from 36.9\% and 15.8\% to 74.8\% and 43.7\% , respectively, using the same base model (Section 4.4 ). To learn how to complete sub-goals and switch between modes, we develop HyWeCollector , a fully automatic pipeline for collecting high-quality hybrid trajectories on real websites. (i) Task prototypes describe reusable sub-goals; (ii) four switching patterns capture capability limits, efficiency, and dependencies between sub-goals; and (iii) multi-agent trajectory synthesis coordinates task generation, execution, phase control, and review to produce verified examples of hybrid trajectories. We use these examples to train HyWe-35B . As a result, it achieves higher success rates and greater efficiency on operation tasks: 59.0\% and 88.3\% success on Online-Mind2Web and WebVoyager, using 48.3\% and 51.9\% fewer actions per successful task than Fara-7B ( Awadallah et al., 2025 ) . It also maintains strong deep search capabilities, with 64.0\% accuracy on xbench-DeepSearch-2510 (Section 4.5 ). We introduce HyWeBench to evaluate real-world hybrid task completion: 100 high-quality, human-written tasks on websites distinct from those used for training, human-written info / op checklists, and a corresponding evaluation pipeline. Each task includes at least one op sub-goal; the judge verifies outcomes from execution evidence regardless of the mode used. HyWe-35B achieves 47.0\% success, up from 28.0\% before training, and outperforms search and operation agents, including XYZ-Aquila-mini ( 22.0\% ) and Fara-7B ( 13.0\% ). Its success rate is comparable to Kimi-K3 ( 46.0\% ) and Qwen3.8-Max ( 44.0\% ), with 1/80 and about 1/69 of their total parameters, respectively (Section 4.3 ). Our contributions are as follows. (i) HyWe . A framework unifying search and operation capabilities through focused sub-goal execution, explicit mode switching, and shared evidence. (ii) HyWeCollector . A fully automatic pipeline using task prototypes, switching patterns, and multi-agent synthesis to collect high-quality examples of hybrid trajectories. (iii) HyWeBench .
