title: Work2Skill: Capturing Human GUI Experience for Reusable Agent Skill Induction
source: https://arxiv.org/abs/2610.12984

§Abstract
Computer-use agents can perform increasingly complex GUI tasks, yet unfamiliar software and workflows requiring human domain knowledge remain challenging. Human demonstrations convey procedural knowledge through the same GUI interaction space, but reuse requires interpreting actions in context and separating workflow rules from task-specific details. We thus introduce Work2Skill, a framework that captures human GUI experience for reusable agent skill induction. WorkRecorder provides the framework's infrastructure for collecting this experience, aligning screen recordings, mouse and keyboard events, and available accessibility-tree information. Using WorkRecorder, we construct WorkDemo-350, the first synchronized multimodal dataset of human desktop GUI demonstrations for reusable agent skill induction and downstream evaluation. Its 350 demonstrations are screened for completeness and task success. We then propose an agentic skill-induction method that inspects evidence on demand to produce reusable skills capturing workflow rules, step dependencies, and completion checks. When the same four execution models are equipped with skills induced by each method under shared execution settings, Work2Skill achieves the highest scores and success rates. Mean score improvements over the corresponding No Skill baseline are 4.67--10.54 points on MyPCBench Bounded Action and 3.11--7.50 points on a 286-task subset of OSWorld-Verified. Our code and data are available at https://github.com/china-qijizhifeng/Work2Skill.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-use agents can perform increasingly complex desktop and web tasks, supported by advances in GUI grounding and planning ( Qin et al., 2025 ; Agashe et al., 2025 ; Wang et al., 2025a ) . Yet agents still struggle with unfamiliar software and workflows that require domain knowledge, where successful execution depends on procedures not spelled out in the user’s request ( Zhang et al., 2026e ; Jang et al., 2026 ) . For example, “submit my reimbursement” does not specify which internal portal to use, which receipts to attach, or what to check before submission. Agents need this user- or organization-specific procedural knowledge to translate a user’s goal into GUI actions. Human demonstrations offer a direct source of this knowledge because humans and computer-use agents share the same GUI interaction space. Demonstrated controls, action sequences, and visible outcomes can therefore guide an agent’s own execution. Prior work converts demonstrations into expert instructions and semantic action traces ( Li et al., 2025 ; Zhang et al., 2026e ) , multimodal tutorials ( Bai et al., 2026 ) , or reusable skills ( Yang et al., 2026a ; Xiao et al., 2026 ) . OpenAI’s Record & Replay ( OpenAI, 2026b ) and Claude’s Record a skill ( Anthropic, 2026a ) bring this approach to user-facing tools. We thus introduce Work2Skill, a framework that captures human GUI experience for reusable agent skill induction (Figure 1 ). Its three components address the following challenges in action grounding, method comparison, and evidence inspection. First, action coordinates reveal where an operation occurred but not what the target control means. ShowUI-Aloha interprets actions from full-screen frames and target crops ( Zhang et al., 2026e ) , while Demo2Tutorial uses before-and-after screenshots ( Bai et al., 2026 ) . Without accessibility-tree (AX) evidence, these parsers depend on visual grounding to infer target semantics; selected frames can also miss transient states and intermediate operations. WorkRecorder addresses this ambiguity by aligning screen recordings, mouse and keyboard events, and available AX information. Recorded element names and roles provide explicit control semantics, while linked video preserves the surrounding state changes. The induction agent can thus interpret an operation using both its visual context and available structured UI evidence. Second, representative desktop GUI studies use different demonstrations, task sets, and execution protocols ( Zhang et al., 2026e ; Bai et al., 2026 ) . Their results mix differences in induction with differences in source experience and evaluation conditions. WorkDemo-350 provides a common demonstration resource for skill induction in desktop environments. Collected with WorkRecorder, it contains 350 human GUI demonstrations covering 64 MyPCBench Bounded Action tasks ( Jang et al., 2026 ) and a 286-task OSWorld-Verified subset ( Xie et al., 2024 ) . Each demonstration is screened for completeness and task success and packaged with synchronized visual and action evidence, plus available AX information. This shared evidence and a controlled downstream protocol support comparisons of induction methods using the same task evaluators and execution conditions. Third, representative pipelines prescribe an order for action parsing and procedure abstraction, even when individual stages refine their outputs ( Zhang et al., 2026e ; Bai et al., 2026 ) . This couples evidence inspection to predefined stages. Loading a long recording into context at once also creates context pressure, while selecting a fixed subset can omit details needed later. Our agentic skill-induction method addresses both constraints by interleaving on-demand evidence inspection with skill writing and revision. Drawing on active evidence acquisition in agentic video understanding ( Yuan et al., 2025 ; Wang et al., 2026 ; Li et al., 2026 ) , the agent selects linked files, images, and video intervals to resolve questions as they arise. It can revisit the source after drafting without loading the entire recording at once. During skill writing, we guide the agent to generalize demonstration-specific inputs into task-dependent descriptions while preserving procedural rules, step dependencies, and completion checks. The skills guide execution without the source recording. We evaluate the resulting skills through downstream execution on the WorkDemo-350 tasks. Using official evaluators and a shared text-guidance interface, we compare Work2Skill with No Skill and text-adapted versions of ShowUI-Aloha and Demo2Tutorial. Across four execution models, Work2Skill improves mean evaluation scores over No Skill by 4.67 – 10.54 points on MyPCBench Bounded Action and 3.11 – 7.50 points on the evaluated OSWorld-Verified subset. Further experiments test reuse under changed requirements within the same application (MyPCBench Jitter) and transfer between two execution models.
