title: Imagine to Act: High-Fidelity Data Synthesis via Image Editing World Model for Scalable GUI Agent Training
source: https://arxiv.org/abs/2610.05861

§Abstract
Graphical User Interface (GUI) agents have emerged as a promising paradigm for automating complex digital workflows across diverse applications. However, training highly capable and generalizable agents fundamentally relies on massive, high-fidelity visual-action trajectories, which are notoriously difficult to acquire. While human demonstrations are unscalable, existing GUI world models rely on text descriptions or HTML rendering, discarding crucial pixel-level visual details like icons and layout styles. To address this issue, we introduce Infinite-Dreamer, a simulation-free data synthesis method powered by a pixel-level Image Editing World Model. By conceptualizing GUI transitions as image editing tasks, we leverage Vision-Language Models (VLMs) to describe action-induced UI changes as structured delta-text. We then fine-tune an image editing backbone to controllably synthesize realistic screenshot transitions. We utilize this model to generate both single-frame visual robustness data and multi-step imaginary trajectories. To validate the effectiveness of our approach, we fine-tune the Qwen3-VL baseline solely on the synthesized data to obtain Infinite-Actor, and evaluate it on AndroidWorld, MobileWorld, and AndroidControl-Curated benchmarks. Infinite-Actor consistently outperforms the Qwen3-VL baselines across scales: Infinite-Actor-8B improves AndroidWorld Pass@1 by +4.45 and nearly doubles the MobileWorld Pass@3 success rate, while Infinite-Actor-2B improves Pass@1 by +9.05. Code is available at https://github.com/swaydy-n/Infinite-Dreamer.

§Introduction (from cached fulltext; cut at ~9000 chars)
Graphical User Interface (GUI) agents have rapidly emerged as a pivotal frontier in artificial intelligence, promising to seamlessly automate increasingly complex digital workflows across diverse operating systems and web applications. Unlike text-based language agents, GUI agents must perceive rich visual screens, effectively reason over layout structures, and accurately execute precise actions just like human users. To achieve robust generalizability across infinitely varied real-world digital environments, these agents must master the intricate mapping between natural language instructions, dynamic screen layouts, and sequential action executions. Ultimately, the development of such highly capable and adaptable GUI agents is fundamentally contingent upon the availability of massive, diverse, and high-fidelity annotated visual-action training data. Despite its critical importance, acquiring high-quality trajectory data annotated with explicit action intents remains exceptionally difficult. Existing efforts to obtain such data generally suffer from two major limitations: (i) Human-driven demonstration is not only financially prohibitive and labor-intensive, but it is also severely bottlenecked by environmental constraints, such as the technical friction of configuring heterogeneous device platforms and the inherent risks of exposing sensitive user privacy during the recording process; (ii) Automated environment exploration typically relies on heuristic search or random-walk strategies. Lacking a long-term semantic objective, these automated agents easily become trapped in trivial UI loops, frequently trigger unrecoverable error dead-ends, or generate disjointed action sequences. Consequently, such exploration-based approaches heavily bias the collected data toward short, repetitive interactions, making them incapable of scaling to complex, multi-step workflows and utterly failing to maintain goal coherence over long execution sequences. Therefore, how to scalably synthesize GUI interaction trajectories while improving data efficiency has emerged as a core challenge in training advanced GUI agents. To address this challenge, the paradigm of world models offers a powerful solution for data synthesis. Fundamentally, world models are specifically designed to internalize the underlying transition dynamics of an environment, predicting subsequent states by learning the causal laws that govern how the world responds to specific actions. In the digital ecosystem, a robust GUI world model acts as an unconstrained virtual simulator, emulating how software applications evolve after a click or a scroll. While recent pioneering GUI world models, such as Qwen-AgentWorld and Code2World, attempt to simulate environments via text descriptions or HTML rendering, they inherently struggle to capture diverse layouts and fine-grained visual features, such as custom icons, banners, and dynamic animations (Figure 1 ). In contrast, pixel-level screenshots represent the natural, raw state space of GUIs, directly reflecting the visual reality experienced by human users. A pixel-level world model can implicitly learn the visual regularities of UI evolution, such as a loading spinner disappearing or a drop-down menu unfolding, thereby preserving both rich graphical details and complex software execution logic. Therefore, leveraging image editing models directly as GUI world models offers a more natural, direct, and high-fidelity paradigm for realistic data synthesis. To this end, we introduce Infinite-Dreamer, a high-fidelity, simulation-free data synthesis pipeline that generates pixel-level screenshots and continuous action trajectories without relying on complex and restrictive simulation environments. First, we construct a specialized image editing dataset built upon AndroidControl. By employing a Vision-Language Model (VLM) to describe the transitions of UI elements before and after an action, we generate fine-grained delta-text that precisely captures added or removed interface elements. Second, we apply fine-tuning to a generative image editing backbone. The resulting model serves as a pixel-level GUI world model, capable of editing a pre-action screenshot into a post-action screenshot conditioned on the delta-text. Finally, to demonstrate how our synthesized data enhances downstream agent performance, we generate two distinct categories of samples: (i) visual robustness data, where we augment single screenshots with diverse layouts, colors, and styles to boost the agent’s adaptability, and (ii) multi-step imaginary trajectories, where the world model continuously edits an initial screenshot to ”imagine” multi-step task executions, expanding state coverage beyond the limits of real-world datasets.
