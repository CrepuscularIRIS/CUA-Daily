title: CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling
source: https://arxiv.org/abs/2610.06829

§Abstract
Open-source web agents are now strong enough to execute realistic browser tasks, but training them with reinforcement learning still depends on weak supervision: binary task success is too sparse for credit assignment, while frontier-language-model judges are too expensive to call at every step and cannot be assumed available at deployment. We introduce CLIFT, a training and test-time scaling method built around conformal self-verification. During training, the agent answers natural-language verification questions about its own rollouts; a Compositional Conformal Certifier keeps only question signals whose URL-conditional evidence agrees with a training-time judge, assigns signed trust weights through polarity-aware lift, and blends the resulting verifier score into per-step rewards in a way that never subtracts from the judge baseline. At test time, the same certified bank is frozen and reused as structured evidence for Conformal Trajectory Selection (CTS): the agent samples a greedy rollout and one or more diverse retries, the self-verifier summarises each URL trace, and a conservative majority-vote rule chooses whether to swap away from the current incumbent without calling any external judge. This single mechanism supports three settings. On WebArena Infinity, CLIFT achieves state-of-the-art performance among open-source web agents. On VisualWebArena, a bank trained with the open model transfers to GPT-5.5 at test time and reaches state-of-the-art performance under the canonical harness. On Online Mind2Web, without training an agent on the benchmark, translating the certified question bank improves a live-web agent in zero-shot evaluation. Together these results position conformal self-verification as a way to turn costly judge feedback into a reusable training signal and a judge-free test-time scaling signal.

§Introduction (from cached fulltext; cut at ~9000 chars)
Open-source web agents have reached the point where they can operate realistic browser interfaces, but the verifier remains the bottleneck for improving them with reinforcement learning. A binary success signal is easy to deploy but too sparse for credit assignment: when all rollouts in a GRPO group ( Shao et al., 2024 ) receive the same outcome, the advantage estimate collapses. A frontier language model judge ( Bai et al., 2022 ; Liu et al., 2023 ) provides richer feedback, but it is costly during training and cannot be assumed available at test time. This tension is especially visible in web-agent benchmarks: WAI ( Zhou, 2026 ) uses programmatic per-app verifiers, VWA ( Koh et al., 2024 ) uses outcome-based URL/DOM checks, and live-web suites such as OM2W ( Xue et al., 2025 ) depend on noisy LLM judges. The policy is often not the only limiting object; the way we score and select its rollouts can dominate the observed success rate. CLIFT maintains a bank of natural-language verification questions about web-agent behaviour and certifies which questions are reliable at which URL states. The same bank is used in two places (Figure 2 ). During training, certified bank evidence is blended with the comparative judge to produce a denser per-step reward and URL-stratified advantages. At test time, the trained agent runs a greedy trajectory plus diverse retries; the frozen certified bank summarizes each URL trace; and a conservative trajectory selector keeps one emitted trajectory per task. The common object is not a new model but a calibrated verifier: a set of questions, URL scopes, polarity signs, and conformal trust weights that can be reused after training. The certifier is the part that makes this more than prompt engineering. Each verification question carries a URL scope and a polarity sign indicating whether YES is evidence of progress or failure. A Mondrian adaptive conformal tracker ( Gibbs and Candès, 2021 ; Vovk, 2012 ) estimates whether that question separates high- and low-judge rollouts at the relevant URL granularity. Certified questions receive signed trust weights. During training this gives a verifier reward that can only add evidence on top of the judge baseline, preventing the reward-collapse failure of earlier linear blends. During test-time scaling, the same signed evidence is frozen and presented to a comparative selector over two completed trajectories. In both cases, the question bank is a compact interface between expensive judge feedback and the agent’s own rollouts. We evaluate this idea in three complementary ways. On WAI, where programmatic verifiers provide dense training supervision, CLIFT improves a trainable open Gemma-4 agent and reaches the strongest public 9-app score we are aware of; the point is both training and CTS on the same open backbone. On VWA, where the evaluation is more outcome-based, we use the bank created during Gemma-4 training as a test-time verifier for GPT-5.5, showing that the learned verification knowledge transfers to a stronger closed backbone and reaches state-of-the-art performance under the canonical harness. On OM2W, we push transfer further: no agent is trained on OM2W; instead, the certified question bank is translated and recalibrated, then used by CTS to improve live-web test-time scaling. These three stories support the same claim: conformal self-verification is useful both as a training signal and as a reusable, judge-free test-time scaling signal.
