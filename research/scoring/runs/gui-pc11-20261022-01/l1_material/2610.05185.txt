title: Recurrent Latent Visual Search for GUI Grounding
source: https://arxiv.org/abs/2610.05185

§Abstract
GUI grounding is a critical capability for GUI agents powered by vision-language models, helping them execute user instructions by locating the corresponding elements in screenshots. Single-step grounding struggles with small elements and dense layouts, motivating multi-step visual search. However, existing approaches commonly rely on textual reasoning misaligned with visual space or costly multi-round interactions with external visual tools. To make multi-step visual search an explicit spatial process within the model, we propose ReLaViS, which performs Recurrent Latent Visual Search in a single interaction round. At each step, a spatial search head uses the hidden state to query the screenshot's visual tokens, producing a spatial search distribution that explicitly represents the search focus. This distribution then aggregates the visual tokens into latent visual evidence, which is recurrently fed back as the next input embedding to condition subsequent search. We further introduce a GUI-aware coarse-to-fine inductive bias through trajectories constructed from flat element annotations, supervising search from the global interface through intermediate element groups to the target. Built on Qwen2.5-VL-7B, ReLaViS improves ScreenSpot-Pro accuracy by 3.1 percentage points to 56.3% with only a 3.5% increase in inference FLOPs and outperforms the matched single-step baseline on all five benchmarks.

§Introduction (from cached fulltext; cut at ~9000 chars)
Advances in large language models (LLMs) and vision-language models (VLMs) enable GUI agents to understand user instructions and operate software interfaces ( Anthropic, 2024 ; Wang et al., 2024 ; OpenAI, 2025 ) . GUI grounding, which locates the interactive element specified by an instruction, is a core capability underlying actions such as clicking ( Yang et al., 2025 ; Yuan et al., 2025 ) . Prevailing approaches formulate GUI grounding as single-step localization, directly predicting a coordinate, bounding box, or spatial distribution ( Xie et al., 2025 ; Tang et al., 2026b ; Wu et al., 2025b ) . Despite strong performance on standard interfaces, they still struggle with high-resolution screens, small targets, and dense layouts, where accurate grounding requires integrating global structure, local appearance, and instruction semantics ( Li et al., 2025b ; Feizi et al., 2026 ) . To address these challenges, recent work improved grounding through multi-step visual search, including inspecting local regions ( Tang et al., 2026a ; Liu et al., 2026a ) or revising predictions ( Zhao et al., 2026 ; Wang et al., 2026b ) before returning a final location. A key design choice is how to represent search states and update them across steps. Thinking about images expresses target semantics and spatial reasoning through chain of thought, yet the textual tokens are not directly aligned with visual space ( Shao et al., 2024 ; Chen et al., 2026c ) . Thinking with images makes visual search explicit through tools such as zoom-in or cropping, but incurs additional test-time computation through multiple interaction rounds and image re-encoding ( Lei et al., 2025 ; Zhang et al., 2026b ; Tang et al., 2026a ) . Latent visual reasoning instead propagates continuous visual representations internally, but existing formulations leave the multi-step spatial search process implicit ( Li et al., 2026a ; Qin et al., 2026 ; Wang et al., 2026a ) . This raises a question: Can multi-step visual search become an explicit spatial process within a model’s internal computation? Our key insight is to represent search as an evolving spatial focus over the screenshot’s visual tokens. Each search state specifies where to search and carries the corresponding visual evidence forward to guide subsequent search. Search thus proceeds over the same encoded screenshot without additional interaction rounds or image re-encoding. Beyond representing search states, we need to determine how their spatial focus should evolve toward the target. Human visual search in GUIs provides useful inspiration, as people often search through likely regions and element groups before identifying the target ( Putkonen et al., 2025 ) . This motivates using the GUI hierarchy as a natural inductive bias to organize multi-step visual search from coarse to fine. In practice, supervising this GUI-aware coarse-to-fine visual search remains challenging, as annotations of UI trees and search trajectories are scarce. Building on these insights, we propose ReLaViS , a framework that performs Re current La tent Vi sual S earch for GUI grounding (Fig. 1 ). Specifically, at each step, a spatial search head uses the hidden state to query the visual tokens, producing a spatial search distribution over them. This distribution represents the current search focus and then aggregates the visual tokens into latent visual evidence, which is recurrently fed as the next input embedding to condition subsequent search. We further supervise the search process with GUI-aware coarse-to-fine trajectories constructed from flat element annotations, progressing from the global interface through intermediate element groups to the target. After the final search step, a deterministic readout converts the distribution into a click coordinate. Our contributions are threefold: (i) we formulate GUI grounding as recurrent latent visual search and propose ReLaViS, a framework that recurrently updates explicit spatial search states aligned with visual tokens within a single model interaction, without external tools; (ii) we construct stepwise supervisory trajectories from flat GUI element annotations to instantiate a GUI-aware coarse-to-fine inductive bias without requiring scarce ground-truth UI trees; and (iii) ReLaViS outperforms matched single-step baselines across all five GUI grounding benchmarks, including a 3.1-point accuracy gain on ScreenSpot-Pro (53.2% to 56.3%) with only 3.5% more inference FLOPs, while controlled analyses support its key design choices.
