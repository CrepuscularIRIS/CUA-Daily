title: Video2World: Benchmarking Coding Agents for Interactive World Modeling from Embodied Videos
source: https://arxiv.org/abs/2610.04432

§Abstract
Building interactive simulators from real-world observations is a promising way to scale embodied data, but current pipelines still rely heavily on manual environment construction and calibration. We study whether frontier foundation models and coding agents can automate this process end to end. We formulate \emph{autonomous video-to-simulation} as a software engineering task in which an agent observes an embodied video, constructs the corresponding simulated environment and robot behavior, and iteratively refines the result through execution feedback. To evaluate this capability, we introduce \textbf{Video2World}, a benchmark comprising 222 reconstruction instances derived from 189 robot and human demonstration videos. Video2World measures reconstructed worlds along geometric fidelity, dynamic fidelity, and functional correctness, capturing spatial perception, physical reasoning, and executable interaction. Evaluating 9 frontier coding-agent systems reveals a sharp improvement in Task success beginning with Claude Opus 5, rising from below 5\% to over 15\%, while substantial gaps to human-assisted reconstruction remain. We further find that worlds that look better could work worse: better visual fidelity does not always lead to higher task success. This echoes the broader gap between perceptual realism and factual correctness observed in generative models.

§Introduction (from cached fulltext; cut at ~9000 chars)
Embodied AI aims to build intelligent systems that can perceive, reason, and act effectively in the physical world, enabling applications such as robotic manipulation, household assistance, and industrial automation ( Duan et al., 2022 ) . Fully acquiring these capabilities requires large amounts of diverse embodied interaction data, which is expensive, time-consuming, and difficult to scale in the real world ( Khazatsky et al., 2024 ; Mandlekar et al., 2023 ) . To alleviate this bottleneck, many prior works have explored interactive simulation as a scalable data engine, where agents can act, observe state transitions, and automatically collect embodied experience ( Nasiriany et al., 2024 ; Wang et al., 2024a ; Wang et al., 2024b ) . Conventional Real-to-Sim pipelines, however, still require substantial engineering effort to reconstruct and configure simulation environments, calibrate geometry and physical properties, align coordinate systems, and integrate perception and simulation components ( Torne et al., 2024 ; Han et al., 2026 ; Chen et al., 2026a ) . In recent years, foundation models and agents have made rapid progress in spatial perception, visual understanding and planning, demonstrating increasingly strong capabilities in solving complex software and embodied tasks ( Yang et al., 2025 ; Jimenez et al., 2024 ; Xie et al., 2024 ; Fu et al., 2026 ; You et al., 2026 ) . These advances make it increasingly promising to automate the full process of interactive world modeling in simulators through an agent itself ( Ye et al., 2025 ; Chen et al., 2026a ) . Such automation could substantially reduce the human effort, and enable the efficient conversion of real-world observations into scalable interactive environments for data generation, policy learning, and evaluation. However, existing benchmarks typically assess only one or a few isolated capabilities for interactive environment reconstruction, such as spatial understanding, physical rule following, scene reconstruction, or environment editing ( Yang et al., 2025 ; Wang et al., 2026 ; Gao et al., 2026 ; Zhao et al., 2026 ; Tang et al., 2026 ) . To fill this gap and directly test whether foundation models and coding agents can autonomously construct interactive physical worlds, we formulate autonomous video-to-simulation as an end-to-end software engineering task ( Ye et al., 2025 ; Chen et al., 2026a ) . Concretely, given an RGB video of an embodied interaction together with a target simulator, an agent must construct the environment, implement the robot behavior, and iteratively refine the simulation through execution feedback. To support systematic evaluation, we construct a dataset that pairs embodied videos with their corresponding simulator environments, including aligned scene configurations, object states, and interaction trajectories. This paired structure allows us to compare an agent-generated simulation directly against the underlying target environment and assess the full reconstruction quality. In this way, we measure not only whether an agent can understand the world, but also whether it can integrate embodied reasoning, physical understanding, spatial perception, and agentic coding abilities to recover an interactive environment that faithfully reproduces the demonstrated physical world. We introduce Video2World , a benchmark for evaluating foundation models and coding agents on autonomous interactive world modeling from embodied videos.
