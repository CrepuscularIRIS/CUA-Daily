title: PhysEvo: Astra Can Act, Let It
source: https://arxiv.org/abs/2610.08995

§Abstract
Astra can act, yet reliable manipulation depends on the system through which it observes and controls the world. We introduce PhysEvo, a framework for physical recursive self-improvement (RSI) around a single frozen model. A task agent executes robot tasks; a meta-agent uses the resulting trajectories to diagnose failures, revise tools and skills, and test corrections. The meta-agent can also improve its own diagnostic tools, so retained revisions support both later action and later self-improvement. This process develops joint-level control, evidence-seeking observation, and reusable manipulation skills without model-weight updates or a separately trained action policy. Across 42 RoboDojo tasks, held-out-layout evaluation of retained task-specific deployment versions yields a five-dimension average score of 68.14/100 and 62.00% success, compared with 47.17% for RoboDawn's one-shot Astra agent, the strongest published reference in our comparison. On eight manipulation tasks challenging direct Astra, PhysEvo achieves 55.00% success, compared with 1.25% for the direct-Astra reference. Deploying the simulation-evolved harness on AgileX PiPER and continuing skill revision yields 90.60/100 average score and 84.00% success across 25 trials on five real-world tasks. PhysEvo turns the consequences of action into persistent, testable changes to how a frozen model acts and improves.

§Introduction (from cached fulltext; cut at ~9000 chars)
Astra can already control a robot, but demonstrated competence does not guarantee reliable execution. In a ten-task RoboDojo evaluation, direct Astra reaches 100% success on object classification yet succeeds on only 26% of attempts overall. Pairing it with the specialized vision–language–action (VLA) policy \pi_{0.5} raises success to 48% ( Su et al., 2026 ) . These results pose a question: what prevents capabilities that are already present from being used reliably? Our executions expose bottlenecks in the harness : the tools, skills, and execution logic between the model and the robot. During pouring, the held bottle obscures the wrist view needed to monitor liquid delivery. With a tool-center-point (TCP) interface, local inverse kinematics (IK) can fold the arm into an obstructive posture, while leaving Astra no explicit way to choose the joint configuration ( figures 3 and 4 ). These failures call for more than a new action through an unchanged interface: the agent needs a useful view or direct authority over posture. Why should the same model be able to fix a failure it did not prevent? Retrospective diagnosis has access to evidence that was unavailable during action selection. A trajectory reveals the consequences of a command; aligned images, robot states, and code help trace those consequences to a cause. Astra can then propose a concrete intervention, such as maintaining a free-arm side view or exposing joint reconfiguration, and test it through further execution. In our pouring case, revised skill guidance changes the observation strategy, and the subsequent episode succeeds. Physical interaction thus provides both evidence for a correction and a test of whether it works. A correction need not end with the episode. Retained tools and skills change later execution; retained diagnostic tools change how later failures can be investigated. In our packing case, Astra reuses a review tool it built earlier to trace box displacement to preceding contact and revise clearance guidance ( figure 5 ). We call this loop physical recursive self-improvement (RSI): experience revises the system used for action and diagnosis, and the revised system is inherited by subsequent rounds. We introduce PhysEvo , which implements this loop with one frozen Astra in two roles. The task agent observes and controls the robot. The meta-agent inspects execution, edits tools and skills, tests revisions, and retains useful changes, including changes to its own diagnostic resources. The resulting framework combines joint-level control, active and historical observation, geometry tools, and manipulation skills. Across 42 RoboDojo tasks, held-out-layout evaluation of retained task-specific deployment versions achieves 68.14/100 score and 62.00% success under equal five-dimension weighting. This exceeds the 47.17% reported by RoboDawn’s one-shot Astra agent, the strongest reference in our comparison ( table 1 ) ( Guo et al., 2026a ) . On the ten-task comparison with direct and hybrid policies, PhysEvo reaches 68.00% success versus 26.00% and 48.00%, respectively. On eight manipulation tasks challenging direct Astra, it reaches 55.00% versus 1.25% , a 53.75-point gain ; Simate-beta, the strongest robot-policy reference on this subset, reports 50.83% ( figures 1 and 3 ) ( RoboDojo Team, 2026 ; Zhang et al., 2026d ) . On AgileX PiPER, the simulation-evolved harness serves as a starting point for continued adaptation. Across five trials on each of five real-world tasks, PhysEvo achieves a mean score of 90.60/100 and 84.00% success. Revisions compensate for liquid-flow effects and replace geometry-first localization with a visually guided approach followed by close-range geometric refinement ( section 5.6 ). The same loop can therefore revise both how the robot moves and when it seeks geometric evidence. Our contributions are (i) a physical RSI framework in which one frozen model acts, revises, and inherits task and meta resources; (ii) an evolved interaction architecture combining joint control, evidence-seeking observation, and reusable skills; and (iii) a 42-task evaluation with mechanism-focused cases and a five-task evaluation of continued adaptation on real hardware.
