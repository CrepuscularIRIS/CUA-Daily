title: MemU-Bench: Benchmarking GUI Agents on Long-Horizon User Interactions
source: https://arxiv.org/abs/2611.00191

§Abstract
Existing Graphical User Interface (GUI) benchmarks predominantly rely on precise and stateless user instructions. In everyday usage, however, instructions are often \emph{vague and history-dependent}: users omit the exact details of their past operations because they no longer remember them, leaving the agent to recover the missing context from long and noisy interaction histories. To bridge this evaluation gap, we introduce \textbf{MemU-Bench}, a mobile benchmark of \textbf{118 vague tasks} grounded in 29 long-horizon user trajectories, where agents must distill raw interaction streams into memory and retrieve the missing context on demand, with task outcomes verified against serialized application databases. Alongside Success Rate, we incorporate Interaction Efficiency (IE) and Success weighted by Path Length (SPL) to expose agents that succeed by exhaustively searching across different applications rather than by \emph{genuinely recalling} the history. Evaluations show that without user history, state-of-the-art systems struggle under such ambiguity: the best-performing Gemini-3.1-Pro achieves an SPL of only 16.4\%, and end-to-end GUI agents fall below 5\%. To address this, we further propose \textbf{AppMem}, a training-free framework that distills user history into a \emph{structured, app-centric} memory bank, tracks interrupted intents across application switches, and selectively retrieves relevant memories via target-app inference. AppMem raises the SPL of GPT-5.5 from 15.7\% to 66.9\% (\textbf{+51.2\%}), outperforms a naive summary baseline by 9.3\%, and delivers consistent gains across evaluated backbones.

T=Text, I=Image Graphical User Interface (GUI) agents built on Multimodal Large Language Models ( Wang et al. 2024b ; Bai et al. 2025b ; Bai et al. 2025a ) are rapidly evolving into general-purpose digital assistants that translate natural language instructions into executable action sequences on real devices ( Tang et al. 2025 ; Hu et al. 2025a ; Cheng et al. 2024 ; Lin et al. 2025 ; Qin et al. 2025 ; Lu et al. 2026a ; Lu et al. 2025 ; Tang et al. 2026a ) . Existing benchmarks almost exclusively evaluate GUI agents under precise, self-contained instructions ( Rawles et al. 2023 ; Rawles et al. 2025 ; Xie et al. 2024 ) . Everyday usage rarely looks like this. Since users seldom remember the exact details of their past interactions, they tend to issue vague, history-dependent commands such as “modify the meeting time”, which cannot be resolved unless the agent knows which meeting was created, when, and in which application (Figure 1 ). Unlike preference-driven personalization, the missing context here consists of objective operational evidence : facts that were fully observable in past interactions but are now buried in hundreds of steps of routine phone usage. Completing such tasks therefore demands more than a capable executor. The agent must continuously distill its user’s interaction stream into memory and retrieve the right piece of it on demand . Faithfully measuring this ability imposes three requirements on benchmark design. First, real interaction histories are long and noisy : the few decisive state changes are scattered among hundreds of visually redundant screenshots, so the benchmark must expose agents to raw histories rather than pre-cleaned summaries. Second, real users multitask : a single intent is often interrupted, resumed later, and interleaved with unrelated activities in other applications, so the trajectories must preserve such fragmented intents . Third, task success alone is not evidence of memory : an agent can complete a vague task by exhaustively searching through applications at execution time, so the evaluation must distinguish genuine recall from brute-force exploration . We introduce MemU-Bench, a mobile benchmark that instantiates these requirements (Table 1 ). It comprises 118 vague tasks grounded in 29 long-horizon user trajectories that cover more than 30 applications, with 100 to 800 steps per trajectory. Tasks are stratified by history length into 71 Level-1 and 47 Level-2 tasks to assess memory scalability. Each task follows a three-phase protocol: the agent first builds a memory bank from the raw history, then retrieves key information for the vague instruction, and finally executes the task online. Outcomes are verified programmatically against serialized application databases , complemented by an LLM judge for open-ended text. Besides Success Rate (SR), we incorporate Interaction Efficiency (IE) and Success weighted by Path Length (SPL) ( Anderson et al. 2018 ) , which penalize agents that reach the goal by wandering across applications instead of recalling the relevant context. Evaluations on MemU-Bench expose a consistent weakness of current systems. Without access to user history, the best-performing model, Gemini-3.1-Pro, attains an SPL of only 16.4%, and end-to-end GUI agents remain below 5%. Their trajectories degenerate into aimless exploration across applications, which inflates interaction cost even when the task eventually succeeds. Long-term memory is thus not an optional extension but a prerequisite for handling vague instructions in realistic settings. Guided by these observations, we propose AppMem, a training-free framework that equips GUI agents with long-term user memory. During daily usage, AppMem summarizes the interaction stream through a sliding window into app-centric memory entries and tracks the status of each intent, so that events interrupted by application switching are merged into coherent threads instead of fragmented records. Upon receiving a vague instruction, it infers the target applications, retrieves only their associated entries, and iterates until the collected information is sufficient for execution.
