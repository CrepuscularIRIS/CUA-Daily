title: Runtime Authorization of Self-Generated Subgoals in Long-Horizon Tool-Using AI Agents
source: https://arxiv.org/abs/2610.04975

§Abstract
Long-horizon tool-using AI agents create subgoals, replan, delegate work, and compose sibling results. Per-tool permission checks cannot establish that a changing goal graph remains within the principal-approved task. We address this authorization gap in a finite structured domain with one principal and one authorization root. Each proposed goal-graph mutation carries a version-bound witness that its continuation traces, resources, obligations, invariants, and closing condition refine the active root contract; every protected effect is rechecked at an atomic commit boundary. Free-form goal text supplies no authority. We prove trace-policy and modeled forbidden-state preservation under explicit mediation, abstraction, freshness, and atomicity assumptions, plus conditional root-success preservation, a separation result for memoryless allowlists, exact finite-domain decidability, and universal-safety monotonicity under sound abstraction refinement. An executable model explores 340 states and 419 transitions. Across 96 matched cases covering 25 structural schemas, the complete mechanism commits zero forbidden states in 48 drifted cases and completes all 48 benign counterparts. Two public upstream runtime paths execute 258 native dispatches across 32 cases, with every case-level decision and receipt chain matching. A frozen host-local study covers 129 synthetic one-factor-at-a-time cells, all matching fixed decisions and reasons. A history-aware continuation comparator blocks every modeled bad trace prefix but commits all operations in 11 cases whose violations lie in typed resources, freshness, or explicit-join evidence outside its trace projection. Within the registered structured domains, runtime authorization preserves useful replanning while preventing self-generated subgoals from becoming a source of new authority.

§Introduction (from cached fulltext; cut at ~9000 chars)
Tool-using AI agents increasingly execute tasks that extend beyond one model response or one API call. A long-running agent may decompose a request, delegate work, revise its plan after an observation, recover from a failed operation, and combine the outputs of several subgoals before producing an external effect. These capabilities improve task completion, but they also change the unit that authorization must govern. A permission check on the next tool call answers whether that call is locally admissible. It does not, by itself, answer whether the growing goal graph still implements the task the principal authorized. This distinction matters whenever policy is non-compositional. Two writes can each target an allowed field while their joint state violates a separation constraint. A recovery action can use an allowed tool yet widen the resource scope from one account to every account. A delegated task can preserve the parent’s vocabulary while replacing its completion condition with an easier proxy. A stale plan can remain locally valid after the policy or relevant environment state has changed. In each case, an allowlist or independent per-call classifier can accept every action even though the authorized task has been expanded through planning. The classical literature already supplies the relevant foundations. Execution monitoring characterizes policies enforceable from traces ( Schneider, 2000 ; Ligatti et al., 2005 ; Leucker and Schallhart, 2009 ) ; hierarchical planning gives formal accounts of task decomposition and refinement ( Erol et al., 1996 ; Georgievski and Aiello, 2015 ) ; and safety and liveness separate finite bad prefixes from eventual progress requirements ( Alpern and Schneider, 1985 ) . Recent peer-reviewed agent benchmarks show that realistic tool use is stateful, multi-step, and vulnerable to adversarial or policy-violating trajectories ( Ruan et al., 2024 ; Debenedetti et al., 2024 ; Yao et al., 2025 ; Trivedi et al., 2024 ; Tur et al., 2025 ; Jiang et al., 2026 ; Li et al., 2026b ) . The open systems question is therefore not whether sequence-aware policies exist. It is how to connect a dynamically changing, agent-produced goal graph to a reference monitor so that planning changes become authorization events and protected effects remain inside the original structured task contract. 1.1. Problem statement We study one principal, one approved root task contract, and a finite structured effect domain. The root contract fixes required and forbidden state predicates, resource bounds, outstanding obligations, temporal limits, and a prefix-closed language of permitted effect traces. The planner and its generated natural-language explanations are untrusted. Before a proposed child, replacement, delegation, or same-root join becomes active, the agent must submit a structured goal description and a checkable transition witness. The witness establishes that the proposed continuation is no broader than the current authorized continuation, preserves active invariants and obligations, and was derived for the current policy and state versions. Every protected effect is then mediated against the active goal and the residual permitted trace language. The paper does not infer authority from free-form text. An upstream component may translate a user request into a structured contract, but the principal or a trusted policy service must approve the structure used for enforcement. This boundary keeps the security claim decidable and auditable: the mechanism checks refinement in a registered finite domain rather than claiming general natural-language entailment. 1.2. Why local authorization is insufficient Consider a task that permits changing either a deployment artifact or its traffic target during diagnosis, but forbids publishing unreviewed code to the production target. The first update is locally permitted, as is the second. After the first update, however, the second must be rejected unless a review obligation has been discharged. A memoryless action allowlist observes the same second action in both the safe and unsafe histories and must return the same decision. A final-state checker can detect the violation only after both effects have committed. The missing state is not another textual warning; it is the authorized composition of the current prefix and the still-reachable future effects. Section 2 gives the executable minimal case and its matched benign trace. 1.3. Approach We represent the approved task and every proposed subgoal in one typed effect and state vocabulary. A goal node records its parent, success predicate, resources, obligations, active frames, policy/state versions, and a finite set of maximal completion traces whose prefix closure denotes the remaining continuations. An ordinary transition is checked along one fresh leaf-to-root witness path; sibling continuations are composed only by an explicit join request whose admissible interleavings are enumerated.
