title: OS-Wizard: Scaling Computer-Using Agents to Specialized Software via Knowledge-Guided Exploration
source: https://arxiv.org/abs/2610.33907

§Abstract
Computer-using agents are increasingly capable of performing complex tasks in the digital world. However, high-quality interaction trajectories remain scarce for specialized desktop applications, where limited application knowledge, cumbersome GUI workflows, and incomplete exploration hinder automated collection. We introduce OS-Wizard, an automated trajectory collection framework. It combines tutorial-guided exploration with a hybrid GUI--Code action space, providing application-specific knowledge and simplifying GUI workflows through direct execution of application-native commands. The framework also checkpoints and revisits pivotal states during tree exploration to explore alternative workflows, complementing linear rollouts for broader coverage. We collect 10.9K trajectories comprising 54.9K state--action samples. Fine-tuning open-source base models on this corpus yields a best-performing model that improves performance on a benchmark of specialized desktop workflows by 58.2 percentage points to 64.1\%, surpassing reported human performance of 59.8\% and establishing a new state of the art. The fine-tuned model also improves performance on general desktop workflows using GUI actions only, suggesting that the collected supervision benefits general desktop tasks as well. Comparative experiments and ablations demonstrate the efficiency of trajectory collection and the importance of code actions.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-using agents (CUAs) extend foundation models from understanding multimodal information to directly interacting with computers, enabling them to complete tasks through graphical user interfaces (GUIs) across web and desktop environments ( Deng et al., 2023 ; Zhou et al., 2024 ; Xie et al., 2024 ; Yuan et al., 2026 ) . Given a task instruction and observations such as screenshots, a CUA repeatedly reasons about the current state and executes actions such as mouse clicks or keyboard input ( Hong et al., 2024 ; Zheng et al., 2024a ; Agashe et al., 2025 ) . As these agents are increasingly expected to handle longer and more complex workflows, their capabilities depend critically on diverse and high-quality interaction trajectories that provide supervision for both interface grounding and multi-step decision making. However, computer-using trajectories remain substantially more difficult to obtain than conventional text or vision data, and existing datasets still rely heavily on costly human demonstrations ( Wang et al., 2026 ; Liu et al., 2026 ; Qin et al., 2025 ) . Recent work has begun to automate trajectory synthesis through model-driven exploration and task generation ( Xu et al., 2025 ; Sun et al., 2025 ; Wei et al., 2026 ) , but collecting useful data for specialized desktop applications faces three challenges. First, the scarcity of application-specific interaction data leaves general-purpose models with limited knowledge of how to use these applications correctly, hindering effective exploration. Second, even when applications expose domain-specific languages (DSLs), issuing commands through the GUI requires additional interface interactions, introducing failure points beyond those of direct command execution. Third, collection through independent linear rollouts leaves functional coverage largely to chance: unguided sampling can miss important capabilities, while valuable intermediate states are not systematically revisited to explore alternative workflows. To address these challenges, we introduce OS-Wizard , an automated trajectory collection framework for specialized desktop applications. OS-Wizard augments GUI interactions with domain-specific code actions that directly submit application-native commands, including DSL expressions, reducing the interface interactions required to execute expert operations. In Figure 1 , this abstraction reduces a multi-step hydrogen-bond visualization workflow to a single code action. To equip the collector with the knowledge needed to use this action space, we retrieve application documentation and tutorials that explain application workflows and command usage, guiding exploration and task execution in unfamiliar software. Beyond independent linear rollouts, we introduce tree exploration organized around pivotal states —states expected to offer valuable branching opportunities. By identifying and checkpointing these states, the collector can repeatedly restore them and explore different continuations, reusing shared workflow prefixes to broaden functional coverage. Both collection strategies combine execution checks with stage-specific verification. We evaluate OS-Wizard on ScienceBoard ( Sun et al., 2026 ) , a benchmark of specialized scientific applications, and OSWorld ( Xie et al., 2024 ) , a general desktop benchmark. On ScienceBoard, fine-tuning Qwen3.5-27B on our collected trajectories improves overall task success from 5.9% to 64.1%, surpassing the reported overall human performance of 59.8% and establishing a new state of the art. Under a matched 10K-sample training budget, OS-Wizard achieves 36.5% success compared with 13.0% and 18.9% for the Task-driven and Branch-driven collection baselines, demonstrating that our collection framework produces more effective supervision per sample. On OSWorld, the fine-tuned model improves success from 39.1% to 42.9% using GUI actions only, which shows that the collected supervision supports substantial gains on specialized applications while also improving general desktop task performance. Our main contributions are: • We introduce OS-Wizard, an automated trajectory collection framework for specialized desktop applications, using tutorials to mitigate knowledge gaps and revisiting pivotal states to explore alternative workflows beyond independent linear rollouts. • We develop a validatable hybrid GUI–Code action space that reduces the interface interactions needed to execute application-native commands, with ablations supporting the value of code supervision. • We collect 10,919 trajectories comprising 54,938 state–action samples, improving performance on ScienceBoard and OSWorld and outperforming alternative collection strategies under a matched training-data budget.
