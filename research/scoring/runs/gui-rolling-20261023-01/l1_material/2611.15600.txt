title: MemCredit: From Relevance to Utility for Decision-Time Memory in Long-Horizon Web Agents
source: https://arxiv.org/abs/2611.15600

§Abstract
Large language model (LLM) agents increasingly operate over long Web interaction histories, making memory management critical for reliable and efficient decision making. Existing methods primarily optimize storage, retrieval, or compression, but the memories most semantically relevant to the current state are not necessarily those that most improve the agent's action. We introduce MemCredit, a decision-centric memory framework that shifts memory selection from semantic relevance to decision utility. MemCredit estimates the state-, reference-context-, and policy-conditional marginal contribution of individual memories through controlled counterfactual interventions, and distills these intervention-derived credits into a lightweight utility estimator. At inference time, semantic relevance is used only for high-recall candidate generation, while predicted utility arbitrates which memories are retained under a fixed token budget, without modifying the underlying agent policy or requiring additional environment interaction. We evaluate MemCredit on ALFWorld and WebShop against representative memory baselines. On ALFWorld, MemCredit achieves 86.57 SR@50 under a 500-token historical-memory budget, compared with 65.67% for BM25 retrieval. Counterfactual analysis further shows that memory utility is sparse, strongly state dependent, and poorly captured by semantic relevance. These results suggest that decision utility provides a more effective principle than relevance alone for long-horizon agent memory management.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language models (LLMs) are increasingly deployed as autonomous agents that search, browse, invoke tools, and interact with online environments over extended trajectories ( Yao et al., 2023 ; Shinn et al., 2023 ; Zhao et al., 2024 ) . Unlike single-turn generation, such interaction is inherently stateful : a correct decision may depend on an earlier user constraint, previously observed information, or a failed action that should not be repeated. As trajectories grow, retaining the full interaction history becomes increasingly inefficient, making memory management essential for long-horizon agents ( Park et al., 2023 ; Packer et al., 2023 ; Zhong et al., 2024 ) . Moreover, access to long context does not guarantee effective use of its contents, as performance can vary substantially with how relevant information is positioned and organized ( Liu et al., 2024 ) . Existing memory systems address this challenge through recency-based retention, semantic retrieval, trajectory compression, structured memory banks, and learned memory policies ( Xu et al., 2025 ; Zhu et al., 2026 ; Chen et al., 2026 ; Luo et al., 2026 ) . Despite these differences, memory selection is still commonly driven by recency, semantic similarity, salience, or learned retrieval scores. Such signals identify information that is related to the current state, but relatedness does not necessarily imply value for sequential decision making. As illustrated in Figure 1 , a recently observed item may be highly similar to the current observation yet contribute little to the next action. Conversely, an earlier constraint, failed attempt, or less similar piece of evidence may be critical for avoiding an incorrect decision. This reveals a fundamental mismatch between information retrieval and agent memory management: semantic relevance measures whether a memory matches the current state, whereas decision utility measures whether it improves the agent’s decision . We therefore ask: would the agent make a worse decision if a particular memory were unavailable? For a decision state s_{t} , reference memory context S , and candidate memory m_{i} , we define its policy-conditional marginal decision utility as (1) \begin{split}U_{\pi}(m_{i};s_{t},S)&=\mathbb{E}\left[Q\mid s_{t},S\cup\{m_{i}\},\pi_{\theta}\right]\\ &\quad-\mathbb{E}\left[Q\mid s_{t},S,\pi_{\theta}\right],\end{split} where Q measures environment-grounded decision quality. This formulation treats memory value as state-, reference-context-, and policy-dependent, and casts memory management as a fine-grained credit-assignment problem rather than relevance ranking. It is related to recent experience- and skill-based agents that evaluate reusable knowledge through downstream outcomes ( Xia et al., 2026 ; Tu et al., 2026 ) , but operates at the granularity of individual memories. Controlled intervention experiments support this distinction (Sec. 4.3 ; Table 3 and Figure 5 ). Across 1,041 context-conditional interventions from 45 ALFWorld tasks, 86.9\% produce no measurable behavioral change, indicating that memory utility is highly sparse. Average utility rises to 0.176 in failure contexts but is only 0.029 outside failure states, while semantic relevance has almost no overall correlation with counterfactual utility ( \rho=-0.011 ). These results suggest that semantic similarity is an unreliable proxy for whether a memory is consequential to the current decision. Motivated by these findings, we introduce MemCredit , a framework for decision-time memory arbitration in long-horizon agents. MemCredit decomposes interaction histories into atomic memories and uses controlled counterfactual interventions to estimate their marginal decision contributions. The resulting credits supervise a lightweight utility estimator, amortizing the cost of counterfactual evaluation. At inference time, MemCredit separates candidate recall from memory arbitration : semantic relevance retrieves a broad candidate pool, while predicted utility determines which memories are retained under a fixed token budget. The underlying agent policy remains unchanged and requires no additional environment interaction at deployment. We evaluate MemCredit on ALFWorld ( Shridhar et al., 2021 ) and WebShop ( Yao et al., 2022 ) . On ALFWorld, MemCredit achieves 86.57\% SR@50 under a 500-token historical-memory budget, outperforming BM25 retrieval by 20.90 percentage points. With a 750-token budget, it reaches 90.30\% SR@50, compared with 81.34\% for BM25, showing larger gains under tighter context constraints. On WebShop, MemCredit achieves the highest task score of 0.612 while using only 152.1 memory tokens per decision. Compared with MemArbiter, the strongest non-MemCredit baseline, it improves the score from 0.586 to 0.612 while using about 2.8\times fewer memory tokens; relative to BM25, memory usage is reduced by approximately 3.9\times .
