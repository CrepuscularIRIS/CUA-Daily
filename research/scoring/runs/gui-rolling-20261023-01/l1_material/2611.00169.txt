title: PatchScout: Thematic Web Data Collection via Information Foraging
source: https://arxiv.org/abs/2611.00169

§Abstract
Researchers often need web corpora that are not answers to a single query, but reusable collections of documents spanning many decentralized sources. We refer to this problem as thematic web data collection: assembling semantically relevant documents that share a common theme but are scattered across heterogeneous and structurally disconnected regions of the web. Existing approaches, including traversal-based methods and LLM-driven web agents, are limited by local exploration or short-horizon stopping, preventing comprehensive collection. We formulate this task as a long-horizon information foraging problem over query-induced semantic patches, where the central challenge is deciding when to continue local exploitation and when to switch to new regions. We propose PatchScout, a multi-agent framework that instantiates a class of patch-switching policies to balance local exploitation and adaptive patch switching under a fixed budget. Experiments on four live-web topics show that PatchScout substantially improves yield and domain coverage over traversal-based and search-augmented reasoning agent baselines. In an applied social science setting with an incomplete prior collection, PatchScout discovers 102 previously unidentified entities, illustrating its ability to expand existing thematic datasets.

§Introduction (from cached fulltext; cut at ~9000 chars)
Many scientific and societal investigations require constructing reusable thematic corpora from decentralized web sources, where relevant documents satisfy shared semantic criteria yet remain structurally dispersed across heterogeneous domains ( Lazer et al., 2009 ) . For example, a public health researcher studying pandemic-related communication may need to collect documents from hundreds of municipal health departments, while an education researcher identifying Autism Support Programs (ASPs) must gather information scattered across hundreds of university websites ( Kusters et al., 2023 ; West et al., 2025 ) . The same problem arises when assembling evaluation data for a model capability, collecting scientific sources that report a specific phenomenon, or identifying entities that satisfy a given criteria. In each case, the objective is not answering a single query, but assembling a collection of semantically relevant documents drawn from diverse, decentralized sources. We refer to this task as thematic web data collection . We define a theme as a user-provided specification of the target collection, which functions as an operational relevance criterion that defines for each encountered document whether it belongs in the collection. For example, "identify colleges that host an Autism Support Program" is a theme: the target is not a broad subject area, but a concrete set of institutions satisfying a specified condition. The theme is not submitted directly as a search-engine query, instead it is used to guide the entire collection process. Unlike traditional retrieval, where success is measured by the relevance of a ranked list, thematic collection requires simultaneously optimizing depth (maximizing thematically relevant yield within discovered sources) and breadth (maximizing coverage across distinct sources) under a limited interaction budget. This dual objective creates a fundamentally different search problem: relevant information is sparse, decentralized, and distributed across semantically related but structurally disconnected regions of the web. One may attempt to address this problem using existing paradigms for web exploration. Traversal-based approaches, such as focused crawling ( Chakrabarti et al., 1999 ; Diligenti et al., 2000 ; Aggarwal et al., 2001 ) , prioritize link expansion from a set of seed pages based on topical relevance signals. However, these methods rely on the assumption that relevant content is reachable through graph connectivity from initial seeds, an assumption that breaks in decentralized settings where semantically related sources are structurally disconnected. Alternatively, query-driven approaches based on search-augmented reasoning generate adaptive queries to retrieve relevant information ( Jin et al., 2025 ; Qian and Liu, 2025 ; Zheng et al., 2025 ) . These systems build on recent work that equips language models with search, browsing, and web-interaction tools to complete question-answering tasks ( Nakano et al., 2021 ; Deng et al., 2023 ) . They often revisit classical retrieval challenges such as selecting promising entry points, iteratively updating relevance estimates, and allocating limited interaction Dragut et al. (2022) . However, they are fundamentally designed for task-bounded objectives: their stopping criterion is answer sufficiency, not collection completeness. Once sufficient evidence is gathered to answer a user request or generate a coherent report, exploration terminates. As a result, they do not support the sustained exploration required for constructing comprehensive thematic collections. These observations highlight a fundamental gap: effective thematic web data collection requires jointly reasoning over local exploitation and global re-entry into new regions of the web under a shared budget constraint. We argue that thematic web data collection is not a page-ranking or task-completion problem; it is a budget-constrained, long-horizon information foraging problem . Information Foraging Theory (IFT) models information seeking as movement among information patches guided by information scent and expected marginal gain ( Pirolli and Card, 1999 ) . Under this perspective, effective thematic collection poses three interdependent challenges: (1) patch discovery – identifying promising new semantic regions; (2) patch exploitation – efficiently extracting high-yield documents within a discovered region; and (3) patch switching – determining when diminishing local returns justify abandoning the current patch in favor of exploring elsewhere. Therefore, the central problem is not relevance estimation or traversal optimization, but strategic patch-switching under budget constraints. Motivated by this perspective, we propose PatchScout, a multi-agent framework that formulates thematic web data collection as a sequential decision problem over semantic patches and instantiates patch-switching policies for long-horizon exploration.
