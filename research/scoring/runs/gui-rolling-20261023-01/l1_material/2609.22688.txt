title: A Design-Intent-Preserving Agent Harness for Parametric CAD Modeling
source: https://arxiv.org/abs/2609.22688

§Abstract
Parametric CAD modeling requires not only matching the target shape, but also preserving design intent under parameter edits. However, most existing methods focus on improving static shape generation accuracy, while the dependencies that govern later edits are often overlooked. To tackle this issue, we present DIP-CAD, a design-intent-preserving agent harness for generating parametric CAD models from images. DIP-CAD combines vision-language model reasoning with CAD kernel operations to establish dependencies that encode the design intent. In parametric CAD, these dependencies are mainly established through geometry references in modeling commands and constraints in parametric sketches. At the command level, ID-based explicit geometry reference binds modeling commands to selected faces, edges, or vertices. At the sketch level, a local-coordinate bridge ensures accurate sketch placement, providing the basis for correctly establishing sketch constraints. Constraints among sketch primitives and constraints to external projected geometry further preserve both internal sketch relationships and dependencies on existing geometry. To provide a more comprehensive data foundation for parametric CAD modeling tasks, we introduce the Geometry Explicit Reference Dataset (GERD), whose structured data format links stepwise modeling commands to intermediate CAD models through explicit geometry references. On GERD-EVL and a DeepCAD test subset, DIP-CAD improves mIoU for static model generation by 11.1% and 5.6%, respectively. In parameter-editing evaluations, the corresponding mIoU improvements are 7.0% and 4.2%. Case studies further demonstrate how parameter edits drive shape updates while preserving design intent.

§Introduction (from cached fulltext; cut at ~9000 chars)
Parametric CAD models encode design intent through geometry reference in modeling commands and constraints in parametric sketches. When upstream parameters are edited, these dependencies enable the CAD models to update while preserving design intent ( Yin and Ma, 2012 ; Cheng et al., 2019 ) . This editability makes parametric CAD models fundamental to iterative design, engineering analysis, and manufacturing. Meanwhile, product images and renderings are widely available during engineering design and product development. Automatically converting such visual inputs into parametric CAD models can reduce the manual effort required for CAD modeling. The resulting models can then be directly edited and reused in engineering tasks, including analysis, optimization, and manufacturing ( Chen et al., 2025b ; Chen et al., 2025a ) . Existing CAD generation methods have improved static model generation accuracy, but preserving the design intents that govern parameter edits remains a challenge. Early methods use transformer or diffusion to generate CAD models as sequences of predefined commands. DeepCAD represents sketch primitives, sketch planes, and extrusion parameters as command vectors and learns their sequential structure with a Transformer ( Wu et al., 2021 ) . Text2CAD introduces text-conditioned sequence generation, while CAD-Diffuser generates modeling sequences from point clouds through multimodal diffusion ( Khan et al., 2024 ; Ma et al., 2024 ) . Image-conditioned methods, including Img2CAD and CADCrafter, further connect visual inputs to structured CAD generation ( Chen et al., 2025b ; Chen et al., 2025a ) . These methods provide compact representations for learning sketch-and-extrude modeling sequences. However, their command vocabularies primarily describe what type of command to perform and its parameters, without explicitly identifying existing faces, edges, or vertices as references. Consequently, reproducing the target shape does not ensure that downstream commands or sketches follow upstream changes as intended. Subsequent LLM- and VLM-based methods typically generate executable CAD code, allowing them to use the reference mechanisms of CAD libraries such as CadQuery. CAD-Recode translates point clouds into Python CAD code ( Rukhovich et al., 2025 ) , and Ortho2CAD generates CadQuery code from drawings ( Joglekar et al., 2026 ) . CAD-Coder and ReCAD incorporates reinforcement learning to improve CAD code generation performance ( Doris et al., 2025 ; Li et al., 2026a ) . However, these methods primarily generate the complete CAD code without observing intermediate models, making reference selection difficult to verify and correct ( Rukhovich et al., 2025 ; Joglekar et al., 2026 ; Doris et al., 2025 ) . Recent agent-based methods incorporate execution, inspection, and revision to generate CAD code or native parametric CAD models (e.g., .SLDPRT document for Solidworks, and .FCStd document for FreeCAD). CAD-Assistant provides FreeCAD tools and visual feedback, while Seek-CAD combines stepwise feedback with references to start, end, and swept faces ( Mallis et al., 2025 ; Li et al., 2026b ) . Multi-agent systems include CADSmith, which combines error correction, geometric validation, and VLM assessment, and Fusion AI-AD, which integrates design knowledge processing with SolidWorks modeling ( Barkley et al., 2026 ; Liu et al., 2025 ) . These works enable some reference errors to be corrected. Related methods further incorporate geometric information from intermediate models. CAD-Refiner uses a topology graph and geometry checker ( Yuan et al., 2026 ) . Pointer-CAD encodes the current boundary representation (B-Rep) to support soft face and edge selection ( Qi et al., 2026 ) . Nevertheless, feature-matching-based geometry reference adopted by these methods remains prone to errors when multiple faces or edges exhibit similar features, leading to incorrect reference selection. Such errors can propagate to sketch placement and constraints to projected external geometry, undermining their ability to faithfully preserve design intent ( Figure 1 ). To address these limitations, we introduce DIP-CAD, a design-intent-preserving agent harness. It enables parametric CAD modeling that mirrors engineering workflows by customizing the interaction between a vision-language model (VLM) and a CAD kernel. Parametric CAD models are typically constructed through modeling commands and parametric sketches ( Camba et al., 2016 ; Kyratzi and Azariadis, 2022 ; Company et al., 2020 ) . For modeling commands, a key challenge is accurately selecting existing geometry. DIP-CAD addresses this challenge using edge-ID tags and structured geometry tables for explicit geometry reference. For parametric sketches, two key challenges arise. The first is accurately placing sketch primitives on the sketch plane, particularly for inclined supports.
