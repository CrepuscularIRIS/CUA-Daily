title: WebArena-Pro: A Heterogeneous, Multimodal, Reproducible Benchmark for Web Agents
source: https://arxiv.org/abs/2611.17955

§Abstract
Web agents powered by large language and vision-language models are increasingly applied to realistic browser work that spans heterogeneous applications, multimodal content, and stateful workflows. However, existing reproducible web-agent benchmarks cover only a small number of web applications drawn from a few software categories, and restrict modality to text and vision. Live benchmarks broaden site coverage but sacrifice reproducibility, since pages and data drift between runs. Moreover, existing benchmarks do not meaningfully evaluate whether agents can understand and use audio and video content embedded within web tasks. To address these gaps, we introduce WebArena-Pro, a benchmark comprising 300 tasks across 20 self-hosted web applications in six domain categories, spanning distinct interface conventions, workflows, and data models. Across the evaluated agents, the best performance is achieved by both Codex with GPT 6.1 Sol and Claude Code with Claude Opus 5.5 at 62.3%, followed by OpenCode with Kimi 3.1 Pro at 60.7%. The strongest GenericAgent configurations, Gemini 3.1 Pro omni and Gemma4 31B, both achieve 30.3%. Among reproducible, human-curated web agent benchmarks, WebArena-Pro provides the broadest application coverage and the most comprehensive multimodal support to date. The benchmark treats audio and video as core observations alongside text and vision, with dedicated actions for extracting information from each. WebArena-Pro runs each task in isolation and supports reproducible, parallel evaluation. Tasks are authored through a dedicated annotator interface, filtered by LLM-assisted triage, and finally validated by humans before release. Project page: https://webarena-pro.github.io

§Introduction (from cached fulltext; cut at ~9000 chars)
Web agents driven by large language and vision-language models have moved quickly from synthetic clicking tasks toward broader browser work, including drafting and triaging messages, updating records in business applications, extracting insight from dashboards, editing media, and coordinating across heterogeneous tools ( Abuelsaad et al., 2024 ; Deng et al., 2023 ; Gur et al., 2023 ; He et al., 2024 ) . A growing body of benchmarks has supported this progress, offering self-hosted web environments ( Zhou et al., 2023 ; hattami et al., 2025 ) , visually grounded tasks ( Koh et al., 2024 ; Miyai et al., 2025 ) , workplace-style scenarios ( Drouin et al., 2024 ; Xu et al., 2025 ) , computer-use settings beyond the browser ( Xie et al., 2024 ) , and increasingly large task pools ( Aggarwal et al., 2026 ) . As models improve and the scope of attempted tasks widens, the design of the evaluation itself becomes a central question. Despite this progress, current self-hosted web-agent benchmarks have limitations relative to the conditions needed for realistic and diverse measurement, as summarized in Table 1 . First, prior self-hosted benchmarks cover only a small number of web applications drawn from a few software categories, which limits the heterogeneity of interfaces, workflows, and data models that an agent encounters during evaluation. Second, modality coverage is limited to text and vision, even though many real browser workflows involve temporal media such as audio and video embedded in web pages. A parallel line of live benchmarks operates on real production websites ( Deng et al., 2023 ; Xue et al., 2025 ; He et al., 2024 ) , broadening site coverage beyond what self-hosted benchmarks offer. However, they sacrifice reproducibility, since pages, content, layouts, and policies drift between runs, making consistent evaluation across rollouts difficult. To this end, we introduce WebArena-Pro , a benchmark for web agents that addresses these limitations. First, addressing the application coverage gap, WebArena-Pro spans 20 self-hosted web applications across six domain categories (productivity, communication, analytics, business operations, design and media, and travel), with applications modeled on widely used services such as Notion, Slack, Spotify, Figma, and Airbnb (Table 2 lists all 20). Second, addressing the modality gap, WebArena-Pro evaluates audio and video as core observations alongside text and vision, exposing media sources through the accessibility tree and providing transcribe() and extract_frames() actions so that agents can incorporate temporal media directly into browser workflows. Third, addressing the reproducibility limitation of live benchmarks, WebArena-Pro runs each task in isolation against per-task seeded container state, supporting reproducible parallel evaluation that avoids drift between runs. WebArena-Pro contains 300 tasks categorized by site coverage (204 single-site, 96 cross-site) and modality (221 text/vision, 79 audio/video), as detailed in Table 3 . Unlike many prior benchmarks that generate many task instances from a small set of templates, each task in WebArena-Pro has its own dedicated template, which yields a more diverse evaluation (Table 1 ). Tasks are authored through a dedicated annotator interface and pass through a two-stage filter, in which LLM-assisted triage flags candidates that appear infeasible or trivial and human reviewers make the final acceptance decision. This pipeline keeps task quality grounded in human judgment while using LLM assistance to scale the authoring process. Our contributions are as follows: • Heterogeneous web coverage. We construct a benchmark of 20 self-hosted web applications across six domain categories with distinct interface conventions, workflows, and data models. • Audio and video as core web observations. We extend the web-agent action and observation space to temporal media, exposing audio and video sources through the accessibility tree and providing transcribe() and extract_frames() actions so that agents can use embedded media directly within browser workflows. Omni agents are provided with listen() and watch() actions. • Reproducible, parallel evaluation. We run each task in isolation against per-task seeded container state, supporting reproducible parallel rollouts and avoiding drift between runs. • Human-validated benchmark construction. We release a task creation pipeline that combines an annotator interface, LLM-assisted infeasibility and triviality triage, and final human validation.
