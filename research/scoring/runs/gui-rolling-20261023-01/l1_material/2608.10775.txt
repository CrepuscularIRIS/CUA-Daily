title: SkillLens: Visual Skill Cards for Retrieval-Augmented GUI Action Prediction and On-Policy Distillation
source: https://arxiv.org/abs/2608.10775

§Abstract
Graphical user interface (GUI) agents can reuse past interaction experience. We study how illustrated procedures support action prediction and students deployed without retrieval. We introduce SkillLens, which represents procedures, applicability cues, and interface views in a shared Visual Skill Card (VSC) schema. Retrieved cards provide a frozen executor with reference evidence alongside the current screen. CardDistill uses this schema to construct privileged teacher context from labeled training steps for on-policy distillation; the student learns from native inputs and requires no retrieval at deployment. With matched training data and update counts, students trained with full-card teachers improve step success rate by an average of 5.04 percentage points over those trained with compact-text teachers across three training seeds on 119 tasks from ten websites absent from training. An independent runtime control uses training-source memory and pre-action retrieval queries: full cards achieve 12/64 correct actions (18.75%) versus 4/64 (6.25%) for text-only cards. These results establish the value of the complete VSC teacher-context package for retrieval-free students and provide evidence for pre-action retrieval of illustrated procedures.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-using agents map requests to actions on graphical user interfaces (GUIs) using vision-language models (VLMs) to interpret screenshots ( OpenAI, 2024 ; Gemini Team, Google, 2025 ; Wang et al., 2024 ; Bai et al., 2025b ; Bai et al., 2025a ) and procedural knowledge to identify operations, applicable states, and signs of progress. Across layouts, agents must ground each action on the live interface ( Figure 2 ). Web agents encounter recurring workflows across websites: finding a product, applying a filter, or completing a form. Reusing these workflows requires both procedural knowledge and action grounding on pages whose controls and layouts change. Reusable skills store procedures ( Chen et al., 2026 ; Xie et al., 2025b ; Hu et al., 2026 ) ; MMSkills and VISUALSKILL attach state information and visual evidence ( Zhang et al., 2026a ; Jiang et al., 2026 ) . We study a memory interface that connects a retrieved procedure to its illustrated page context and supplies both to the agent making the current action decision. This connects reusable web experience to page-level grounding. We also ask whether learning from this interface improves a student’s actions on unseen websites when deployed without skill retrieval. We introduce SkillLens to study how visual skills support action prediction at inference time and through student training. Its Visual Skill Cards (VSCs) pair procedures with interface views and cues for applicability and verification. Trace-to-VSC constructs cards from recorded web actions and desktop grounding examples ( Deng et al., 2023 ; Lù et al., 2024 ; Xie et al., 2025a ) . At inference time, a text index selects relevant cards, whose procedures and visual evidence accompany the live screen. A frozen executor uses this context to predict the current action. To test whether card evidence can also improve a student that acts without retrieval, we further develop CardDistill . It uses the same VSC schema to construct privileged teacher context from labeled training steps. During on-policy distillation, the student generates actions from task context and the live screen, and the teacher uses the additional card evidence to score tokens along these responses. The student learns from these scores and acts without cards. We evaluate both uses of VSCs in offline studies on Multimodal-Mind2Web ( Deng et al., 2023 ; Zheng et al., 2024 ) , WebLINX-BrowserGym (WebLINX-BG) ( Lù et al., 2024 ; Le Sellier de Chezelles et al., 2025 ) , and OSWorld-G ( Xie et al., 2025a ) . Runtime evidence spans benchmark-specific reference protocols and an independent training-source control. Full cards lead both single-modality variants in the Web reference comparisons and yield 12 strict successes versus four for text-only cards in the independent 64-task control. In controlled training, full-card teachers gain 5.04 points in step success rate (Step SR) over compact text across three seeds on 119 tasks from ten training-disjoint websites. In summary, our contributions are threefold: • We propose SkillLens, a VSC memory interface that connects reusable procedures and visual evidence to action prediction by frozen executors. • We develop CardDistill to use the same VSC schema for privileged teacher context and on-policy training of students deployed without card retrieval. • We demonstrate retrieval-free student gains under controlled training across three seeds and on training-disjoint websites, and provide an independent pre-action runtime comparison using training-source memory.
