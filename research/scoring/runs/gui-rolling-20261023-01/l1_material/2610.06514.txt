arxiv: 2610.06514 (2610.06514v1)
title: ANT: A Multi-Granularity Network Traffic Dataset and Benchmark for Agents Behavior Auditing
source: https://arxiv.org/abs/2610.06514

§Abstract
The growing adoption of large language model (LLM) agents creates a need for network administrators and security teams to audit agent behavior within organizational networks without inspecting private user content. Network traffic offers an observable source of evidence, but how much it reveals about agent tasks and operations remains unclear. Existing traffic datasets lack the joint task and stage annotations needed to evaluate this question. We introduce ANT (Agent Network Traffic), a dataset providing agent behavior information at risk, scenario, and behavior primitive granularities alongside network traffic. ANT contains 3,114 execution episodes across 20 tasks and five scenarios, comprising 276,417 bidirectional flows and 40,049 behavior primitive segments organized into 47 macro groups. We establish a benchmark for agent risk identification, scenario recognition, and behavior primitive classification using 13 representative traffic analysis baselines. The results show that existing methods recover useful but uneven behavioral signals. They struggle to identify risk when malicious workflows resemble benign tasks and to distinguish scenarios with similar traffic patterns. Primitive classification is more reliable for frequent macro groups and those with distinctive traffic patterns than for rare or semantically similar groups. ANT provides a common basis for developing more precise auditing and forensic analysis of agent behavior from network traffic. Our data and code are available at https://anonymous.4open.science/r/ant-main-suite-7BC0/.

§Introduction (from cached fulltext; cut at ~9000 chars)
LLM agents are evolving from conversational assistants into systems that can plan, invoke tools, and interact with external environments on users’ behalf, driving their adoption in everyday workflows. However, this adoption has also raised governance concerns. Microsoft reports that 58% of surveyed organizations are concerned about unsanctioned generative AI use, while 57% report an increase in security incidents associated with AI use ( Microsoft, 2024 ; Microsoft, 2025 ) . Since Agent communications are encrypted during transmission, organizations need mechanisms to identify and govern LLM agent use without relying on deep inspection of user content. Encrypted traffic analysis offers a promising way to meet this need. Rather than examining encrypted payloads, these methods infer applications and activities from observable traffic features, such as packet sizes and timing. These signals support application identification, website fingerprinting, malicious traffic detection ( Canadian Institute for Cybersecurity, 2016b ) etc. Zhang et al. (2025a) further show that encrypted traffic can reveal fingerprints of agent interactions. This motivates our central question: To what extent can an agent’s task and behavior be inferred from the network traffic generated during its execution? Answering this question requires accounting for the distinctive structure of LLM agent traffic. Figure 1 illustrates an execution of a question answering task using the Claude Code harness ( Anthropic, 2026 ) and a DeepSeek backend ( DeepSeek-AI et al., 2025 ) . The upper timeline shows the sequence of model calls and tool events, while the lower timeline shows the network flows observed during the same period. At the semantic level, the execution can be partitioned into a sequence of behavior primitives , each of which pursues a coherent subgoal. A behavior primitive typically encompasses communication with the backend model for reasoning and planning, invocation of a selected tool, and analysis of the returned result. Correspondingly, bursts of network traffic appear near the onset of each behavior primitive. Primitives with different subgoals also produce different traffic compositions and interaction patterns. For example, traffic during a WebSearch primitive is dominated by communication with the model backend because Claude Code delegates the search operation to that backend. By contrast, a WebFetch primitive introduces DNS lookups and Web content download flows because the agent retrieves the content of a specified URL. These differences show that network traffic carries signals associated with both an agent execution and its constituent behavior primitives. Systematically evaluating these behavioral signals requires traffic traces paired with annotations of both overall tasks and local execution stages. Existing datasets do not provide the traffic and annotations needed to evaluate agent risk, task scenarios, and behavior primitives. Traditional traffic datasets typically label applications, websites, or fixed workloads, including browsing, chat, and file transfer ( Canadian Institute for Cybersecurity, 2016b ; Canadian Institute for Cybersecurity, 2016a ; Wang et al., 2017 ; Aceto et al., 2019 ; Sirinam et al., 2018 ) . However, they contain neither traffic generated by agent model–tool–environment loops nor descriptions of the corresponding execution stages. AgentPrint identifies agents and coarse activities ( Zhang et al., 2025a ) , but lacks joint annotations for episode risk, task scenarios, and behavior primitives. To close this evaluation gap, we introduce ANT , a dataset for analyzing agent behavior from user-side network traffic. ANT contains 3,114 execution episodes across 20 tasks and five scenarios, covering legitimate applications and cybersecurity misuse. Its 276,417 bidirectional flows are paired with task and runtime metadata. To expose execution semantics, we align traffic with session logs and construct 40,049 behavior primitive segments in 47 primitive macro groups. Meanwhile, we establish a benchmark for evaluating traffic analysis methods on risk identification, scenario recognition, and behavior primitive classification. Although all 13 baselines exceed 0.900 accuracy in risk identification, seven attain malicious class recall below 0.500, reflecting their difficulty in detecting content level misuse. The best baseline for scenario recognition reaches 0.727 accuracy, indicating that scenario semantics are partly recoverable even though similar scenarios remain difficult to distinguish. For behavior primitive classification, existing baselines perform better on frequent macro groups and groups with distinctive traffic patterns, but struggle with rare and semantically similar groups.
