title: ReTTT: Reflection-Driven Test-Time Training via Experience-Based Parametric Memory
source: https://arxiv.org/abs/2610.23942

§Abstract
LLM agents accumulate valuable task-specific information through their actions, observations, and environmental feedback during multi-turn task execution. When effectively used, this information can help agents refine subsequent decisions and improve task performance. However, the learning value of an interaction depends on its context and subsequent feedback, making it challenging to extract reliable, actionable lessons and revise them as the task unfolds. In this paper, we introduce ReTTT, which enables experience-driven self-adaptation through test-time training on lessons constructed and continually revised within an episode. ReTTT lets the agent reflect on interaction feedback, maintain the resulting lessons in an explicit memory, and learn from them by updating an episode-local LoRA adapter while keeping the backbone frozen. The adapted model then performs both subsequent actions and reflection, coupling policy adaptation with the construction of future learning experience. We evaluate ReTTT on ALFWorld, ScienceWorld, and SWE-bench Lite using two model families. ReTTT outperforms trajectory-based test-time training across all six model--benchmark settings, improving task success by up to 12.14 percentage points. A frozen-reflection comparison further shows a 7.14-point benefit from adapting the reflection policy, while trajectory analysis illustrates how adapted reflection derives more task-specific guidance from failed attempts. These findings suggest that learning to reflect on its own behavior can boost agents' performance on long-horizon tasks.

§Introduction (from cached fulltext; cut at ~9000 chars)
Modern large language model (LLM) agents ( liu2024agentbench ) tackle multi-turn tasks, such as software development ( yang2024swe ; jimenez2024swe ) , web navigation ( zhou2024webarena ) , and scientific research ( wang2022scienceworld ) , through an iterative agent loop. The agent alternates between reasoning, taking actions, and receiving environmental feedback, accumulating a trajectory of plans, intermediate reasoning, actions, and observations in its context ( yao2022react ) . This trajectory records action outcomes and task progress, providing task-specific experience that can inform subsequent decisions and learning. A substantial body of work investigates how agents can make better use of this interaction history. Context management methods organize, compress, and retrieve historical information to guide subsequent actions through the input context while keeping model parameters fixed ( park2023generative ; packer2023memgpt ; zhang2026adamem ; mi2026procmem ) . Parametric memory approaches consolidate accumulated experience into learned parameters, allowing information from past trajectories to shape the agent’s policy beyond the immediate context ( yao2026parammem ; ren2026scaling ) . Recently, agentic test-time training (aTTT) has brought parameter adaptation into ongoing task execution, using signals from agent outputs, environmental observations, or generated progress summaries ( wang2026no ) . It downweights repeated token spans to limit redundant self-training while retaining novel information. Each update changes the policy that acts next and thereby shapes the interaction history available for subsequent learning. However, continual parameter updates leave a key question: what should an agent learn from its ongoing interactions? An interaction trajectory records what happened, but useful supervision must capture what should guide future behavior. Failure feedback, for example, can turn an unsuccessful action into a lesson about prerequisites for subsequent attempts(Figure 1 a). New observations can also revise earlier conclusions, requiring the supervision used for later updates to change as the task unfolds. The challenge is therefore to continually derive reliable, decision-relevant lessons from the trajectory and use them to adapt the policy within the same episode. To investigate the limitations of agentic test-time training over longer task horizons, we analyze aTTT’s performance and execution errors. Its improvement over the frozen policy falls from 16.7 percentage points on short tasks to 6.4 on medium tasks and disappears on long tasks (Figure 1 c). Meanwhile, aTTT’s off-goal error proxy, measured as placements of target objects at non-goal locations per 100 tasks, rises from 5.6 to 17.0 and 38.7 across these groups (Figure 1 d). These findings suggest that accumulating more interaction data does not necessarily provide better learning supervision, motivating the explicit construction and revision of task-relevant lessons before parameter updates. To address these challenges, we introduce ReTTT(Figure 1 b), which couples the construction and revision of learning experience with policy adaptation through test-time training. The same adapted model acts in the environment and constructs the lessons used for later updates within the ongoing episode. At periodic reflection steps, it interprets interaction feedback to extract task-relevant lessons, including action prerequisites, failure conditions, and guidance for remaining subgoals. These lessons are checked against interaction evidence and maintained in an explicit memory that is revised as new information arrives. New and revised lessons, together with selected prior experience, are then used to update an episode-local LoRA adapter through test-time training, while the backbone remains frozen. We instantiate these lessons as question–answer pairs (ReTTT-QA) and structured summaries (ReTTT-Sum). We evaluate ReTTT on ALFWorld, ScienceWorld, and SWE-bench Lite using Qwen3.5-9B and Gemma4-12B. Both ReTTT-QA and ReTTT-Sum outperform aTTT in all six model–benchmark settings (Table 1 ). With Qwen3.5-9B, ReTTT-QA improves success over aTTT by 12.14, 11.67, and 3.33 percentage points on the three benchmarks, respectively. On ALFWorld, ReTTT-QA’s advantage over aTTT grows from 5.6 percentage points on short tasks to 14.7 on long tasks, grouped by reference action count (Table 2 ). Further analysis examines how adapting the reflection policy contributes to these improvements. On ALFWorld with Qwen3.5-9B, ReTTT-QA achieves 63.57% success, compared with 56.43% when the reflection policy remains frozen while action-policy adaptation is retained (Section 3.4 ). A trajectory-level example illustrates the difference: with the same interaction history, the adapted reflector derives task-specific search guidance from failed attempts, while the frozen reflector repeats generic advice (Figure 4 ).
