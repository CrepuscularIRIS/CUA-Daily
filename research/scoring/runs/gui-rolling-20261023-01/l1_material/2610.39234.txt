title: AgentHeal: Evaluating Goal-Preserving Resource Recovery of Web Agents under Access Barriers
source: https://arxiv.org/abs/2610.39234

§Abstract
Large language model (LLM) agents have demonstrated strong capabilities in automating complex information-seeking and transactional tasks across the open web. However, their real-world reliability remains limited by access barriers, such as dead links, authentication walls, rate limits, and anti-scraping defenses. These barriers block the primary execution path, causing agents to abort prematurely, loop indefinitely, or quietly compromise the user's original constraints. Existing evaluations either implicitly assume that target resources are freely accessible or focus on transient perturbations that simple retries can resolve, failing to capture scenarios where agents must actively reroute around impassable bottlenecks. To bridge this gap, this paper introduces AgentHeal, a comprehensive benchmark evaluating goal-preserving resource recovery, defined as the ability of web agents to detect non-transient access barriers, pivot to legitimate alternative sources, and fulfill the user's exact original objective. Spanning nine barrier families across a counterfactual sandbox and real-website replay, our experiments on leading LLM backbones show that average task success drops sharply from 89.4% to 43.7% under access barriers. Further analysis reveals that agents frequently fall for deceptive look-alikes, fail to escalate to users when necessary, violate access policies, or waste computation on futile retries, providing actionable diagnostics for developing resilient web agents.

§Introduction (from cached fulltext; cut at ~9000 chars)
Recent advancements in LLMs have catalyzed a paradigm shift from passive text generators to autonomous agents capable of complex reasoning, planning, and tool use ( Yao et al., 2022b ; Schick et al., 2023 ) . Within this landscape, web agents have emerged as a particularly promising frontier. By automating multi-step digital workflows, such as open-ended information retrieval, cross-platform navigation, and online decision-making, these systems are increasingly deployed across the open web as autonomous research assistants, browser extensions, and command-line tools ( Nakano et al., 2021 ; Zhou et al., 2024 ; Drouin et al., 2024 ) . To systematically evaluate and advance these capabilities, a progression of foundational benchmarks has emerged. Early efforts such as WebShop ( Yao et al., 2022a ) established a simulated e-commerce environment for grounding language instructions into web actions. Subsequent benchmarks including Mind2Web ( Deng et al., 2023 ) , WebArena ( Zhou et al., 2024 ) , and VisualWebArena ( Koh et al., 2024a ) expanded evaluation to realistic, multi-step tasks across diverse, functional websites. Most recently, BrowseComp ( Wei et al., 2025 ; Chen et al., 2026 ) and BEARCUBS ( Song et al., 2025 ) challenge agents to locate hard-to-find information directly on the live web, substantially raising the bar for generalist web navigation. Despite their increasing realism, existing benchmarks largely operate under an implicit Idealized Reachability Assumption –the premise that the target webpage or primary information source required to fulfill a user’s instruction is perpetually accessible and functional. In the wild, however, the open web is inherently dynamic, fragmented, and adversarial, which makes the assumption unrealistic. Autonomous agents frequently encounter hard access barriers, including subscription paywalls, anti-bot CAPTCHAs, geographic restrictions, rate-limiting blocks (e.g., HTTP 403/429), and link rot (e.g., HTTP 404 or deprecated pages). While recent stress-testing and robustness studies have examined agent resilience against UI layout perturbations, pop-up distractions, or adversarial prompt injections ( Kara et al., 2025 ; Wang et al., 2026 ; Bai et al., 2026 ) , they fundamentally overlook scenarios where the primary resource itself becomes completely unreachable, simply retrying is infeasible and the agent must instead identify an alternative route that still satisfies the user’s original request. Consequently, we argue that a fundamental gap exists between static, controlled benchmark evaluations and the unpredictable reality of open-world web deployment. Even on the live web, existing benchmarks usually assume “happy-path” execution where target pages remain intact and accessible. In practice, humans rarely abandon a task when they encounter a broken link or a paywalled article. Instead, they naturally adapt by reformulating search queries, consulting cached archives, or cross-referencing alternative repositories. Current web agents, by contrast, often become trapped in repetitive action loops or hallucinate unverified answers when their primary trajectory is blocked. We formalize this missing competency as Autonomous Self-Healing : the ability of an agent to diagnose terminal access failures, dynamically reroute to legitimate alternative sources, rigorously audit cross-source factual consistency, and abstain honestly when no viable substitute exists. Bridging this gap necessitates a dedicated evaluation paradigm that moves beyond idealized “happy-path” execution. To this end, this work investigates how modern web agents behave under resource-blocked conditions by addressing three core research questions: (1) Capability: When obstructed by unexpected access barriers on a primary target, can an agent autonomously pivot and discover alternative resources to successfully complete the task? (2) Reliability: Can the agent critically audit the authenticity and relevance of candidate alternative resources (e.g., avoiding outdated or spurious mirrors), and honestly report task infeasibility rather than hallucinating when no valid alternatives exist? (3) Efficiency: How many interaction steps does an agent require to either successfully recover via an alternative path or decisively terminate an unsolvable task without wasting computation in futile retries? However, constructing a rigorous benchmark to evaluate these dimensions presents three non-trivial challenges: (i) Controllable and Reproducible Obstruction: Real-world web blocks (e.g., dynamic CAPTCHAs or temporary server outages) are stochastic and ephemeral, making it difficult to ensure deterministic, reproducible evaluation across different models and time periods. (ii) Multi-Path Ground-Truth Verification: Once an agent deviates from the blocked primary source, the space of valid trajectories expands exponentially.
