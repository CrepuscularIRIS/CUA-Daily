title: ScienceCUA: Resource-to-Skill Construction and Execution-Guided Skill Evolution for Scientific Computer Use Agents
source: https://arxiv.org/abs/2611.03238

§Abstract
Computer-use agents for scientific software require application-specific expertise. Much of this expertise is documented in human-authored software manuals and web pages. However, turning these resources into executable, reusable skills remains challenging due to mismatches between documented and deployed software versions and differences in scope between documentation coverage and task requirements. We introduce ScienceCUA, a two-stage framework combining resource-to-skill construction with execution-guided skill evolution. First, ScienceCUA identifies tasks supported by the software from its documentation, infers operational trajectories, and generalizes them into reusable Skills. Command catalogs, syntax constraints, and shortcuts are organized separately as References for on-demand lookup. Then, ScienceCUA uses execution feedback to drive skill self-evolution by contrasting successful and failed trajectories for the same task, identifying deficiencies, revising existing skills or adding new ones, and updating the skill library only after repeated validation in real environments. To enable reliable evaluation without benchmark noise or task leakage, we introduce two improved benchmarks. ScienceBoard-Verified provides an audited and corrected basis for measuring task performance, while ScienceBoard-VE separates skill evolution from final testing through disjoint evolution and test tasks and further supports native-agent evaluation. Experiments show that the initial Skills and References improve average task success rate by up to 7.23 percentage points over the base model, while skill self-evolution increases the total gain over the baseline to as much as 17.12 percentage points. ScienceCUA turns software documentation into an evolving set of executable skills and queryable references, offering a practical way for general-purpose agents to use scientific software reliably and at scale.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-use agents (CUAs) built on foundation models can now execute multi-step tasks through graphical and command-line interfaces ( Qin et al., 2025 ; Sager et al., 2026 ; Xie et al., 2024 ) . Most existing benchmarks, including WebArena, OSWorld, and Windows Agent Arena, focus on general-purpose web, office, and desktop tasks, while scientific software has received comparatively less attention ( Xie et al., 2024 ; Zhou et al., 2024 ; Bonatti et al., 2024 ; Sun et al., 2026 ) . Scientific software is widely used for experiments, simulations, and data analysis, but operating these tools often requires application-specific workflows, commands, syntax, and parameter constraints ( Sun et al., 2026 ; Ai et al., 2026 ) . To complete scientific-software tasks, agents must use software-specific knowledge to select appropriate operations and organize them into effective workflows ( Shao et al., 2026 ) . We study this problem using ScienceBoard ( Sun et al., 2026 ) , which evaluates CUAs on six scientific applications. Figure 2 (a) shows that each application provides user manuals or official tutorials containing application-specific knowledge. However, Figure 2 (d) shows that directly placing these resources in the model context yields only limited gains in task success while substantially increasing execution time. Figure 2 (b) illustrates that human-authored documentation mixes operational instructions with conceptual explanations and other narrative content. A particular task, however, typically depends on only a small fraction of the available information, as shown in Figure 2 (c). The central question is how to extract task-relevant information from these human-oriented resources and organize it as structured knowledge that the model can use effectively. Prior work has constructed reusable skills from human-created resources for content creation, gaming, software operation, and related applications ( Fan et al., 2026 ; Che et al., 2026 ; Jiang et al., 2026 ; Shen et al., 2026 ) . For scientific software, these resources must supply two kinds of knowledge with different lifetimes: procedural guidance for a specific task, and shared software knowledge queried on demand. We therefore introduce ScienceCUA, which extracts task-oriented procedural knowledge and cross-task shared software knowledge from raw software resources, organizes them as Skills and References, respectively, and combines them on demand during execution. However, the initial Skills and References constructed from raw resources have inherent limitations. First, the available PDF or HTML resources may not match the version of the software deployed in the execution environment, since perfectly matched resources are not always available. Second, for some applications, the resource coverage is broader than the range of tasks being evaluated, while the task scope is unknown during construction. The resulting knowledge library therefore contains many entries that are irrelevant to the evaluation tasks, reducing the density of useful information. Third, some task requirements may fall outside the coverage of the resources themselves. To address these limitations, ScienceCUA drives the continual evolution of Skills and References through execution feedback. Prior work has used task feedback and execution trajectories to build reflective memory, optimize external skills, or adapt agent behavior ( Shinn et al., 2023 ; Zhao et al., 2024 ; Ni et al., 2026 ; Liu et al., 2026 ; Yang et al., 2026 ; Chen et al., 2026 ; Zhang et al., 2026 ; Sun et al., 2025 ) . In contrast, ScienceCUA improves a scientific-software knowledge library initialized from software resources, using historical failure trajectories to guide subsequent exploration and help agents avoid repeating failed paths or continuing to follow potentially erroneous Skills and References; when knowledge is insufficient, it revisits the original resources to retrieve and construct task-relevant Skills or References. Combined with on-demand composition, this design both helps agents bypass ineffective paths caused by version mismatch and, where the original resources support it, supplements omitted or overly general knowledge in the initial library, thereby reducing the mismatch between the resources and the actual tasks. Candidate updates are added only after independent validation in the target environment. To support reliable evaluation, we audit and repair ScienceBoard to create ScienceBoard-Verified. We also add a set of tasks that do not overlap with the final test tasks, use them exclusively for skill evolution, and combine the audited benchmark and the new tasks into ScienceBoard-VE; in addition, we extend the evaluation framework to support native agents. Across six scientific applications, the initial Skills and References improve the average task success rate over the base model by up to 7.23 percentage points.
