title: From Interaction to Capability: Task Advancement as State and Supervision for GUI Agents
source: https://arxiv.org/abs/2610.37482

§Abstract
GUI memory should preserve the results of past actions and learn reusable operations. This is difficult in long-horizon workflows, where agents must use information across applications and useful operations are interleaved with failed attempts. We introduce Task Advancement Memory (TAM), which defines task advancement as verified task progress, and supports ongoing task execution and learns reusable operations. During execution, Task Advancement State represents how verified task progress changes the remaining goals, allowing the agent to build on earlier achievements across applications. After each task, advancement supervision identifies and abstracts the interactions that produced a verified local result. The learned operations preserve the relation between required inputs, expected outcomes, and verification conditions. This retains locally successful operations from both successful and failed tasks. On MobileWorld GUI-only tasks, Advancement State alone raises success from 12.0% to 28.2%. Full TAM achieves a 17.6% relative gain in task success over the strongest evaluated baseline and reduces lifecycle tokens per solved task by 38.7%. On SPA-Bench, TAM achieves state-of-the-art task success in the single-app English Level 3 setting.

§Introduction (from cached fulltext; cut at ~9000 chars)
GUI agents should complete workflows whose information and effects are distributed across screens and applications. Long interaction histories mix completed work with attempts and productive actions with detours, leaving the agent to reconstruct how far the task has advanced and what remains to be done. For example, after confirming a calendar event, an agent should proceed to notifying participants using the event details it has already read. Therefore, memory should represent how completed work changes the remaining task. Recent methods improve the information available to the agent through context management, program-guided execution, and verified task state ( Yang et al., 2025 ; Tian et al., 2026 ; Liu et al., 2026a ; Zheng et al., 2026 ; Wu et al., 2026 ; Liu et al., 2026b ) . Trajectory exemplars, induced workflows, and experience memories also transfer knowledge to later tasks ( Zheng et al., 2024b ; Wang et al., 2025b ; Wang et al., 2025a ; Xiao et al., 2026 ; Ouyang et al., 2026 ) . These approaches address how memory can help an agent complete remaining goals and how successful interactions can become reusable operations. However, agents still struggle to apply correctly acquired information to later goals across applications. Workflow memories tied to historical action sequences also leave the agent to adapt past routes when the interface changes. A task’s final outcome also gives incomplete feedback about intermediate operations, a failed task can contain useful successes, while a successful task can include ineffective attempts. We propose Task Advancement Memory (TAM), a memory framework that uses task progress to guide execution and learning. A task advancement occurs when GUI observations confirm that a previously unresolved requirement is satisfied, either by obtaining required information or by achieving a requested outcome. Each advancement reduces what the agent still needs to determine or accomplish. We call this task reduction . For online execution, Task Advancement State makes earlier advancements usable by later goals. It shows what information is available for each remaining goal and which goals are ready to pursue. TAM uses each advancement to supervise the selection and abstraction of productive interactions. The learned operations specify the inputs needed at entry, the result to achieve, and how to verify it. This retains useful capabilities from productive portions of both successful and failed workflows. Figure 1 illustrates these two uses of task advancement. We evaluate TAM on the GUI-only subset of MobileWorld ( Kong et al., 2026 ) and the Level-3 English subset of SPA-Bench ( Chen et al., 2025 ) . With Qwen3-VL-32B-Instruct used by every listed MobileWorld method, TAM improves success from 29.1% for the strongest evaluated memory baseline to 34.2%. With GPT-4o in the SPA-Bench English Level 3 setting, it reaches 57.0%, the highest success rate in the reported comparison. Our contributions are as follows: • We introduce Task Advancement State within TAM to guide execution across applications. It represents the remaining task in terms of satisfied requirements, available inputs, and unresolved dependencies. This lets the agent build on earlier advancements when choosing its next action. • We propose advancement supervision , which converts partial task success into capabilities that can be reused in subsequent tasks. Each learned operation specifies what it needs, what it should achieve, and how to verify the outcome. • We show that TAM outperforms the evaluated memory baselines in task success on MobileWorld and SPA-Bench. Cross-benchmark comparisons, component ablations, and cost analyses establish the value of task-state memory and the additional benefit of persistent operators.
