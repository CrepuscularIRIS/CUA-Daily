title: InterWebCoder: Learning Interactive Webpage Generation from Executable Tests via Reinforcement Learning
source: https://arxiv.org/abs/2610.28610

§Abstract
Interactive webpages underpin modern applications, but reproducing both their visual appearance and multi-step behavior remains challenging for multimodal large language models (MLLMs). Scalable training data must capture user actions, state transitions, and expected outcomes, while real-world webpage code is often entangled with irrelevant scripts and external dependencies. Moreover, existing GUI-agent-based verification provides slow and potentially unstable functional feedback. To address these challenges, we propose InterWebCoder, an efficient framework for interactive webpage code generation. InterWebCoder introduces a Test-Specification-Guided and Execution-Verified Data Synthesis pipeline that records real-world interaction trajectories and synthesizes self-contained webpage code with executable test scripts. A failureattributed repair mechanism uses runtime evidence to locate and iteratively fix errors in either the webpage code or test script. We then combine test-ID-weighted supervised fine-tuning with group-relative policy optimization, directly optimizing functional correctness and visual fidelity using test pass rates and state-level visual similarity. This replaces costly GUI-agent verification with fast, reproducible executable feedback. Our pipeline produces 1,736 verified samples from 2,058 tasks, achieving an 84.35% synthesis success rate. On IWR-Bench and Vision2Web, InterWebCoder achieves final scores of 48.54 and 48.42 with a 9B backbone, outperforming 30B-level models and Gemini-3.7-Flash while remaining competitive with Claude-Sonnet-5. It reduces reward-computation latency by over 97%, eliminates external MLLM verification costs, and accelerates end-to-end training by up to 1.4x.

§Introduction (from cached fulltext; cut at ~9000 chars)
Websites have become an indispensable interface through which people access information, communicate with others, and interact with digital services. However, developing a high-quality website remains a time-consuming and labor-intensive process, requiring developers to translate design specifications into executable code while carefully maintaining visual fidelity ( Liu et al., 2025 ) , functional correctness ( Xiao et al., 2025a ) , and cross-component consistency. Multimodal Large Language Models (MLLMs) have demonstrated strong vision-language understanding capabilities, driving growing interest in UI-to-code generation. Representative methods include DCGen ( Wan et al., 2025 ) for modular decomposition, DeclarUI ( Zhou et al., 2025 ) for segmentation and transition modeling, UICopilot ( Gui et al., 2025c ) for hierarchical generation, and LatCoder ( Gui et al., 2025b ) for layout-aware reconstruction. While these methods primarily reconstruct individual UI states, real-world web applications involve interactions that connect multiple states. Interactive webpage generation ( Xiao et al., 2025a ; Chen et al., 2026 ) therefore aims to translate a task instruction and a sequence of visual interaction states into executable HTML, CSS, and JavaScript. Each state captures the webpage before or after a user action, such as clicking a button, entering text, or selecting an option. The generated code must reproduce not only the appearance of each state but also the interaction logic governing the transitions between them. However, learning these visual and behavioral requirements jointly, introduces substantial challenges in data construction and model training. First, constructing large-scale, high-quality training data is difficult. Unlike static UI2Code data, interactive examples must capture user actions, state transitions, and expected outcomes. On the interaction side, constructing multi-state prototypes requires costly human annotation of user actions, state transitions, and expected outcomes ( Xiao et al., 2025a ; Chen et al., 2026 ) . On the code side, real-world webpages are entangled with irrelevant scripts and external dependencies ( Gui et al., 2025a ) , making it difficult to obtain clean, self-contained training targets. Second, obtaining reliable functional feedback is costly and time-consuming. MLLMs have demonstrated the ability to perform GUI testing ( Teoh et al., 2026 ) . Existing interactive webpage generation methods such as TDDev ( Wan et al., 2026 ) and WebGen-Agent ( Lu et al., 2026 ) similarly employ GUI agents to execute and verify multi-step interactions. However, this process requires repeated, time-consuming MLLM calls and remains vulnerable to errors in visual grounding, action execution, and state interpretation. We provide a detailed empirical analysis of these two challenges in Section 2.3 . To address these challenges, we propose InterWebCoder, an efficient data synthesis and training framework for interactive webpage generation. First, we introduce a Test-Specification-Guided and Execution-Verified Data Synthesis (TEDS) pipeline . TEDS uses a GUI agent to interact with real websites and automatically records the actions and resulting visual states. The recorded actions define the required operations, while the observed state changes provide the expected outcomes for constructing the test specification. Because real-world source code is often inaccessible, noisy, and dependent on external services, a coding agent reconstructs a clean, self-contained webpage and generates a corresponding executable test script. TEDS executes the script on the synthesized webpage and verifies the result by checking both its assertions and the visual similarity between the recorded and replayed states. When verification fails, a failure-attributed repair mechanism determines whether the error originates from the webpage code or the test script and repairs the identified source of failure.This pipeline constructs verified training samples without manually implementing webpages, writing tests, or labeling execution outcomes. Second, we propose a Test-Driven Reinforcement Learning (TDRL) framework that uses executable test scripts to provide deterministic rewards, replacing costly and unstable GUI-agent verification. Supervised fine-tuning primarily learns token-level code patterns and does not explicitly determine whether the generated interactions execute correctly. TDRL executes the tests generated by TEDS on each webpage and provides reproducible rewards based on the proportion of passed test steps and the visual similarity between the rendered and reference states. Consequently, TEDS addresses the shortage of clean, behaviorally verified training data, while TDRL provides an efficient mechanism for learning from such data and directly optimizing functional correctness and visual fidelity.
