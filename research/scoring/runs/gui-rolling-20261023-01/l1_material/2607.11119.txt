title: VIA: Visual Interface Agent for Robot Control
source: https://arxiv.org/abs/2607.11119

§Abstract
Robot manipulation is a complex task that requires visual perception, physical reasoning, planning, and closed-loop control. General-purpose foundation models (FMs) have grown remarkably capable of some of these, especially perception and reasoning. Inspired by the growing ability of FM-powered agents to operate software through visual interfaces, we ask whether that same competence suffices to control a robot directly given the right interface. We present VIA (Visual Interface Agent), a framework that recasts robot control as an agentic task where an off-the-shelf agent drives a manipulator directly through an interface. The interface is a virtual workspace of interactable visual components where the agent can probe pixels of interest with mouse-like tools and command a virtual end-effector to set new target poses with a small set of general tools. We show that VIA enables agents of varying capabilities to perform diverse tabletop manipulation tasks in simulation. We also use VIA to drive an off-the-shelf mobile manipulation robot in the real world to complete tasks that require both navigation and manipulation. Both settings are zero-shot, requiring no robot training or additional action primitives. Performance scales well with the size and strength of the underlying FMs. These results suggest that frontier agents already possess skills that transfer directly to robot control given the right interface: your coding or computer-use agent is, in a sense, secretly a robot-control agent.

§Introduction (from cached fulltext; cut at ~9000 chars)
General robot manipulation is a long-standing research goal at the intersection of robotics and learning. It requires policies that are capable of complex visual understanding, physical reasoning, long-term planning, and precise closed-loop control. Foundation models (FMs) ( Radford et al., 2019 ; Bommasani and others, 2021 ; OpenAI, 2023 ) trained on internet-scale data have become remarkably capable of several of these, such as visual perception and reasoning, which has made leveraging them for robotic manipulation highly attractive. One approach for this is to convert existing vision-language models into vision-language-action (VLA) models, by fine-tuning them on robot data to produce low-level actions ( Zitkovich and others, 2023 ; Black et al., 2025 ) . However, due to a lack of both compute and robot-specific data, VLAs are often orders of magnitude smaller than frontier FMs. This gap has a profound impact on capabilities, particularly the physical reasoning and long-horizon planning skills that current robot policies lack. Another paradigm is Code-as-Policies (CaP) ( Liang et al., 2023 ; Singh et al., 2023 ) , where FMs generate programs to control robots using perception APIs and hand-crafted skill primitives, e.g., mask = segment_text_prompt("green cube") , grasp_pose = sample_grasp_pose("red cube") ( Fu et al., 2026 ) . Although this is a natural way to tap into the strong coding capabilities of FMs, the FMs are not directly involved during rollouts. Therefore, the system is often bottlenecked by human-crafted perception and action abstractions rather than by the FM. We propose a new way to connect FMs to robot manipulation: recasting robot control as a visual tool-use task for agents by introducing a virtual workspace that the agent can probe and interact with, similar to general computer use. Agents ( Yao et al., 2023 ) wrap FMs with harnesses to enable better performance on long-horizon tasks ( Yang et al., 2024 ; Jimenez et al., 2024 ) , as well as closed-loop control of software or games in virtual environments ( Anthropic, 2025a ) . Frontier agents can now operate real software through native screenshots, clicking, and keyboard operations ( Shi et al., 2017 ; Anthropic, 2024a ; OpenAI, 2025b ) . They perform long-horizon tasks in a closed-loop manner, iteratively observing, planning, and executing, remarkably similar to what we want from robot policies. Therefore, we ask: given the right visual interface and human-legible tools, can a state-of-the-art agent control a robot without any robot-specific adaptation? We present VIA ( V isual I nterface A gent), a framework for robot control that lets off-the-shelf visual agents drive robot manipulators through an interface ( Fig. 1 ) and a controller. The interface is a virtual workspace where the agent interacts with the scene, staging and refining controller commands without affecting the real environment. The core component is a virtual target gripper that the agent can move around with a small set of human-legible Model Context Protocol (MCP) tools ( Anthropic, 2024b ) , much as a human would pose an object in 3D design software such as Blender. Through the interface, the agent reasons about the scene, issues MCP tool calls, and inspects their visual effects to refine the target gripper’s state until satisfied. The agent submits the refined target gripper state to the controller as a waypoint , and the controller moves the real gripper to that target. The agent then observes the updated scene and plans the next waypoint, repeating until the task is complete. We evaluate VIA with two frontier agents, Claude Code ( Anthropic, 2025b ) and Codex ( OpenAI, 2025a ) , across various model tiers. Our evaluation suite includes six simulated tabletop manipulation tasks and five real-world mobile manipulation tasks, spanning pick-and-place, articulated objects, precise execution, and long-horizon multi-object assembly. VIA achieves strong results, solving these tasks end-to-end in a zero-shot setting with high success rates at an estimated API cost of a few dollars per successful episode on most tasks. We show that VIA ’s performance scales well with the underlying model capacity, achieving success rates of 38\% , 73\% , and 100\% with Codex using Terra 5.6, Sol 5.6, and Astra 6, respectively, and showing a similar trend for Claude Code. VIA can also consume demonstrations written as plain text: providing a list of example waypoints increases VIA ’s success rate with Claude Code from 62\% to 76\% and with Codex from 68\% to 74\% on simulated tasks. VIA opens up a new opportunity for leveraging state-of-the-art FMs at scale in robotics and demonstrates that, with the right interface, robot control can become another economically valuable agentic task that benefits directly from modern models and agents.
