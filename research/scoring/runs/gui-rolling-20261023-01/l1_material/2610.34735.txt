title: iPrefBench: A User-Centric Benchmark for Personalized Mobile Use Agents
source: https://arxiv.org/abs/2610.34735

§Abstract
An agent that truly knows and acts on behalf of its user has been a long-standing promise of AI assistants. Computer-use agents bring this promise within reach by capably executing fully specified tasks across apps. However, real-world user requests are often underspecified. To act correctly for the particular user, an agent must infer some missing information from the user's activity history and ask for other information that only the user can provide, without making unsupported assumptions or burdening the user with unnecessary questions. We present iPrefBench, a benchmark for evaluating the infer and ask capabilities of personal mobile-use agents in an executable iOS environment with an interactive simulated user. Grounded in a coherent persona with 3,051 past activity events, iPrefBench comprises 130 underspecified user tasks across 26 apps. Each omitted user-dependent requirement is, by construction, either history-inferable or ask-only. iPrefBench evaluates personalized mobile agents on both whether agents complete tasks correctly for the user (i.e., personalized task completion) and whether they seek user input when necessary (i.e., user-agent interaction). Evaluation of 7 frontier agents reveals a substantial gap between execution and personalization. Agents achieve high action completion scores (up to 91.6%) but low full task success (up to 47.7%) because personalization lags behind. They especially struggle with ask-only information, failing to request enough necessary information. Our findings highlight a challenge for personalized agents in knowing what to infer and when to ask. We hope that iPrefBench can serve as a valuable testbed for building agents that know their user and work with them.

§Introduction (from cached fulltext; cut at ~9000 chars)
It has been a long-standing goal in Artificial Intelligence and Human-Computer Interaction to develop agents that can understand and act on behalf of users ( Maes and Kozierok, 1993 ; Lieberman, 1997 ; Horvitz, 1999 ) . Recent computer-use agents (CUAs) have made rapid progress in completing digital tasks across apps and over long horizons ( Xie et al., 2024 ; Yuan et al., 2026 ; Rawles et al., 2025 ; Ye et al., 2025 ) . These agents often excel at fully specified tasks (e.g., “make a reservation at Harborline Seafood tomorrow at 7:30 PM for a party of four.”). However, realistic user queries rarely provide complete details, and are often underspecified ( Völkel et al., 2021 ) . For example, a user may say “book me my usual restaurant for tomorrow” instead of specifying the restaurant name, reservation time, and party size. Contending with such underspecified tasks requires personalization capabilities, in which an agent resolves missing information in two ways: infer from knowledge of the user (e.g., the user’s usual restaurant from past reservations and orders), and ask for details that the available history does not establish (e.g., the desired time and party size). An agent that silently makes unsupported assumptions can diverge from a user’s actual intent, while an agent that asks for details already inferable from the user’s history defeats the purpose of autonomy. A truly useful personal agent must reason not only about what information is missing, but also where it should come from. Yet this challenge is not fully captured by existing evaluations. Typical CUA benchmarks fully specify every task and cold-start agents without any knowledge of the user ( Xie et al., 2024 ; Rawles et al., 2025 ; Zhou et al., 2024 ) , leaving nothing to infer or ask. Benchmarks with underspecified tasks usually supply only one resolution source: personalization benchmarks expose a user history but offer no one to ask ( Lyu et al., 2026 ; Yang et al., 2025 ) , while interactive benchmarks provide a simulated user but no user history that would make some questions unnecessary ( Yao et al., 2024 ; Vijayvargiya et al., 2026 ) . Some provide both ( Chen et al., 2026b ; Chen et al., 2026c ) , but do not distinguish which missing details should be inferred and which require clarification. Therefore, they cannot measure whether the agent knows what to infer and when to ask. To bridge the gap, we present iPrefBench, a benchmark designed around the infer-and-ask capabilities of personalized mobile-use agents in an executable iOS environment. As shown in Figure 1 , agents can know about the user through two sources: an activity history, provided as their only prior context, and a simulated user, reachable through an ask_user action, who answers clarification questions. Both are grounded in rich seeded data around one coherent persona in the environment. iPrefBench comprises 130 underspecified tasks, and each omitted detail is designed to be either inferable (i.e., grounded in specific evidence in activity history) or ask-only (i.e., held solely by the simulated user). To further assess whether agents can apply historical preferences appropriately in challenging real-world scenarios, we include tasks in which current instructions override past patterns, recent behavior indicates changing preferences, or preferred options are unavailable. iPrefBench assesses both whether agents complete tasks correctly for the user (i.e., personalized task completion ) and whether they seek user input when necessary (i.e., user-agent interaction ). Personalized task completion is measured by task-specific rubrics, split into two types: action-completion criteria measure whether required operations were successfully executed (e.g., a restaurant reservation was made), while personalization criteria measure whether each user-dependent decision matches the intended values (e.g., the restaurant, time, and party size). However, correct outcomes alone do not establish user satisfaction: an agent may succeed by interrogating the user about every detail, or luckily guessing the ask-only information correctly. Therefore, inspired by Grice’s maxims ( Grice et al., 1975 ) , we also evaluate user-agent interaction through recall and precision on ask-only information: recall measures whether the agent elicits all required ask-only information, while precision measures whether its requests obtain new ask-only information rather than ask for inferable or irrelevant details or repeat earlier requests. We evaluate seven frontier agents on iPrefBench. The results reveal a substantial gap between executing a task successfully and personalizing it for a particular user. Although Claude Opus 5, the best-performing agent evaluated, achieves a 91.6 % action-completion score, its task success rate is only 47.7 % because personalization lags behind.
