title: MARC: Mechanism-Aware Reflective Correction for Articulated Object Code Generation
source: https://arxiv.org/abs/2610.33060

§Abstract
Generating an articulated object from images and text requires more than plausible parts and movable joints: the assembled mechanism must execute the intended motion. This is particularly challenging for closed-chain and coupled mechanisms, where an error in one connection can block motion or separate connected parts. We introduce MARC, Mechanism-Aware Reflective Correction, which shares an executable kinematic graph across program construction, motion solving, and correction. The graph binds physical connections to local attachment frames and represents loop closures and joint-coordinate couplings. Given prescribed driver inputs, a numerical solver computes follower motion and associates errors with specific connections and configurations. The agent uses these diagnostics to probe possible causes, revise connections or geometry, and retest the mechanism along the original motion paths. On a 20-object test set, MARC with Kimi-K3 achieves 67.8% valid motion coverage and 60.0% overall success, outperforming six baselines. Starting from the same initial candidates, correction improves these scores by 13.7 and 20.0 percentage points, respectively. Ablations further show the benefits of graph-based mechanism support and graph-guided repair. Project homepage: https://demianmusk.github.io/MARC-Home/.

§Introduction (from cached fulltext; cut at ~9000 chars)
Articulated 3D assets are used in robot learning, manipulation planning, and interactive simulation ( Xiang et al., 2020 ) . Their usefulness depends on how connected parts move together. This becomes particularly challenging when connections form closed loops or joint motions depend on one another. Consider a scissor lift: a single driving input must rotate several links and raise the platform while keeping the hinged connections intact. Generating such an asset from images and text therefore requires specifying both its geometry and the relationships that coordinate its motion. A model can match the reference in a static pose yet lock, collide, or separate when driven. The central challenge is therefore to coordinate geometry and connections so that the complete mechanism can realize the requested motion. Existing methods have made progress in generating part geometry and articulation structure ( Liu et al., 2024 ; Wang et al., 2026a ) . Program-generating agents further express asset construction as editable code and iteratively revise it through execution, inspection, and feedback. Articraft provides an SDK for geometry and articulation authoring together with structured validation ( Zhou et al., 2026 ) , while Procedura and aDSL combine assembly or spatial relations with execution feedback and visual assessment to identify and correct generated defects ( Lin et al., 2026 ; Wang et al., 2026b ) . However, for closed-chain and coupled structures, code generation and correction require considering several interdependent connections together. For example, a blocked follower joint may be caused by misplaced attachments, an overly restrictive joint limit, or interference between parts. To choose an effective edit, the agent must connect the observed failure to the mechanism entities involved and account for how the change affects the rest of the assembly. We introduce MARC , Mechanism-Aware Reflective Correction, an agent harness built around an executable kinematic graph for generating articulated-object programs from images and text. Its central design shares this graph across construction, motion solving, and correction. Our mechanism-authoring interface lets the agent specify rigid bodies, physical connections, loop closures, and joint-coordinate couplings. An SDK and its usage instructions expose this interface to the agent. Each connection binds local attachment frames, or sockets, to the participating bodies. Numerical tools translate these declarations into kinematic constraints, solve follower motion for prescribed driver inputs, and report errors at the relevant bodies, joints, sockets, and configurations. The agent then probes possible causes and revises the affected connections or geometry. A change to linkage-layer spacing, for instance, can update body positions, socket depths, and pin lengths together. The revised mechanism is rerun along the original motion paths. We evaluate MARC on 20 articulated objects using measures of executability, structure, valid motion, coupled motion, and overall success. With Kimi-K3, MARC achieves 67.8% valid motion coverage and 60.0% overall success. Correction improves these scores from 54.1% and 40.0% on the same initial candidates. Structural and coupled-motion correctness remain unchanged in this comparison, identifying motion validity as the main benefit of correction. Comparisons with six generators and ablations of mechanism support and repair guidance further examine how the shared graph contributes to generation and revision. Our method makes three contributions: • An agent harness for articulated-object generation. MARC uses an executable kinematic graph to connect program construction, motion solving, and reflective correction for coupled and closed-chain mechanisms. • A shared representation for construction and motion solving. Physical connections bind local attachment frames to part geometry, while connection types and coordinate couplings specify kinematic constraints. Numerical tools solve for motion from the declared topology and associate motion anomalies with the relevant parts and connections. • Graph-guided evaluation and reflective correction. The reference, kinematic graph, and execution diagnostics guide targeted probes and agent-generated repairs. This guidance helps pinpoint the topology or interface parameters responsible for a failure.
