§Abstract
We introduce Sage S1.5 Flash, a 320-billion-parameter general-purpose mixture-of-experts model designed to reason over scientific evidence and act in interactive environments. Sage Sci-Perception uses dedicated encoders for molecular graphs and biological sequences and represents spectra as ordered patches of measurements. Modality-specific projectors map these representations into the input space of a shared backbone, which processes them alongside text and images. To develop the model's agent capabilities, we construct verifiable environments for tool use, search, and coding, as well as specialized workflows involving machine learning experiments and scientific software. Task completion is checked against execution results, changes in environment state, or submitted artifacts. We evaluate Sage S1.5 Flash on 33 benchmarks across seven domains. In the primary comparison against five baselines, it ranks first on OfficeQA Pro (72.2), MLE-bench Lite (90.3 HumanRank), Harvey LAB, and SpreadsheetBench~2, and second on OSWorld-Verified (85.2), WebArena-Verified (67.6), and DeepResearch Bench~II (54.2). These results show particular strengths in using documentary evidence, producing verifiable workbooks, and carrying out machine learning tasks, alongside competitive performance in desktop and browser workflows that require the model to act on visual feedback.

§Introduction (from cached fulltext; cut at ~9000 chars)
Visual feedback helps scientific agents select actions and assess their results [ 1 , 2 , 3 ] . Recent advances in multimodal agents span visual information retrieval and understanding, coding with visual feedback, and computer use [ 4 , 5 , 6 , 7 ] . We introduce Sage S2.1 Flash , a frontier 320-billion-parameter mixture-of-experts (MoE) language model for general-purpose and scientific tasks. In scientific workflows, we focus on retrieving and interpreting visual evidence from the scientific literature and using intermediate visual outputs to guide analysis. For scientific computer use, the model interprets the state of specialized software and uses visual feedback from its actions to decide how to proceed. Through Sage Sci-Perception, Sage S2.1 Flash uses scientific encoders and numerical patching to represent heterogeneous inputs such as molecular graphs, biological sequences, and spectra [ 8 ] . Modality-specific projectors map these representations into the input space of a shared MoE backbone, which processes them alongside the task instructions. In post-training, we combine general-purpose agent tasks in tool use, search, and coding with specialized scientific workflows in a large collection of verifiable environments. General tasks develop transferable skills in tool use and task execution, while scientific tasks require the model to apply those skills under domain-specific constraints. Task-specific checks provide feedback on whether the agent has achieved the intended outcome. Our evaluation compares Sage S2.1 Flash with five primary baselines across 33 general-purpose and specialized benchmarks spanning computer use, tool use, software engineering, and research. The model ranks first on OfficeQA Pro, MLE-bench Lite, Harvey LAB, and SpreadsheetBench 2, and second on OSWorld-Verified and WebArena-Verified. It also achieves competitive results in terminal execution and deep research. We study AI coding through tasks such as running machine learning experiments and post-training models, with the longer-term goal of using these capabilities to accelerate AI research and advance toward recursive self-improvement [ 9 , 2 , 10 , 11 ] .
