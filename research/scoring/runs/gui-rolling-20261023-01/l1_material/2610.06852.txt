title: One Figure, Every Canvas: Editable Flowchart Relayout via Agentic Pipeline
source: https://arxiv.org/abs/2610.06852

§Abstract
Pipeline figures in ML papers must be repurposed across many canvases, including paper columns, 16:9 slides, portrait posters, 1:1 social teasers, 9:16 phone previews. Each format imposes a different aspect ratio on the same computational graph, where any silently broken connection misrepresents the method. We formulate aspect-ratio-adaptive flowchart relayout as a distinct task: given a raster flowchart and a target ratio, produce a structurally faithful, hallucination-free, editable layout. Existing methods fail characteristically: image-to-image models stretch blocks and reject extreme ratios, text-to-image agentic systems hallucinate content, and parse-then-render systems mis-route edges. We propose an agentic pipeline factored into Parse, Style, and Layout stages, each pairing a main agent with a critic that combines deterministic constraint checks with VLM visual feedback so connectivity is explicitly checked and prevented from being silently broken. Outputs are draw.io-editable mxGraph XML. On a curated benchmark of 100 flowcharts at five aspect ratios, evaluated by Gemini 3.1 Pro and validated against human judgments, our method reaches 68.6% Content Fidelity versus 11.2-41.4% for prior work. Project page: https://onefigureeverycanvas.vercel.app/

§Introduction (from cached fulltext; cut at ~9000 chars)
Pipeline figures are central to how vision and ML research is communicated, yet the same diagram has to live across many canvases: paper columns, 16:9 slides, portrait posters, 1:1 social teasers, 9:16 phone previews. Each target imposes a different aspect ratio on the same computational graph, and every conversion must preserve the original blocks, edges, and flow direction. Any silently broken connection misrepresents the method. Manually re-laying out figures for each canvas is tedious and error-prone. As shown in Fig. 1 , our goal is to produce structure-preserving relayouts at arbitrary aspect ratios from a single source figure, with each output remaining editable in draw.io for further refinement. Recent work on automating scientific-figure creation falls into three families. Image-to-image (I2I) models such as Nano Banana Pro and GPT Image 2.0 re-synthesize the source figure at a requested resolution. Text-to-image agentic systems, PaperBanana ( Zhu et al., 2026a ) , SciFig ( Huang et al., 2026b ) , and Paper2Poster ( Pang et al., 2025 ) , orchestrate planner, stylist, and critic agents to create a new figure from a methodology description. A third line targets editability: AutoFigure-Edit ( Lin et al., 2026 ) emits SVG, while AutomaTikZ ( Belouadi et al., 2023 ) and DeTikZify ( Belouadi et al., 2024 ) use TikZ. All target figure generation from textual or programmatic inputs; none takes an existing flowchart and refits it to an arbitrary canvas while keeping its computational graph intact. When repurposed for relayout, each family exhibits a categorical failure mode (Fig. 2 ). I2I models resize in pixel space. Embedded panels and blocks are uniformly stretched, and ratios outside 3:1–1:3 are rejected. T2I agentic systems re-synthesize from a prompt, dropping source blocks and adding labels not present in the source. Parse-then-render systems recover the components but mis-route edges, breaking the directed graph that the flowchart exists to communicate. None simultaneously achieves the three properties this task requires: structural fidelity, hallucination-freedom, and arbitrary canvas resizing in a downstream-editable format. As summarized in Table 1 , these methods produce non-editable raster outputs, lack native flowchart-editor support, or cannot resize an existing flowchart to arbitrary canvases. We introduce an agentic pipeline for aspect-ratio-adaptive flowchart relayout. Given a raster flowchart F_{0} and target ratio r , our method produces a draw.io-compatible mxGraph XML X^{*} that preserves the structure, content, and style of F_{0} while fitting the new canvas. Since directly resolving structure, appearance, and spatial arrangement in a single step is difficult, we decompose the problem into three stages, each pairing a main agent with a critic (Fig. 3 ). The Parse stage recovers structured XML from F_{0} with SAM 3 ( Carion et al., 2025 ) spatial priors; the Style stage reconstructs visual appearance while extracting colors deterministically to mitigate unreliable VLM color perception; and the Layout stage rearranges the recovered graph for the target canvas, combining deterministic structural checks with VLM visual feedback to prevent connectivity errors. We further curate flowcharts from oral papers at top-tier venues, evaluate them at five target ratios, and propose four VLM-as-a-Judge metrics validated against human judgments. Our pipeline reaches 68.6% Content Fidelity versus 11.2–41.4% for prior work. Our contributions are: • We formulate aspect-ratio-adaptive flowchart relayout as a distinct task and propose the first agentic pipeline for it, factored into Parse, Style, and Layout stages, each guarded by a critic combining VLM reasoning with deterministic verification so connectivity is explicitly checked and prevented from being silently broken. • We construct FlowchartRelayoutBench , a benchmark pairing flowcharts from CVPR/ICCV/ECCV/NeurIPS/ICLR/ICML oral papers at five target ratios (9:16, 2:3, 1:1, 3:2, 16:9) with a four-metric VLM-as-a-Judge protocol (Relationship Preservation, Hallucination-free Rate, Layout Quality, Style Similarity) validated against human assessments. • Experiments and a user study show that our pipeline substantially outperforms both monolithic VLM and existing agentic figure systems on the structural-fidelity dimensions that matter most for cross-canvas relayout.
