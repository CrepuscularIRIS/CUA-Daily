title: Beveridge: Open Weight System One Decision Models with Calibrated Probabilities
source: https://arxiv.org/abs/2611.18655

§Abstract
Many production systems need a model to make a narrow decision about a document (route a ticket, check a limit, refuse a request, pick the next step of a browser agent) rather than to write text about it. We present Beveridge, a family of open weight System One decision models that take a document and up to 15 typed questions (yes/no, choice among described options, or a level on an ordered scale) and return, in one forward pass without generating text, an answer with a calibrated probability for every option. Beveridge-Large-C (398M parameters) adds a 3.5M parameter decision network to ModernBERT-large: typed number and date features in the input, exact facts from a rule engine, question-to-document evidence attention, a three-step recursive core with learned halting and an exact yes/no path. Beveridge-Pro-C adapts Gemma 4 26B-A4B with LoRA to score option letters, and Beveridge-Pro-C-Web extends it to the next step of a browser agent. On held-out tests the 0.4B model reaches 93.0% on our operations-document benchmark against 91.1% for the best of five general LLMs (31B-675B) and 87.9% for a commercial System One API, and, because its confidences are calibrated (ECE 0.029 on that benchmark), it can hand over 76% of decisions automatically at 95% accuracy, where no general LLM we tested can hand over any. It answers in 4.9 ms per decision on one NVIDIA H200 GPU and 60 ms on the 14 core CPU of an Apple M4 Pro laptop. Beveridge-Pro-C-Web raises next-step accuracy on web pages from unseen site types from 49.4% to 98.2% and completes live browsing tasks without losing document accuracy. We describe the models, the training recipes and an evaluation on 19 held-out test sets against a commercial System One API and five general LLMs, including where the models are weak. Weights and inference code are released under Apache 2.0.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language models (LLMs) are now routinely used as classifiers: a prompt describes a document and a question, and the generated text is parsed into a label. This works, but it is an obstinate fit for automation. The answer has to be parsed from free text, the model’s stated confidence is not tied to how often it is right, one decision costs seconds and a remote call; and the same weights that make the model fluent make it slow. Following the distinction between fast, automatic judgement and slow, deliberate reasoning [ 28 ] , we call a model that answers typed questions in one pass, with a probability for every option and no text generation, a System One decision model. Beveridge is a family of such models with open weights. A request is a document (any text: an e-mail, a log, an invoice, a web page as JSON) and named, typed questions; the response is a probability distribution per question (Section 3 ). Three models are released: • Beveridge-Large-C (0.4B): ModernBERT-large [ 44 ] with a decision network that reads typed values and exact facts, refines its answers over three recursive steps and answers all questions of a request in one encoder pass. It runs on a laptop. • Beveridge-Pro-C (25.8B total, about 4B active per token): Gemma 4 26B-A4B [ 20 ] with a LoRA adapter [ 25 ] trained to score option letters, for knowledge heavy decisions on one GPU. • Beveridge-Pro-C-Web : Beveridge-Pro-C with a second round of adapter training on generated web navigation steps, used as the decision maker of a browser agent. Contributions. The typed question interface follows an existing System One API [ 42 ] , and most components we use are known; our contributions are the following. 1. An encoder decision architecture that combines typed value features, an exact fact engine and a halting recursive core, with a closed form yes/no path (Eq. 1 ) that lets an exact comparison decide when it applies and inference time ablations showing how much the trained model relies on each part (Section 8.3 ). 2. Open-weight, calibrated decision models (Apache 2.0) and their training recipes (Section 6 ). 3. A comparison on 19 held out test sets against a commercial System One model and five general LLMs (31B–675B) under identical inputs, showing that a 0.4B calibrated encoder is the most accurate system on operations document decisions and that, measured as automation at a target accuracy, none of the general LLMs can hand over any decision at 95% accuracy because of how they report confidence (Sections 7 – 8 ). 4. The use of a System One model as the decision maker of a browser agent (Section 8.6 ).
