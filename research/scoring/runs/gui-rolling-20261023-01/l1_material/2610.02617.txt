title: WebUIProof: Benchmarking WebUI Code Generators with UI-Agent Execution Harness
source: https://arxiv.org/abs/2610.02617

§Abstract
Evaluating WebUI code generation at scale is difficult: outputs may compile and look plausible yet fail under user interaction, and prior benchmarks largely rely on free-form prompts with static checks (build success, screenshots) that miss functional correctness. We introduce WebUIProof, an execution-oriented benchmark that provides structured specifications and dense, executable interaction tests for WebUI generation across two task families: general WebUIs (e.g., dashboards, game, interactive tools) and 3D interactive simulation (e.g., particle/galaxy systems, physics dynamics). WebUIProof includes a UI-agent harness that runs executable interaction tests in a headless browser using an iterative plan--act--observe loop: it locates DOM elements, performs actions, observes resulting UI/DOM changes, and checks the specified assertions. We evaluate across eight commercial LLMs and observe frequent failures on interaction-based requirements even when pages render successfully, especially on 3D simulation interfaces. Finally, we show the UI-agent harness can provide outcome-level training signals. Training compact models (e.g., Qwen2.5 14B and MIMO 7B) with RL rewards derived from executable interaction tests improves functional completion while reducing build failures.

§Introduction (from cached fulltext; cut at ~9000 chars)
With LLMs increasingly integrate into the software development cycles, reliable evaluation for code generation becomes critical, motivating the benchmarks for real-world GitHub issues Jimenez et al. (2023) , programming competitions Li et al. (2022) , multilingual coding tasks Zheng et al. (2023) , and interview coding problems Hendrycks et al. (2021) . Frontend code generation (WebUI generation) differs fundamentally from backend code synthesis and remains comparatively underexplored. The correctness depends not only on whether code compiles, but on what the UI renders and how it behaves under interaction. Existing WebUI benchmarks only partially address this challenge. WebDev-Arena Zheng et al. (2024) provides a large set of web prompts, but instructions are largely free-form and evaluation relies on human preference rather than executable functional verification. WebGen-Bench Liu et al. (2024b) introduces test cases for web prompts, but many requirements stated in instructions are left unchecked, resulting in incomplete coverage of instruction-following. More broadly, many benchmarks Xiao et al. (2025) ; Zhang et al. (2025) ; Team (2024) depend on static checks such as build success, lint/type checks, or screenshots, which are insufficient to validate interactive behavior. We introduce WebUIProof , an execution-oriented benchmark designed to measure functional, interactive correctness of WebUI code generation. WebUIProof replaces free-form prompts with structured specifications (website summary and UI element requirements) and pairs them with executable interaction tests that drive the UI agent to verify expected behavior. WebUIProof contains 219 tasks (149 general + 70 3D) paired with 3k executable interaction tests, enabling functional evaluation at much higher granularity than prompt-only benchmarks. The tasks span two families that cover standard UI workflows and richer interactive behaviors, including dashboards/games/tools and interactive 3D simulations such as physics dynamics and 3D scenes (see Fig. 1 ). Our evaluation protocol is automated and reproducible, with a fixed UI-agent execution harness that runs these tests in a headless browser by iteratively planning the next interaction, executing browser actions (e.g., click, select, type, scroll), observing DOM/visual state changes, and verifying test assertions. While WebUIProof is primarily a benchmark contribution, the harness also provides outcome-level training signals by self-observing the rendered UI in training rollouts and deriving interactive tests from it. We therefore include VisRL (Visual-guided Reinforcement Learning), an execution-grounded RL approach that optimizes a compact model using composite rewards from build/runtime execution, visual quality, and UI-agent execution test success. In addition, we adopt several training strategies, such as multi-temperature sampling and fast-gate filtering, to improve rollout efficiency and stabilize learning under costly executable evaluation. We provide an agent-assisted construction pipeline for producing structured specs. and element-aligned executable tests at scale (Sec. 3 ). 3.
