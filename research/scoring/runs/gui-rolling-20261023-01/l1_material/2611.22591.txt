title: PACT: Plan-Action Consistency Training by Preserving Correct Plans and Repairing Actions in GUI Agents
source: https://arxiv.org/abs/2611.22591

§Abstract
GUI agents can formulate a correct immediate plan in their reasoning yet emit an action that fails to execute it, creating an execution gap. This recurring mismatch undermines reliable task completion, as a single execution error can derail a multi-step workflow. In outcome-supervised reinforcement learning, broadcasting a negative response-level advantage across all generated tokens risks penalizing valid planning together with erroneous execution. To address this credit-assignment conflict, we introduce PACT (Plan-Action Consistency Training), a training framework that combines reference-aligned plan protection and plan-aligned action repair without altering the original scalar action reward. Using annotated reference actions to identify execution gaps, PACT protects the verified plan by masking negative policy-gradient contributions across its token span. Keeping the generated reasoning unchanged as context, it then favors the reference action over the emitted erroneous action through a preference surrogate with stop-gradient pair weights. Compared with the outcome-only baseline, PACT raises AndroidWorld task success from 60.34% to 68.97% (+8.63 pp), while improving rule-based plan-action consistency on AndroidControl High from 83.71% to 89.74% (+6.03 pp). Adapting PACT to desktop agents also improves task success from 40.92% to 44.17% (+3.25 pp) on the full 369-task OSWorld benchmark. Together, these results establish PACT as an effective credit-assignment framework for bridging execution gaps and improving task completion across mobile and desktop GUI environments.

§Introduction (from cached fulltext; cut at ~9000 chars)
GUI agents must translate visual interfaces and user goals into executable interactions. Yet formulating a correct immediate plan in generated reasoning does not guarantee that the emitted action executes it. For example, an agent may state that it will tap a visible + button, yet emit an application-launch command instead (Figure 1 ). This execution gap is distinct from a planning error: the response already contains a valid immediate plan, but the final action fails to realize it. Building on prior diagnostic studies of reasoning–execution gaps in mobile agents [ 5 ] , we investigate how training can preserve valid plans within failed responses while repairing their execution. In reinforcement learning (RL), such execution gaps create a credit-assignment problem. Several GUI-agent methods use Group Relative Policy Optimization (GRPO) or its variants to learn from action feedback [ 7 , 9 ] . In implementations that broadcast one response-level advantage across reasoning and action tokens [ 17 ] , a negative advantage penalizes valid planning alongside erroneous execution. A scalar thought–action consistency reward [ 9 ] does not determine the direction of correction: higher agreement can result from adapting a plan to justify an incorrect action, and a flawed plan can be executed consistently. Effective correction therefore requires identifying which component the annotated reference action supports preserving. Our central principle is to preserve a reference-supported plan and repair the action that fails to implement it . Here, a plan denotes the intended next GUI interaction expressed in the generated reasoning, and the plan span denotes the tokens expressing it. Verifying reference support for parameterized GUI actions requires checking spatial or textual arguments beyond action type alone, enabling selective credit assignment that shields valid plans while repairing failed actions. We present PACT , which instantiates this principle within a group-relative RL pipeline while leaving the original scalar action reward intact. First, a conservative rule-based selector identifies responses featuring a reference-supported plan but an incorrect, inconsistent final action. Second, reference-aligned plan protection masks negative policy-gradient contributions within the plan span, leaving the advantages on action tokens and the remaining reasoning unchanged. Third, plan-aligned action repair pairs a reference-derived positive action suffix with the model’s emitted erroneous suffix under the same decoded reasoning trace via a stop-gradient pair-weight preference surrogate in the spirit of direct preference optimization (DPO) [ 15 ] , outside the original GRPO rollout group. Both mechanisms operate strictly during training; inference retains the standard single-pass reasoning–action interface without extra reflection or re-planning. PACT improves interactive task completion over the original GRPO baseline, reaching 68.97% success on AndroidWorld [ 16 ] (+8.63 pp) and 44.17% on the full OSWorld benchmark [ 21 ] (+3.25 pp). It also achieves 89.74% rule-based plan–action consistency on AndroidControl High [ 12 ] (+6.03 pp), alongside improved visual grounding on ScreenSpot-v2 Mobile [ 20 ] . Three complementary diagnostics examine why these gains arise. Fixed-plan continuation isolates action generation, showing that plan-aligned action repair improves execution of a valid plan. Aligned-state retention analyses demonstrate that reference-aligned plan protection reduces regressions on baseline-correct actions. Free-generation comparisons further show that protecting plans preserves more valid plans and enables more joint repairs, supporting the complementary roles of protection and repair beyond surface plan–action agreement. Our main contributions are threefold: • Reference-aligned plan protection and plan-aligned action repair. PACT uses reference-supported plans to decouple plan preservation from action correction without altering the scalar action reward. • Task improvements across mobile and desktop environments. Comparisons against outcome-only and two repair baselines demonstrate consistent gains in dynamic task completion on AndroidWorld and OSWorld, supported by consistency and grounding evaluations on AndroidControl and ScreenSpot-v2 Mobile. • Mechanistic evidence on repair and retention. Through fixed-plan continuation, free-generation, and baseline-correct retention analyses, we characterize the repair–retention trade-off while disentangling plan correctness, action validity, and plan–action consistency.
