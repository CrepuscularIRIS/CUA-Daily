title: DyCraft: An Agentic System for Long-Horizon 4D Scene Generation
source: https://arxiv.org/abs/2610.40754

§Abstract
While frontier coding agents can generate high-quality 3D scenes and articulated assets, they struggle to create coherent long-horizon animations. When equipped with general-purpose harnesses, they frequently produce physically implausible outputs, generating objects that interpenetrate, lack physical support, or move unnaturally. Such bare agents struggle to repair these errors because they default to scripting the full animation in one pass, making it difficult to verify their work and disentangle complex spatiotemporal constraints. Drawing on the practice of human animators, we introduce DyCraft, a system for animated 3D scene generation that breaks animation into steps that coding agents can more reliably solve. DyCraft first expands the user's prompt into a detailed plan and builds a static scene. It then creates a 3D storyboard of key animation poses, where each frame is a static 3D scene that the agent can build and debug in isolation. Storyboarding decomposes the problem into pairs of verified start and end states, allowing the agent to author local motion between them with a collection of motion authoring tools. We evaluate DyCraft on 24 long-horizon, multi-shot animation tasks covering humanoid robots, human and animal characters, and physical mechanisms. Compared with a native GPT-6 agent in Codex and prior agentic baselines, DyCraft substantially reduces physical violations and generates higher-quality animated 3D scenes that are more often preferred by human raters.

§Introduction (from cached fulltext; cut at ~9000 chars)
Animated 3D content is labor-intensive to produce, yet fundamental to filmmaking, gaming, and robot learning. Although video generative models can produce highly realistic footage, their pixel-space outputs are difficult to precisely control and often exhibit geometric, temporal, and physical inconsistencies ( Cai et al., 2024 ; Sun et al., 2025b ; Fang et al., 2025 ; Song et al., 2026 ; Gu et al., 2026 ) . Meanwhile, learned 4D generation methods ( Wu et al., 2025 ; Yin et al., 2026a ) suffer from scarce training data, limiting such approaches to short object-centric animation sequences. A compelling alternative, given recent advances in coding agents, is to represent animated content as explicit code for 3D creation tools such as Blender ( Blender Foundation, 2026 ) . Representations based on code are controllable and persistent, naturally enabling downstream tasks that require geometric consistency or precise physical interaction. Although agentic systems ( Hu et al., 2024 ; Lu et al., 2025 ; Zhou et al., 2026 ; Pfaff et al., 2026 ) and general-purpose coding agents can generate highly detailed 3D scenes and articulated assets, agentic generation of 4D (i.e. 3D+time) content has received comparatively little attention. Most existing systems generate short sequences often based on simulation ( Yin et al., 2026b ; Zhang et al., 2026b ; Wang et al., 2026a ; Liu et al., 2026 ) , animate a single articulated mesh ( Zou et al., 2026 ) , or compose pre-built characters and environments into cutscenes without substantial dynamic motion ( Xu et al., 2025b ; He et al., 2026 ) . Even frontier coding agents ( OpenAI, 2026 ) exhibit systematic failures during long-horizon animation (Fig. 2 ), including frequent interpenetration, objects that lack physical support, and implausible motions. We attribute these failures mainly to the agent’s workflow rather than its coding abilities. Animation quality depends on subtle temporal and spatial relations across many frames, making animations difficult to author and repair locally. Traditional animation practice addresses this by planning and reviewing key poses before producing intermediate motion, commonly called pose-to-pose animation ( Thomas & Johnston, 1981 ; Lasseter, 1998 ) . Applied to coding agents, this practice has two advantages: (1) it reduces long-horizon animation authoring to a sequence of static 3D scenes, drawing on agents’ strong 3D modeling ability; and (2) it allows subsequent motion to be authored between 3D states whose physical validity was already verified. We observe that general coding agents lack this workflow and instead author full animations in a single pass without systematic verification. In this work, we present DyCraft , which equips coding agents with an animation workflow, domain-specific authoring guidance, and systematic verification while leaving authoring autonomy to the agent. DyCraft contains three components: (1) a planning stage that expands the user’s prompt into a detailed scene and motion plan; (2) an authoring stage that plans key states as a 3D storyboard, renders and reviews those states, then authors continuous motion between the reviewed states; and (3) a verification stage that validates per-frame geometry and motion for interpenetration, contact, and physical support. DyCraft also provides domain guidance and solvers for locomotion and grasping, as well as a structured CAD-based representation for object and scene authoring. We evaluate DyCraft on a benchmark of 24 long-horizon multi-shot animation briefs covering humanoid robots, human and animal characters, and physical mechanisms. Compared to general coding agents and existing specialized agentic systems using the same underlying model, DyCraft substantially reduces physical violations (Sec. 4.4 ) and is preferred in a user study (Sec. 4.3 ).
