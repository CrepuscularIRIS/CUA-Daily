arxiv: 2403.05468 (2403.05468v1)
title: Will GPT-4 Run DOOM?
source: https://arxiv.org/abs/2403.05468

§Abstract
We show that GPT-4's reasoning and planning capabilities extend to the 1993 first-person shooter Doom. This large language model (LLM) is able to run and play the game with only a few instructions, plus a textual description--generated by the model itself from screenshots--about the state of the game being observed. We find that GPT-4 can play the game to a passable degree: it is able to manipulate doors, combat enemies, and perform pathing. More complex prompting strategies involving multiple model calls provide better results. While further work is required to enable the LLM to play the game as well as its classical, reinforcement learning-based counterparts, we note that GPT-4 required no training, leaning instead on its own reasoning and observational capabilities. We hope our work pushes the boundaries on intelligent, LLM-based agents in video games. We conclude by discussing the ethical implications of our work.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language models (LLMs) such as GPT-4 [ 1 ] are able to parse input text (prompts) as instructions, and execute them to remarkable accuracy. No training or fine-tuning is required for this: instead, a few exemplars (shots) in the prompt suffice. This capability has led the community to actively research LLM problem-solving capabilities, Of interest to us are planning and reasoning skills in complex environments, namely, video games. In this paper, we aim to push and evaluate these capabilities by playing a 1993 first-person shooter (FPS) developed by id Software: Doom. Although it has become a running meme to determine whether a device is able to run a port of its code (“will it run Doom?”), this exploration has scientific value. For starters, the source code is open-source; and has been ported into Python, a common scripting language in machine learning research. Doom is also a relatively simple, non-deterministic game, so LLM memorisation [ 2 , 3 , 4 ] of benchmarks is not a concern. Hence, the game can serve as an informal, community-led benchmark on computational capabilities, and, as proposed here, on LLM planning abilities. We show that, although GPT-4 has technical limitations on its ability to run Doom directly, it can still act as a proxy for the engine–not unlike some existing “will it run (display) Doom?” implementations, such as Windows Notepad [ 5 ] , E. Coli [ 6 ] , or Minecraft [ 7 ] . We also demonstrate that using two GPT-4 models, the game can be played by the LLM to a reasonable degree: it is capable of open doors, fight enemies, and fire weapons. It is also capable of executing a broader instruction set (a level walkthrough) to improve its own performance. A critical evaluation of its reasoning capabilities shows that the model is able to execute short-term planning, but it has shallow reasoning depth and low memory recall: for example, if an enemy goes out of view, the model will forget about it. This paper adds to the growing body of work informing the application and development of LLM-based intelligent agents in video games, for example, to develop playtesters [ 8 ] that do not require pretraining. To our knowledge, our work is the first to deploy LLMs in FPS games, and the first to use visual input from the game instead of descriptions. It is also the first to measure the performance of LLMs in single-player FPS. We open source the code used on this work.
