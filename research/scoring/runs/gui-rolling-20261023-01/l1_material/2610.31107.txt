title: Learning What to Ask for Tomorrow: Active Preference Acquisition for Long-Term Personalized Web Agents
source: https://arxiv.org/abs/2610.31107

§Abstract
Web agents increasingly serve the same user across repeated online tasks such as booking travel, shopping, and scheduling, so their long-term usefulness depends on how well they know the user's preferences. Passive memory and personalization methods cannot obtain preferences the user never reveals, and clarification methods that value a question by its benefit to the current task overlook the benefit of reusing the answer in later tasks. We study Active Preference Acquisition (APA): which missing preferences are worth the cost of asking? We define the Prospective Personalization Value (PPV) of a missing preference as its expected cumulative utility gain over future tasks minus the effort and disclosure-risk cost of asking, and select questions under a per-interaction budget. We characterize when cumulative reuse justifies acquisition despite insufficient single-task benefit, and evaluate this regime with an initial-profile diagnostic. APA computes the counterfactual gain of each candidate preference on public task prototypes with the agent's own task solver and aggregates it by the expected reuse of each task family. We evaluate it on ActiveWebPref, a controlled longitudinal benchmark with hidden but queryable user profiles and exact task utilities. At a horizon of 20 tasks, 34.4% of budget-feasible valuable missing preferences are amortization-dependent; APA acquires 80.3% of them, whereas current-task value of information acquires 5.1%. Under per-user asking-cost caps matched to APA's realized expenditure, APA achieves higher net utility than four heuristic selection baselines. In our cost setting, asking about every unknown preference yields lower net utility than not asking, while APA recovers 84.2% of its utility gain with 27.6% of its questions. The value of acquiring a user preference should account for its reuse across future tasks, not only its benefit to the task at hand.

§Introduction (from cached fulltext; cut at ~9000 chars)
Web agents can now carry out realistic Web tasks such as online shopping and navigating real-world websites ( Yao et al., 2022 ; Deng et al., 2023 ; Zhou et al., 2024 ) , and they are moving from one-shot assistance to persistent service. The same agent may book a user’s conference travel in March, order office supplies in April, and reserve a team dinner in May. Its usefulness over time then depends less on any single task than on how well it knows the user : that the user avoids red-eye flights, keeps hotels under a per-night budget, and needs vegetarian options. This paper studies that user-modeling problem for users of persistent Web agents: which missing preferences a persistent Web agent should acquire, and when doing so pays off. Valuable preferences, however, need not appear in the interaction history. Personalization methods condition on past behavior ( Salemi et al., 2024 ) or infer profiles from what users have said ( Zhang et al., 2026 ) , and long-term memory systems decide how to extract, store, retrieve, and update observed information ( Packer et al., 2023 ; Zhong et al., 2024 ; Chhikara et al., 2025 ; Rasmussen et al., 2025 ; Yang et al., 2026 ) . These methods work with evidence that exists; a preference the user has never had reason to mention or to reveal through behavior cannot be extracted or retrieved. Asking can fill such gaps, but asking is not free: each question costs the user effort, and each answer discloses personal information. An agent therefore cannot simply ask about everything; in our experiments, asking about every unknown preference, or about whatever an LLM deems most worth knowing, yields lower net utility than not asking at all (§ 6 ). Valuing each question by the current task does not resolve this either. Current-task clarification and value-of-information (VoI) methods ask when a question improves the current task enough to justify its cost ( Rao and Daumé III, 2018 ; Aliannejadi et al., 2019 ; Zamani et al., 2020 ; Dong et al., 2026 ) . While booking a hotel, the agent can finish without the user’s seat preference, so current-task VoI does not ask (Figure 1 ). Why not wait and ask when a flight is booked? Because even then, a single booking’s gain may not cover the cost of asking; only reuse across many later bookings does. A criterion that values a question only by the task at hand then never acquires such a preference, however often it is reused (Proposition 3.1 ). An agent therefore needs to value acquisition across tasks: Which currently unknown user preferences are worth acquiring, because their benefit across future tasks outweighs the cost of asking? We call this problem Active Preference Acquisition (APA). At each interaction the agent holds a partial profile and can already complete the current task; it decides which missing preferences to ask about and stores the answers persistently. Unlike cold-start elicitation or within-session clarification, APA interleaves acquisition with ongoing service and values persistent attributes by their reuse across heterogeneous future tasks. We define the Prospective Personalization Value (PPV) of a missing preference: its expected utility gain across future tasks, minus the effort and disclosure-risk cost of asking. PPV complements clarification rather than generalizing it, and the key distinction is in how a preference is valued, not when it is asked: a cross-task criterion may still ask at the first relevant task. We estimate PPV by counterfactual reuse valuation . For each candidate missing preference, the agent’s own task solver computes how much knowing it would change utility on public task prototypes, and these gains are aggregated by the expected reuse of each task family; questions are then selected under asking cost, disclosure risk and a per-interaction budget. To test when this helps and by how much, we build ActiveWebPref, a controlled longitudinal testbed modeled on personalized Web services, with hidden but queryable user profiles, multi-domain task sequences, and exact task utilities. It isolates the value of preference acquisition, which existing memory benchmarks do not measure ( Wu et al., 2025a ; Maharana et al., 2024 ) , and does not evaluate agents acting on live websites.
