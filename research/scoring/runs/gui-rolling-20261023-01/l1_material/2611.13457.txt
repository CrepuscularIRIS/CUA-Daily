title: Deep Personalization: Continuous Context Observation for Local Proactive Agents
source: https://arxiv.org/abs/2611.13457

§Abstract
As AI agents become increasingly capable, users must still recognize when and how to ask for help, leaving many opportunities for useful support unrealized. Proactive agents hold the promise to close this gap, but effective proactivity requires understanding users' real-time activities and personalizing intervention timing so that assistance is offered when it is likely to be helpful rather than disruptive. We introduce deep personalization, a closed-loop process that connects continuous context observation with continual agent adaptation: an agent observes user activity, selectively retains long-term context, and adapts intervention decisions from implicit feedback. We initiate deep personalization in Coco, a proactive desktop agent, by having a separate Observer Agent that monitors desktop activity, maintains compact long-term user modeling context, and learns when assistance is desirable from implicit signals such as engagement, dismissal, explicit requests, and repeated work patterns. We further develop efficient on-device strategies to enable the Observer Agent to run on local AI compute platforms without streaming raw activity data off-device. For evaluation at scale without collecting sensitive real-user activity, we introduce a data-synthesis pipeline that transforms existing computer-use trajectories into OSWorld-Persona, a benchmark with persona-conditioned intervention labels. On OSWorld-Persona, deep personalization improves macro F1 across three model backbones from 0.12-0.19 under direct prompting to 0.35-0.48 after adaptation, a 2.4-3.0x relative gain. In a week-long user study, we observe that Coco improves its macro-averaged F1 score from 0.199 to 0.515. These results suggest that on-device deep personalization can make proactive agents more timely and increasingly aligned with each user's everyday work.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language models (LLMs) and LLM-based agents are becoming increasingly capable, transforming how people work [ 1 , 2 , 3 ] . Yet most agents today remain reactive: users must first recognize when AI could help, then initiate interaction through explicit instructions. This potentially limits the benefits of increasingly capable agents to those who already know when and how to engage them [ 4 , 5 ] . Proactive agents offer a different paradigm, in which agents recognize opportunities for support and initiate interaction itself. This vision has a long history in intelligent interfaces [ 6 , 7 ] and is recently re-emerging with modern LLM-based agents [ 8 , 9 , 10 , 11 ] . However, proactivity requires an agent to decide not only what it can do, but whether its help is wanted at a particular moment. An intervention that is useful for one user may be redundant or disruptive for another, and even the same user may prefer different levels of assistance across tasks and situations [ 12 ] . We argue that addressing this problem requires moving beyond personalization based on static profiles or explicit configuration. What proactivity requires is deep personalization : a close-loop process in which an agent continuously observes user activities, selectively retains user context, makes personalized intervention decisions, and adapts itself from implicit user feedback. Such an agent builds its understanding of the user from everyday interaction—what they are working on, how they work, what assistance they value, and when they prefer to be left alone—and keeps revising it as it observes new activity and how its interventions land. We present Coco , a personalized proactive agent that realizes deep personalization through three specific technical contributions. First, at its core is an Observer Agent that continuously processes desktop activities, maintains a compact representation of the user’s ongoing work, and predicts whether proactive assistance would be valuable (§ 3.1 ). Second, a long-term memory module that accumulates context across observations, maintaining a hidden state that is updated with each new observation and used to condition downstream assistance (§ 3.2 ). Third, a closed-loop adaptation mechanism that treats user behavior such as acceptance, rejection, explicit requests, and repetitive-work patterns as implicit supervision signals to continually refine the Observer Agent via evolutionary prompt optimization and LoRA fine-tuning (§ 3.3 ). Together, these components enable Coco to learn each user’s preferred intervention timing without manual annotation. As there is an inherent tension between personalization and data exposure, we develop an efficient deployment strategy combining change-aware frame selection with observation-first scheduling (§ 4 ) to keep deep personalization on device. We demonstrate that the Observer Agent can run entirely on a single consumer device, such as an RTX 5090 or DGX Spark, with latency suitable for processing user activity over multi-second windows. To evaluate personalized proactive agents, we introduce OSWorld-Persona , a new benchmark for deep personalization that we construct via a novel data synthesis pipeline. Rather than collecting real user data which raises privacy concerns and limits reproducibility, we leverage existing computer-use benchmarks and use VLM-based user simulators conditioned on distinct personas to generate personalized labels for intervention timing appropriateness. Experiments on OSWorld-Persona show that personalized adaptation is essential for proactive support: direct prompting rarely identifies useful intervention opportunities (macro recall 0.08-0.19 and F1 below 0.19), while personalization via evolutionary prompt optimization or LoRA training raises macro F1 by 2.4-3.0 \times across base models and reaches up to 0.77 F1 on one of the personas. We further evaluate Coco on real user workloads in a week-long user study with 10 participant. Coco improves its macro-averaged F1 score from 0.199 to 0.515, demonstrating the effectiveness of deep personalization in the wild. In summary, our contributions include: • We introduce Coco , a personalized proactive agent built with deep personalization. Its Observer Agent continuously observes the user’s digital context, learns when assistance is desirable from implicit feedback, and provides relevant context to the Execution Agent. • We develop an efficient on-device deployment strategy that runs the Observer Agent locally for both time-sensitive screen understanding and personalization workloads, demonstrating that local compute can support privacy-preserving personalization in a large agentic system. • We introduce a data curation pipeline for deriving synthetic personalization benchmarks from computer-use datasets and use it to curate OSWorld-Persona. We further instantiate Coco as a desktop app and validate its effectiveness in a week-long user study.
