title: Chart the Invisible: Interactive Perception for Hidden-Target Exploration in GUI Agents
source: https://arxiv.org/abs/2610.35237

§Abstract
Despite rapid progress in command-line interface (CLI) tasks, recent LLM-based agents still struggle with reliable task execution through graphical user interfaces (GUIs). A key challenge is the limited content visible within a bounded viewport, especially on mobile devices, where many task-relevant targets remain hidden and can only be revealed through swipe interactions. Therefore, although most GUI agents support swipe as an action primitive, the lack of target visibility makes it difficult for them to decide when, where, and how to swipe to reveal the hidden content. Our quantitative study further shows that GUI agents incorrectly choose a click action in 47.8% of cases that require swipe exploration. To bridge this gap, this paper proposes equipping GUI agents with scrollable-region perception to support hidden-area exploration before action selection. To this end, we trained the first multimodal model for scrollable-region perception on a manually collected dataset of 667 UI screens, called Hagasu. By correctly identifying 78.5% of scrollable regions, experiments across nine GUI agents show that integrating Hagasu improves the mean end-to-end completion rate from 64.8% to 82.7% on explore-dependent tasks. To facilitate follow-up research, we release the swipe dataset and the source code of Hagasu.

§Introduction (from cached fulltext; cut at ~9000 chars)
Although large language models (LLMs) have made surprising progress on command-line interface (CLI) tasks ( Yang et al., 2023b ; Yang et al., 2024 ) , reliable task execution through graphical user interfaces (GUIs) remains challenging ( Xie et al., 2024 ; Kong et al., 2026 ) . Beyond the well-known challenge of interpreting visual semantics, the limited content visible within a bounded viewport constitutes a key bottleneck for GUI agents. Specifically, to preserve visual appeal, UI designs constrain element density and thereby prevent visual clutter ( Reinecke et al., 2013 ) . Modern UIs therefore widely use scrollable containers, such as lists and carousels, to accommodate additional functionality and content beyond the current view, requiring scrolling to reveal them ( Pfeuffer and Li, 2018 ) . At every step, GUI agents are thus forced to decide under uncertainty whether to pick a visible target or explore hidden areas. This dilemma is particularly acute in mobile GUIs. Limited screen size leaves many UI elements outside the current viewport, accessible only through swipe interactions. Although most GUI agents already support swipe as an action primitive ( Rawles et al., 2023 ; Zhang et al., 2025 ; Wang et al., 2024 ; Lin et al., 2025 ; Qin et al., 2025 ) , recent research shows that reliably completing mobile tasks remains challenging ( Rawles et al., 2025 ; Kong et al., 2026 ) . To quantify this difficulty, this paper conducts a study of 7 GUI agents across 218 tasks and finds that the rate of correctly planned swipe actions is 47.3 percentage points lower than that of click actions. Further analysis of 83.73% failed tasks shows that a major cause of failure is clicking an incorrect visible target when the correct target is still hidden. These findings highlight the need to help agents recognize opportunities for hidden-area exploration rather than force a choice among visible elements. Therefore, this paper focuses on equipping GUI agents with scrollable-region perception, providing explicit cues about where hidden-area exploration is possible. Achieving this goal involves two challenges. First, scrollable regions lack clear visual indicators, requiring an understanding of UI structure and semantics to identify them. To address this challenge, this paper builds on the UI understanding capabilities of a pretrained vision-language model (VLM) and fine-tunes it on 540 manually collected and annotated UI screens, to develop Hagasu for scrollable region perception. Second, improving a specific capability of a generalist GUI agent may compromise its broader capabilities. This paper therefore implements Hagasu as a non-intrusive plug-in that modifies only the GUI screenshot and prompt presented to the agent: it marks predicted scrollable regions on the screenshot and adds textual cues for swipe exploration. Extensive experiments evaluate Hagasu in scrollable-region perception, swipe planning, and end-to-end task completion. Comparisons and ablations across eight configurations demonstrate the effectiveness of Hagasu ’s training design for scrollable-region perception, with the full configuration achieving the highest recall of 78.46%. In offline swipe-planning experiments with nine VLMs, Hagasu raises mean swipe prediction recall from 46.02% to 53.87%. And it decreases click prediction recall by only 1.67 percentage points. Finally, online experiments show that integrating Hagasu into existing GUI agents increases mean end-to-end task success rate from 64.81% to 82.72%. To facilitate follow-up research, we release the scrollable-region dataset and the source code of Hagasu . We summarize the contributions of this paper as follows. • We systematically identify off-screen content as a critical, understudied bottleneck that partially explains the performance gap between GUI and CLI agents. • We build the first dataset of scrollable UI regions and open-source Hagasu , a multimodal model that equips GUI agents with scrollable-region perception for proactive hidden-area exploration. • Comprehensive experiments demonstrate the effectiveness of scrollable-region perception in improving GUI agents’ task completion on explore-dependent tasks.
