arxiv: 2611.03930 (2611.03930v1)
title: What Is This Memory Useful For? Measuring Task-Conditioned Utility in Long-Term Agent Memory
source: https://arxiv.org/abs/2611.03930

§Abstract
A stored experience may answer one future question and offer little help with another. We measure this task-conditioned utility rather than assigning each memory a single importance score. A task-blind writer stores a memory without seeing the later task; a frozen reader then answers that task with and without the memory, using identical filler. A cost ledger records the resources used to form, store and expose the memory. On single-call factual-recall tasks built from LongMemEval-V2 web-agent memories, the same memory helps more when it contains information needed for the answer. Its mean paired reward gain on these answer-bearing task pairs exceeds that on matched-control pairs by $+0.33$ (95% interval $+0.21$ to $+0.46$). The tested task-blind summaries and structured records yield smaller gains than Raw, including at fixed total context; a budget sweep is consistent with retention of answer-bearing content contributing to the difference. The bearing--control contrast remains positive in a new session with randomized memory position and under a second reader, although individual memory--task labels change. Generic retrieval performs above chance but misses most screen-defined answer-bearing memories. The factual-recall gains do not extend to the tested software-engineering and scientific-coding benchmarks, where even raw memories have no measurable effect. We provide a public, versioned Conditional Memory Utility Dataset of paired measurements and costs. The practical takeaway is to evaluate memory compression by the task utility it preserves alongside its costs. Task-conditioned measurements make this comparison possible; their stability must also be checked.

§Introduction (from cached fulltext; cut at ~9000 chars)
A long-horizon agent has to decide which past experiences to retain, which to retrieve for a task, and which to expose to the model that answers it. For retention, the relevant quantity is a memory’s expected effect over future tasks; for exposure, it is the effect on the task at hand. Both depend on how a memory’s effects vary across tasks: whether it helps many tasks or few, and whether a memory that helps one task can hurt another. Memory systems already score items ( Chen and Cheng, 2026 ; Yan et al., 2025 ; Ye et al., 2026 ) , and prior work observes that value depends on the task ( Li et al., 2026 ; Anonymous, 2026 ; Yang et al., 2026 ) . We provide a measurement protocol that jointly holds the filler context fixed, keeps the writer blind to the later task, and records the memory’s cost beside its effect. We apply it to web-agent memory on LongMemEval-V2 ( Wu et al., 2026 ) . The central finding is that usefulness depends on the memory–task pair and on whether the representation preserves the content needed for that task. Consider a hypothetical past page visit that shows a project’s budget. A task-blind writer stores that visit as a memory without seeing any future question. A later question asks for the budget, and the same reader answers it twice, with the same filler, once with and once without the stored memory; the reward difference is that memory’s effect on that question. Repeating the comparison for other questions and representations yields the memory’s task-conditioned profile. The controlled comparisons show that a memory gains more on tasks for which it contains answer-bearing information than on matched controls. The tested summaries and structured records gain less than Raw, including when total context is fixed. These findings make preserved task utility a concrete evaluation target for memory compression, alongside its costs: a shorter memory is useful only if it still helps the reader answer the relevant question. They also expose two practical challenges: generic retrieval misses most screen-defined answer-bearing memories, and individual memory–task labels can change across measurement conditions. The aggregate bearing–control contrast remains positive across the tested sessions, positions and readers; that stability does not make each individual label stable. Scope. Our empirical evidence comes from single-call factual-recall evaluation: the memories are page visits from web-agent trajectories, the future evaluation tasks are questions with deterministically scored answers, and a reader answers each question in one call without acting in an environment. We make no claim about procedural memory, acting agents, or a trained retention policy. Contributions. (1) A conditional memory utility protocol (Section 3 ): paired evaluation with identical context filler, a memory writer that never observes the future task, and a cost ledger that records formation, storage, retrieval and exposure costs beside each measurement. (2) Bounded findings for factual recall (Sections 5.2 , 5.3 , 5.4 ; Figures 3 and 4 ). Within the same memory, answer-bearing task pairs gain +0.33 [+0.21,+0.46] more reward than matched-control pairs. The evaluated task-blind compressed representations show smaller gains than Raw at their own length and at a fixed total context, consistent with reduced retention of answer-bearing text, and generic retrieval recovers only part of the screen-defined answer-bearing set ( 40\% in its top ten, against about 1\% by chance). (3) Measurement-reliability findings (Sections 3.4 , 5.5 , 5.6 , 6 ). The headline contrast keeps its direction across a new session with randomized position ( +0.50 ) and a second reader ( +0.6002 ), while its magnitude and per-pair labels change; sign-flip and harm summaries are confounded by pairs per memory and baseline correctness, and we show how to condition both away. (4) A dataset (Section 6 ) of per-pair measurements with costs, for reproducing the contrasts, evaluating retrieval against screen-defined labels, and studying variability.
