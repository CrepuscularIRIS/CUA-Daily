title: MAGAR: Multimodal Agents for GUI-Based 3D Mechanical Assembly and Minimal Rework
source: https://arxiv.org/abs/2611.02472

§Abstract
A GUI command can be correct at the interface level yet still produce an incorrect assembly. An agent must identify the relevant components, respect their structural relationships, and determine which parts should move during recovery. We introduce MAGAR-Bench, a benchmark of 4,000 multimodal samples from 26 assembly families that separates Assembly Decision, Atomic Action, and Minimal Rework. For rework, the objective counts distinct moved parts within the validated recovery candidate set for each state, rather than the number of actions. We also introduce MAGAR, a selective correction framework built on a frozen policy obtained by supervised fine-tuning. Its key design matches correction granularity to output dependencies. Structured candidates revise assembly fields and rework scope, while complete action candidates keep native GUI primitives coupled with their parameters. A learned selector retains the original prediction unless a candidate passes a task-specific intervention threshold. On recorded states from held-out assembly families, MAGAR improves Overall, the task-balanced aggregate, from 37.50 to 41.39, with gains on all three tasks. Across 209 interventions, 70 correct an error and 22 introduce one. These results support task-specific correction while highlighting the remaining tradeoff between fixing errors and preserving reliable predictions.

§Introduction (from cached fulltext; cut at ~9000 chars)
Correct GUI execution does not guarantee correct assembly modification. A command may target a valid interface element while selecting the wrong component, expressing an incompatible assembly intent, or disturbing parts that should remain fixed. When the current assembly is already incorrect, recovery adds another challenge, determining which components should actually move. GUI-based 3D assembly therefore requires more than control recognition. An agent must connect interface operations to object structure, part relationships, and the current assembly state. Multimodal GUI agents have made substantial progress in visual grounding and computer interaction ( Hong et al., 2024 ; Cheng et al., 2024 ; Qin et al., 2025 ) . Benchmarks such as VisualWebArena, OSWorld, and AndroidWorld evaluate interaction in realistic software environments ( Koh et al., 2024 ; Xie et al., 2024 ; Rawles et al., 2025 ) . Geometry-aware GUI control and assembly error correction further emphasize the importance of structural dependencies ( Wei et al., 2026 ; Wan et al., 2024 ) . Together, these lines of work motivate an evaluation focused on assembly that separates three distinct failures, incorrect assembly intent, incorrect native action grounding, and incorrect recovery scope. Evaluating them separately makes it possible to identify not only whether a prediction improves, but also what was corrected. We introduce MAGAR-Bench to make these distinctions measurable. Assembly Decision predicts an operation, the involved part set, and the next subgoal; Atomic Action predicts one native GUI primitive and its parameters; Minimal Rework predicts the moved part set and its cardinality, together with auxiliary recovery identifiers. The benchmark contains 4,000 samples from 26 assembly families, with six families held out for testing. Rework is measured by the number of distinct moved parts within the validated recovery candidate set for each state. Moving one part repeatedly is different from moving several parts once. This objective explicitly values preservation of the current assembly. All three tasks are evaluated on recorded Unity states rather than through online rollouts. The same task decomposition motivates MAGAR , a selective correction framework anchored by a frozen policy obtained through supervised fine-tuning (SFT). Replacing an entire prediction can discard fields that are already correct, while correcting every field independently can violate output dependencies. We therefore align correction granularity with output structure. Module A proposes structured assembly candidates and field-preserving variants, and revises moved part sets and counts for rework. Module B proposes complete native actions, keeping each primitive coupled with its parameters. A learned selector retains the original SFT prediction unless a candidate passes a task-specific intervention threshold. Preserving prediction fields is a modeling choice, whereas minimizing moved components is a separate benchmark objective. Our contributions are summarized as follows. • We formulate assembly intent, native GUI action grounding, and minimal rework relative to validated recovery candidates in a multimodal benchmark containing 4,000 samples, with assembly families disjoint across the training and test splits. • We develop a selective correction framework that uses structured field corrections for assembly and rework outputs and complete action replacements for native GUI actions, while retaining a common frozen SFT anchor. • MAGAR improves the overall task-balanced aggregate, from 37.50 to 41.39 across all three tasks. Intervention accounting further reports both corrected and introduced errors rather than treating every prediction change as beneficial.
