title: HarnessFlow: MCTS-Guided Harness Optimization for LLM Agents
source: https://arxiv.org/abs/2611.06254

§Abstract
The performance of large language model (LLM) agents depends on both the underlying model and the harness that governs interaction with tools and the environment. Yet harness design remains largely manual, and automating it requires navigating an open-ended search space through costly end-to-end evaluations. We introduce HarnessFlow, a framework for optimizing complete executable harnesses under a limited candidate-evaluation budget, with the model and task environment held fixed. HarnessFlow organizes candidates and their evaluation histories in a refinement tree, using a Monte Carlo Tree Search (MCTS)-based policy to balance exploitation and exploration. A coding agent refines selected harnesses using archived code, execution feedback, and a library of reusable harness mechanisms. With 15 refinement attempts per benchmark, HarnessFlow achieves the highest mean test scores among the compared methods on six benchmarks spanning agentic tasks, coding, and web interaction. The optimized harnesses achieve an average score of 69.48%, outperforming the initial harnesses and Meta-Harness by 10.89 and 3.95 percentage points, respectively, while incurring lower average per-task execution costs than hand-engineered baselines. These results suggest that structured harness search offers a promising route toward automating the design of capable and efficient LLM agents.

§Introduction (from cached fulltext; cut at ~9000 chars)
The performance of LLM agents depends not only on the underlying model but also on the harness, the executable system that governs access to information, maintains state, invokes tools, and coordinates execution ( Yang et al., 2024b ; Shang et al., 2025 ; Khattab et al., 2024 ; Hu et al., 2025 ) . Prior studies of context management and multi-agent systems show that these mechanisms can substantially affect agent behavior ( Packer et al., 2023 ; Park et al., 2023 ) , highlighting harness design as a practical means of improving agent performance without modifying model weights. However, harness design remains largely manual and expertise-intensive, making effective designs difficult to adapt and reuse across tasks and domains ( Zhang et al., 2025b ) . Recent work has sought to automate harness design and refinement to reduce reliance on manual engineering ( Zhuge et al., 2024 ; Yuan et al., 2025 ; Zhang et al., 2024 ; Zhang et al., 2025a ; Yue et al., 2025 ; Hong et al., 2026 ) . Despite this progress, efficient optimization remains challenging: the harness design space is open-ended, and evaluating each candidate requires costly end-to-end agent execution. HARBOR ( Sengupta & Wang, 2026 ) , PRISM ( Ruan et al., 2026 ) , and Self-Harness ( Zhang et al., 2026a ) refine harnesses through predefined configurations or bounded edits. Meta-Harness ( Lee et al., 2026 ) permits full-harness code refinement, while AutoSaddler ( Park et al., 2026 ) organizes durable updates from agent execution traces. DarwinX ( Zhang et al., 2026d ) explores harness populations through selection and preservation checks. These approaches motivate the study of search organization under a limited evaluation budget, leading to a central question: How can we systematically search over complete executable harnesses while making effective use of a limited candidate-evaluation budget? To address this challenge, we introduce HarnessFlow , a Monte Carlo Tree Search (MCTS)-based framework ( Browne et al., 2012 ) designed to systematically explore and discover optimal harnesses under a limited evaluation budget. First, it represents each harness as a complete executable codebase that a coding agent can inspect and modify in a filesystem workspace, enabling coordinated changes across the entire harness ( Chen et al., 2026a ; Lee et al., 2026 ) . It also provides the coding agent with a Harness Component Library of reusable mechanisms that can be adapted, composed, or extended during refinement. Second, it reformulates harness optimization as a tree-structured search problem over these executable codebases: nodes represent harness implementations, and edges record code-level modifications. The tree preserves earlier designs together with their evaluation scores and execution traces, providing structured experience that the coding agent can inspect and reuse across branches. Finally, it employs an MCTS-based selection policy to determine which eligible candidate in this tree to refine next, while the coding agent determines how to modify it. The policy combines measured performance with prior expansion counts to balance exploitation of promising designs with exploration of underexplored refinement paths ( Auer et al., 2002 ; Kocsis & Szepesvári, 2006 ) . We conduct extensive evaluations on six established benchmarks spanning agentic tasks (TAU2-bench and AppWorld), code generation (BigCodeBench-Hard and SWE-bench Verified), and web interaction (WebShop and BrowseComp-Plus). The results demonstrate that HarnessFlow is (i) high-performing , achieving the highest average test score of 69.48\% in the main comparison and improving over Vanilla by 10.89 percentage points; (ii) cost-efficient , running at a lower average inference cost than every hand-engineered harness, at 41.4\% of Codex’s across the six benchmarks; and (iii) sample-efficient , attaining a mean best-so-far validation score of 71.5\% after three candidate evaluations per benchmark and 74.2\% by round 15 . In summary, our key contributions are as follows: • We formulate full-harness optimization as a tree-structured search problem over complete executable codebases under a limited candidate-evaluation budget. • We introduce HarnessFlow , an MCTS-based framework that uses a coding agent, tree-structured experience, and a Harness Component Library to generate full-harness refinements, while an explicit selection policy allocates the search budget across alternative designs. • We conduct extensive evaluations on six benchmarks, demonstrating that HarnessFlow achieves strong task performance, cost-efficient inference, and sample-efficient harness optimization.
