title: 3DCodeVerse: Exploring 3D Worlds as Code

§Abstract
We introduce 3DCodeVerse, a research ecosystem that enables coding agents to create editable and verifiable 3D content at scale. 3DCodeVerse comprises large-scale, high-quality datasets of executable 3D code, a coding harness for spatial reasoning and automated verification, and practical guidance for 3D coding. First, we construct 3DCodeVerse-2M, a large-scale curated dataset of standalone 3D executable code. We build this corpus by collecting open-source data, converting specialized representations, and generating new programs with coding agents. Each program is packaged with the source files and associated assets required for execution in its declared environment, along with available descriptions and verification records. Second, we develop the 3DCodeVerse Harness, a multi-agent directed acyclic graph framework for generating and refining 3D content. It uses execution checks, spatial measurements, and visual feedback to automatically evaluate and revise generated programs without human feedback during generation. Third, we conduct systematic empirical studies of 3D coding, establishing baselines with fine-tuned open models and deriving practical guidance through component-level analyses of our harness. Extensive experiments demonstrate that fine-tuning on our dataset significantly improves the 3D coding capabilities of open-source models. Notably, our 3DCodeVerse harness achieves a 90% win rate against Claude Design (3D Object) in pairwise human evaluations, when both are utilized by Claude Opus 5.5.

Unlike typical 2D generation workflows ( Chang et al., 2025 ; Ho et al., 2020 ; Yuan et al., 2025 ; Yuan et al., 2024 ) , code-based 3D generation produces structured, executable content that users can edit, reuse, compose, and inspect. These properties enable scalable, controllable 3D modeling for diverse applications. Recent advances in language models and coding agents further automate this process, allowing users to create complex 3D content through text instructions ( Sun et al., 2023 ; Yin et al., 2026 ) . Despite these advances, shared infrastructure for developing and evaluating 3D coding systems across environments remains limited. Existing resources address complementary aspects of 3D coding: DeepCAD and BlenderLLM provide supervision for CAD construction and Blender scripting ( Wu et al., 2021 ; Du et al., 2024 ) ; SceneCraft and VIGA refine generated content using visual feedback ( Hu et al., 2024 ; Yin et al., 2026 ) ; and Articraft combines a specialized SDK with a harness for articulated asset generation ( Zhou et al., 2026 ) . However, these resources remain fragmented across tasks and environments. As shown in Table 1 , existing datasets primarily focus on static or articulated objects, while harnesses vary in their support for visual assessment and automated corpus construction. To bridge these gaps, we introduce 3DCodeVerse (Figure 1 ), an open-source foundational framework for learning and scaling 3D coding through a large-scale executable code corpus and a 3D code generation harness. We first build 3DCodeVerse -2M, a unified corpus of executable 3D programs spanning static objects, articulated assets, scenes, and graphics. Rather than simply aggregating existing datasets, we systematically convert heterogeneous 3D representations into reusable source code and remove dependencies on specialized or unavailable libraries. For example, we translate DeepCAD construction sequences into CadQuery programs and inline Articraft geometry routines while preserving URDF articulation specifications. Each program is paired with its associated assets, textual descriptions, provenance, and available verification signals. We further develop 3DCodeVerse Harness, a 3D code generation harness for synthesizing and refining complex 3D programs from text, images, or videos. The harness decomposes multi-component projects into a directed acyclic graph (DAG) of coding and assembly tasks, allowing multiple agents to develop and integrate source files in a structured manner. Generated programs are executed and rendered, after which an independent judge agent evaluates the outputs against explicit acceptance criteria. Complementary spatial checks detect structural inconsistencies and prevent visually plausible but geometrically invalid solutions from receiving high scores.
