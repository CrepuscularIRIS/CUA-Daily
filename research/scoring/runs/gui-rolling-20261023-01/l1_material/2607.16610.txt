title: Just A Rather Very Intelligent Spoken Agent

§Abstract
Long-horizon AI agents are becoming increasingly capable, yet their interaction with users remains surprisingly thin. In most workflows, users give an initial instruction, receive only selective textual updates, and lose a clear sense of what the agent is doing or when to step in. This leaves a missing part in the current agent ecosystem: an always-on Jarvis-style mediator that keeps the agent continuously reachable to the user. Such a mediator should support real-time spoken interaction with the user, answer questions without interrupting the worker, proactively report progress or confusion, and inject user guidance back into the agent's execution when useful. In this work, we introduce JarvisBench, a benchmark for measuring the dual value of mediation in long-horizon agent workflows. JarvisBench contains two complementary tracks: an agent-collaboration track that measures whether mediation improves downstream task completion, and a user-interaction track that measures whether mediation makes ongoing execution more understandable, responsive, and accessible to users. We instantiate the benchmark with a modular reference Jarvis prototype and evaluate it on 34 text-only WildClaw tasks executed in OpenClaw. Preliminary results with GPT-5.5, Claude Opus 4.7, Gemini-based, and GPT-based worker agents suggest that Jarvis-style mediation can provide trace-grounded responses to user questions and improve task performance when sparse user guidance is injected at appropriate moments. The results also show that effectiveness depends strongly on the mediator's LLM brain, highlighting both the promise of this missing middle layer and the need for broader community effort. §Introduction (from cached fulltext; cut at ~9000 chars)
Recent advances in AI agents have rapidly expanded their capabilities across diverse domains, from solving complex programming tasks to assisting users in everyday activities ( Huang et al., 2024 ) . Despite their growing competence and deployment potential, their interaction paradigm remains largely unchanged. Most existing agents operate in a turn-based manner: users issue instructions, agents work autonomously for extended periods, and communication occurs only through sparse textual updates, if any. Such delayed and intermittent interaction often leaves users out of the loop, making it difficult to understand agent progress, correct errors early, or steer the execution before the agent drifts away from the user’s intent. Science fiction has long imagined a different paradigm for human-agent interaction. In Iron Man, J.A.R.V.I.S. functions as an always-on intelligent collaborator that communicates with user in a spoken manner: proactively sharing progress, answering questions anytime, and executing commands through natural voice interaction. This hands-free, real-time experience enables fantastic collaboration without pausing their ongoing activities. In contrast, today’s agents remain largely turn-based and screen-bound: users can launch an agent, but cannot easily stay connected to it. We argue that this contrast points to a missing interface in current long-horizon agent workflows. The issue is not simply that agents need stronger models or larger agent teams. Rather, users and agents need a continuous communication layer between them. On the user side, this layer should make agent execution reachable through natural speech: users should be able to ask what is happening, request clarification, and receive progress reports without inspecting the full execution trace. On the agent side, this layer should monitor the worker agent’s working trajectory, surface confusion or failure to the user when guidance may help, and carry concise user feedback back into the worker’s ongoing ReAct timing. In this work, we introduce JarvisBench , a benchmark for measuring the value of a Jarvis-style mediator between the user and a long-horizon worker agent. JarvisBench is organized into two tracks. The user-interaction track evaluates whether the mediator can provide timely, trace-grounded, and task-consistent responses to users during execution. The agent-collaboration track evaluates whether the mediator can help the worker agent recover from failure-prone states by consulting the user and injecting concise guidance back into the ongoing process. This two-track design makes it possible to test different LLM brains, speech modules, worker agents, monitoring policies, or memory designs under the same mediation role. To instantiate the benchmark, we build a modular reference Jarvis prototype. The user-facing side supports spoken interaction, while the agent-facing side receives textual ReAct-style updates from the worker agent, maintains execution context, and opens interaction checkpoints when user questions or expert guidance should be handled. This prototype is not intended to be the only possible implementation of Jarvis; it is a reference system for running the benchmark and exposing the required logs. We instantiate JarvisBench on 34 text-only WildClaw ( Ding et al., 2026a ) cases executed in OpenClaw or Hermes platforms, covering practical long-horizon tasks that require planning, tool use, recovery, and safety-aware decisions. With simulated nonexpert users, Jarvis provides useful progress and topic-related responses during execution, suggesting that mediation can make agent work more transparent without requiring users to inspect the full trajectory. With simulated expert users, Jarvis also improves task outcomes by reporting failure-prone states and relaying concise user guidance back to the worker agent. The effect depends strongly on the capability of the Jarvis brain: with a GPT-level mediator, the Overall Score of a Claude Opus 4.7-based worker agent increases from 64.01 to 75.79 on WildClaw. Case analysis further suggests that useful guidance does not need to be highly specialized; even when the expert user cannot access the full ReAct trajectory, simple suggestions based on Jarvis’s reports can help the worker agent escape local failure modes.
