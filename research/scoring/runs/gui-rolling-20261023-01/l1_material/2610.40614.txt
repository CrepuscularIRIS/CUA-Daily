title: L3G-World: Real-Time Infinite World Generation with Latent 3D Gaussian Memory
source: https://arxiv.org/abs/2610.40614

§Abstract
Interactive world models generate visual content conditioned on user actions, yet maintaining spatial consistency over long-horizon exploration in real time remains challenging. Existing approaches rely on either temporal context or explicit 3D memory, both of which scale poorly because memory grows with the length of the generated stream. Moreover, explicit 3D memories condition latent video generators by re-encoding RGB renderings, which precludes real-time generation. In this paper, we introduce a Latent 3D Gaussian Memory (L3G) that combines the efficiency of feed-forward reconstruction with a compact, rapidly renderable scene representation. Building on this memory, we propose L3G-World, in which a memory updater and a video diffusion transformer (DiT) alternate autoregressively to generate spatially consistent worlds. The memory updater spawns Gaussians in newly observed regions and refines existing ones, so that the memory grows with scene extent rather than stream length. Each Gaussian further stores a VAE latent feature, allowing the memory to be rendered directly into the DiT's latent space without VAE re-encoding. Experiments show that L3G-World achieves state-of-the-art generation quality and long-horizon spatial consistency, with up to $38.6\times$ fewer 3D primitives, $3.2\times$ faster memory updates, and $359\times$ faster memory rendering relative to the most efficient prior 3D-memory baseline for each metric, enabling real-time world generation at 9 FPS.

§Introduction (from cached fulltext; cut at ~9000 chars)
Interactive video world models ( Seo et al., 2026 ; Nam et al., 2026 ; Bruce et al., 2024 ; Team et al., 2026 ; Mao et al., 2026 ; Sun et al., 2025 ; Wang et al., 2026 ; Gao et al., 2026 ; Basant et al., 2026 ) , which generate visual content conditioned on user-provided actions, have recently emerged as a promising framework for real-world simulation ( Seo et al., 2026 ; Mao et al., 2026 ; Basant et al., 2026 ) , interactive game generation ( Bruce et al., 2024 ; Team et al., 2026 ; Sun et al., 2025 ; Wang et al., 2026 ; Gao et al., 2026 ) , and embodied simulation ( Agarwal et al., 2026 ; Chen et al., 2026b ) . A central challenge lies in maintaining spatial consistency during long-horizon exploration and loop closures while still supporting real-time generation. One line of work employ temporal context, by retrieving history frames or KV caches of self-attention layers in diffusion models during autoregressive generation ( Team et al., 2026 ; Wang et al., 2026 ; Mao et al., 2026 ; Yi et al., 2026 ) . By allowing each new chunk to attend to information from earlier generations through attention, these methods help maintain scene consistency ( Kwon et al., 2026 ) . However, its memory and attention costs grows with the length of the generated stream and spatial resolution. As shown in Tab. 1 , this linear growth makes long-horizon generation increasingly expensive and can eventually lead to out-of-memory failures. Another line of work explicitly stores scene information in persistent 3D representations. These approaches preserve previously generated content by reconstructing frames into point-cloud-based memories ( Ren et al., 2025 ; Zhao et al., 2026 ; Wu et al., 2026a ; Shen et al., 2026 ; Lee et al., 2026 ) or 3D Gaussian primitives ( De Lutio et al., 2026 ; Wu et al., 2025 ; Yang et al., 2026 ) . Such spatially anchored representations improve consistency across revisited regions while enabling fine-grained camera control. However, as shown in Tab. 1 , existing approaches exhibit a fundamental trade-off between reconstruction efficiency and throughput. Feed-forward methods based on per-pixel point clouds or Gaussian primitives enable fast scene reconstruction, but predicting dense 3D representations for every pixel introduces substantial memory overhead. As generation proceeds, these dense primitives are repeatedly accumulated over the same spatial regions, resulting in increasingly redundant scene representations and slower target-view rendering. Moreover, since previously stored primitives are not adaptively updated, geometrically inaccurate regions may persist over time. In contrast, optimization-based methods ( De Lutio et al., 2026 ; Wu et al., 2025 ) maintain more compact representations whose memory footprint primarily scales with scene extent, but their iterative optimization introduces substantial latency, making them unsuitable for real-time generation. To address these challenges, we introduce a compact L atent 3 D G aussian Memory ( L3G ), which is continually read and updated online, and whose size grows primarily with the spatial extent of the explored scene rather than with the length of the generated stream. Building on this memory, we propose L3G-World , a world-generation framework composed of two modules: a feed-forward memory updater L3G-Mem , and a memory-conditioned video diffusion transformer L3G-Gen . As the two modules alternate autoregressively, L3G-Mem spawns new Gaussians only in uncovered regions, and refines the existing Gaussians in explored regions through residual updates. The memory is therefore not a buffer that accumulates primitives, but a persistent scene representation revised over time, which avoids redundant accumulation and progressively corrects geometrically inaccurate Gaussians. Since each Gaussian additionally stores a VAE latent feature, the memory is rendered directly into the latent space of L3G-Gen under the target cameras, conditioning the generation of the next video chunk without VAE re-encoding. The generated chunk is then fed back to L3G-Mem, which again updates the memory, closing the autoregressive loop. Combined with few-step distillation of L3G-Gen, this design enables real-time, long-horizon world generation. Experiments demonstrate that L3G-World achieves state-of-the-art long-horizon consistency and generation quality while using 26.7 – 38.9\times fewer 3D primitives, performing memory reconstruction 3.0 – 3.2\times faster, and providing 349 – 359\times higher VAE-space rendering throughput than the most efficient prior explicit 3D-memory baseline for each metric. Combined with few-step distillation of L3G-Gen, this enables real-time world generation at 9.02 FPS on one H100 GPU.
