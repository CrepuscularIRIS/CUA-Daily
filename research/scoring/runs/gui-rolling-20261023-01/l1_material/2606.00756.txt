title: CoMIC: Collaborative Memory and Insights Circulation for Long-Horizon LLM Agents in Web Cloud-Edge Systems

§Abstract
LLM-based Web agents are increasingly deployed on edge servers to carry out long-horizon tasks on behalf of users with low latency. However, the lightweight models that fit on edge servers often struggle with long-horizon tasks that require persistent memory, subgoal tracking, and reflection. Fine-tuning edge models after deployment is costly and difficult to scale across heterogeneous nodes, while purely local execution confines each agent to its own isolated experience. We propose \textsc{CoMIC}, a parameter-update-free cloud-edge framework for Collaborative Memory and Insights Circulation. Following the paradigm of ``Act at the Edge, Reflect in the Cloud'', edge agents execute locally with subgoal-oriented hierarchical memory and selective re-expansion of relevant histories, while a cloud-side LLM critic asynchronously evaluates the trajectories uploaded through a Web gateway, admits reusable experience, and circulates cross-agent guidance indexed by semantic subgoal identifiers back to all edge agents. On five long-horizon benchmarks, \textsc{CoMIC} enables weak edge agents to achieve non-zero success on tasks where a standard memory-based agent fails entirely, and improves their task progress over both the standard agent and purely local execution while reducing context consumption relative to the standard agent, all without updating model parameters. When stronger heterogeneous agents join the edge, the weak agents further improve in success, progress, and grounding with lower context consumption.

§Introduction (from cached fulltext; cut at ~9000 chars)
The Web is shifting from a space where users search and browse by themselves to one where AI assistants accomplish tasks on their behalf ( Shao et al., 2025 ) . Benefiting from recent breakthroughs in large language models (LLMs), LLM-based agents have shown great potential in autonomous decision-making ( Borzilov et al., 2025 ; Zhu et al., 2025 ) , enabling Web applications to translate rapid advances in AI into more personalized and convenient user experiences ( Wang et al., 2024 ; Xi et al., 2025a ) . Such agents have proven effective in helping users handle massive Web content and tasks, including long-horizon tasks such as Web browsing ( Lai et al., 2024 ) , content search ( Sharma et al., 2024 ) , online shopping ( Nie et al., 2024 ) , and travel planning ( Xie et al., 2024 ) . These tasks involve dozens of interdependent decisions, require persistent tracking of intermediate progress, and call for reflection on failures ( Yao et al., 2022 ; Hu et al., 2025 ) . To meet users’ demand for low latency when performing Web tasks, Web infrastructure is pushing these agents toward the network edge. Deploying lightweight LLM agents on edge servers to serve users’ end devices has become a practical solution for bringing autonomous capabilities closer to users ( Qu et al., 2025 ) . However, as illustrated in Figure 1 (a), constrained by the limited computational resources of edge servers and the limited context capacity of lightweight models, edge-deployed LLM agents exhibit restricted reasoning capability on complex long-horizon tasks ( Yao et al., 2025 ) . Although continuously fine-tuning models on task experience is a conventional approach, performing frequent parameter updates across highly diverse tasks and heterogeneous edge nodes incurs substantial computational overhead, making it difficult to scale in practice ( Zeng et al., 2024 ) . Therefore, optimizing text-based memory interaction mechanisms without parameter updates offers a more scalable alternative ( Zhang et al., 2025a ) . However, classic memory paradigms that concatenate entire interaction histories into prompts suffer from context explosion and high token consumption ( Yao et al., 2022 ; Hu et al., 2025 ) . Recent studies mitigate this by decomposing memory into cross-trial and in-trial (working) memories ( Xi et al., 2025b ; Zhang et al., 2025b ; Li et al., 2025 ) , yet maintaining and retrieving cross-trial memories accumulated over many tasks introduces considerable computational and storage overheads, making them better suited to resource-rich environments than to edge servers. Moreover, purely local execution confines resource-bounded edge agents to isolated experiences, lacking the cross-agent sharing required to support complex tasks efficiently. The constraints faced by edge-deployed agents resemble the cognitive limitations of human individuals: with limited memory and cognitive resources, no single individual can master all relevant knowledge alone. To cope with this, human groups have developed a fundamental strategy ( Wegner, 1987 ) : they accomplish complex tasks collaboratively through distributed memory and shared knowledge. Inspired by this observation, we propose Co llaborative M emory and I nsights C irculation ( CoMIC ), a parameter-update-free cloud-edge collaborative framework for memory-enhanced edge LLM agents. Operating under an “Act at the Edge, Reflect in the Cloud” paradigm(Figure 1 (b)), CoMIC offloads computationally intensive tasks, such as cross-trial long-term memory maintenance and complex logical reflection, to the cloud. Meanwhile, edge nodes maintain only lightweight, selectively expandable memories for immediate decision-making, thereby improving the capability of agents deployed at the Web edge to handle complex long-horizon tasks under resource constraints.
