title: Building Fully On-Device GUI Agents with Mobile NPUs
source: https://arxiv.org/abs/2611.20772

§Abstract
Mobile GUI agents are increasingly used to automate everyday smartphone tasks, but most existing systems still rely on cloud-hosted models or remote inference, introducing repeated communication latency, privacy exposure, and dependence on network availability. Modern smartphones integrate neural processing units (NPUs) that provide an attractive substrate for fully on-device LLM inference. However, directly deploying conventional GUI-agent pipelines on mobile NPUs is inefficient. GUI-agent inference is fundamentally a long-input, short-output workload, yet conventional agents spend substantial time on autoregressive reasoning and action generation, while mobile NPUs provide much higher throughput for prompt prefill than token-by-token decoding. Meanwhile, dynamically varying GUI-agent contexts conflict with the fixed context profiles required by statically compiled NPU runtimes. We present DroidPrefill, a prefill-centric inference architecture that reshapes the GUI-agent workload around mobile-NPU execution. DroidPrefill combines Prefill-Centric Inference to reduce unnecessary autoregressive decoding with Efficient Context Management to preserve decision-critical information within a fixed compiled context budget. Experiments on commercial smartphones show that, in controlled comparisons with the autoregressive T3A+ baseline, DroidPrefill reduces per-step inference latency by up to 85.0%, while improving task success rate by up to 24.6%.

§Introduction (from cached fulltext; cut at ~9000 chars)
Mobile GUI agents provide a general-purpose approach to automating everyday smartphone tasks, such as navigating applications, retrieving information, and completing forms, while also improving application accessibility ( Liu and others, 2024 ; Wen et al., 2024 ; Lee et al., 2024 ; Zhang et al., 2025 ; Rawles et al., 2025 ) . Unlike application-specific scripts, a GUI agent observes the current interface, reasons about task progress, and executes user-level actions such as tapping, typing, and scrolling. Recent advances in large language models (LLMs) and vision-language models (VLMs) have enabled increasingly capable mobile GUI agents ( Qin and others, 2025 ; Zhang and others, 2025 ; Yan and others, 2025 ; Tang and others, 2026 ) . However, many existing systems still rely on cloud-hosted models or remote inference. Because multi-step tasks repeatedly invoke an observe–reason–execute loop, cloud-based agents incur network communication and remote-inference latency at every step, expose privacy-sensitive UI states, and remain dependent on network availability ( Wen et al., 2025 ; Huang et al., 2026 ) . These limitations motivate fully on-device mobile GUI agents ( Yuan et al., 2024 ; Zhang and others, 2025 ; Yan and others, 2025 ) . Modern smartphones integrate heterogeneous compute resources, including CPUs, GPUs, and neural processing units (NPUs) for local machine-learning workloads ( Jeong et al., 2022 ; Yuan et al., 2024 ) . Among them, NPUs are particularly attractive for mobile agents because they provide specialized and energy-efficient acceleration for LLM inference while preserving CPU and GPU resources for application logic and rendering ( Xu et al., 2025a ; Yin et al., 2026a ; Cai et al., 2026 ) . Although moving inference on device improves privacy, offline availability, and cost, a conventional on-device agent still inherits the long-context, decode-heavy inference pattern of cloud agents, making it inefficient on mobile NPUs. We observe that GUI-agent inference is fundamentally a long-input, short-output workload. Each interaction step may consume a long task instruction, UI representation, and interaction history, yet typically produces only one executable action from a small action space ( Rawles et al., 2025 ) . This structure creates a natural opportunity for mobile NPUs: the long input can be processed during high-throughput prefill, while only a small amount of autoregressive decoding is fundamentally required. Guided by this observation, we present DroidPrefill , a prefill-centric inference architecture for fully on-device mobile agents on commercial smartphone NPUs. Rather than asking the model to freely generate a reasoning trace and action at every interaction step, DroidPrefill first compiles the current UI state into a compact set of executable candidates. Efficient Context Management then preserves UI evidence and bounded task state within a fixed NPU context budget. After this context is prefilled, Prefill-Centric Inference directly examines the candidate-label logits exposed at the prefill boundary. Confident decisions can be dispatched immediately through Self-Speculative Action Dispatch (SPAD), while uncertain decisions continue from the same KV cache through a short Structured Decision Refinement step. Only actions that require textual arguments invoke an additional bounded fill stage. Together, these mechanisms shift common-case decision making away from long autoregressive generation while keeping dynamically varying agent contexts within an efficient compiled profile. They directly address two workload–hardware mismatches that prevent conventional mobile-agent pipelines from efficiently exploiting mobile NPUs: Prefill–decode mismatch. Mobile NPUs execute prompt prefill efficiently, whereas autoregressive decoding is sequential and substantially slower ( Xu et al., 2025a ; Cai et al., 2026 ) . Conventional GUI agents, however, spend substantial inference time decoding reasoning traces and free-form actions. DroidPrefill addresses this mismatch by moving common-case action selection to the prefill boundary and invoking decoding only when additional reasoning or textual output is needed. Static–dynamic mismatch. Mobile NPU runtimes commonly rely on statically compiled context profiles, while GUI-agent request lengths vary dynamically across tasks, UI states, and interaction steps. Using a large profile reduces inference efficiency, whereas a small profile may fail to accommodate context-heavy requests. DroidPrefill addresses this mismatch by packing decision-critical UI, task-state, and action information within a bounded context budget. In summary, this paper makes the following contributions: • To the best of our knowledge, we present the first systematic study of mobile GUI-agent inference on commercial smartphone NPUs.
