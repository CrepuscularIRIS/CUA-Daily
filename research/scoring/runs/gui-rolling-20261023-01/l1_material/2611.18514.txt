arxiv: 2611.18514 (2611.18514v1)
title: Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination
source: https://arxiv.org/abs/2611.18514

§Abstract
Mechanistic Interpretability (MI) has made significant progress in explaining the internal computations of Large Language Models (LLMs); however, these advances have yet to demonstrate comparable success in explaining the decision-making processes of LLM-based agents. This paper examines the challenges MI tools face when applied to realistic agentic failures. We focus on one such failure: web agents hallucinating actions that are not available on a website. We apply a series of mechanistic analyzes to Qwen2.5-7B-Instruct as it interacts with live websites. We find that a linear probe trained on the last prompt token can predict hallucinations before generation begins (0.80 AUC) and steering along a probe direction corrects 85\% of hallucinations, but disrupts 7\% of valid actions. However, these results only provide a partial explanation of why the agent hallucinates. The probe direction is sensitive to prompt formatting, losing much of its steering effect after a minor change to how actions are represented. Additionally, circuit identification can be difficult as the computation is distributed across multiple components and positions, and the information the agent relies on varies across examples. We discuss how these observations challenge the assumptions underlying standard MI methods for circuit discovery and feature identification, and outline future directions for making these methods better suited to explain failures in LLM-based agents.

§Introduction (from cached fulltext; cut at ~9000 chars)
LLM-based agents are increasingly deployed in complex, long-horizon tasks ranging from web navigation ( Zhou et al., 2024 ; Deng et al., 2023a ; Xue et al., 2025 ; Aghzal et al., 2026b ) and code generation ( Jiang et al., 2024 ; Tang et al., 2024 ; Li et al., 2025 ) to scientific reasoning ( Wei et al., 2025 ; Xin et al., 2024 ) . Unlike traditional LLM tasks and settings where a model produces a single response to a fixed input, agents operate sequentially: they perceive an environment, form plans, execute actions, observe outcomes, and adapt over multiple steps. While LLM-based agents have achieved success in a number of scenarios Schmidgall et al. (2025) ; Yang et al. (2024) , the complexity of underlying environments and the sequential nature of the decision-making involved introduce failure modes that are qualitatively different from those observed in standard LLM settings ( Aghzal et al., 2026b ; Cemri et al., 2025 ; Zhu et al., 2025 ; Liu et al., 2024 ) and the mechanisms underlying these failures remain poorly understood. Mechanistic interpretability (MI) ( Olah et al., 2020 ; Elhage et al., 2021 ) is a candidate for closing this gap. MI aims to recover the algorithms and concepts a network implements from its weights and activations, and has traced the circuits and features responsible for a wide range of behaviors ( Meng et al., 2022 ; Geva et al., 2021 ; Ravfogel et al., 2021 ; Finlayson et al., 2021 ; Olsson et al., 2022 ; Akyürek et al., 2023 ) . While this demonstrates the promise of MI for understanding and improving LLMs, its application to LLM agents remain limited, despite agent reliability being a critical concern for both performance and safety ( Bereska and Gavves, 2024 ; Bengio et al., 2025 ; Jones et al., 2026 ; Lee et al., 2026 ) . This gap reflects a discrepancy between what current MI tools are able to explain and the root causes of agent failures. While MI has been designed to target model-level analysis, agentic failures emerge over long trajectories and over multiple agent components. Aghzal et al. (2026a) , thus, argue that explaining LLM agents requires multiple levels of attribution that combine behavioral analysis with MI. In this work, we focus on the mechanistic level of their proposed framework, highlighting the challenges that must be overcome to extract meaningful mechanistic insights from the backbone LLMs powering agents. To highlight these challenges, we conduct an analysis on a failure mode in which web agents hallucinate actions that are not available on the provided web page. Using Qwen2.5-7B-Instruct on live websites from Online-Mind2Web ( Xue et al., 2025 ) , we apply a number of MI techniques in order to explain the causes behind this behavior. We find that a linear probe on the last prompt token predicts the hallucination with 0.80 AUC before the action is written, and that steering along the probe direction fixes 85% of hallucinations while breaking 7% of valid actions. However, each of these analyzes captures only part of the mechanism. On the circuit discovery side, computation is distributed across components, and targeted component interventions based on component analysis fix at most 8.9% of cases. Moreover, the input responsible varies across samples. On the feature identification side, we find that the probe direction is coupled to the prompt format and loses much of its steering effect under a small change in how actions are listed, and pretrained SAEs yield no interpretable features guiding hallucinated decisions. These findings highlight how the assumptions made by MI approaches can be challenged in the realistic settings agents operate in. We highlight some directions that can help address these issues.
