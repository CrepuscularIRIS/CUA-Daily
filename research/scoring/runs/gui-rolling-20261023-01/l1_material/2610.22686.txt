title: Multimodal Filesystem Memory For Long-Horizon Embodied Agents
source: https://arxiv.org/abs/2610.22686

§Abstract
Agents operating over long horizons need an effective memory that allows them to reuse their experience throughout long interactions. If the entire history of an interaction is retained, it becomes difficult to find the relevant experience, while compressing it into summaries may result in the loss of visual and spatial details that are required later on. We present \textbf{MFM}, a multimodal filesystem memory architecture that keeps complementary types of agent memory. \textbf{Episodic memory} stores the observations, actions, and outcomes, and \textbf{spatial memory} associates experiences with locations. \textbf{Semantic and procedural memory} build up general knowledge and reusable methods of acting, and \textbf{working memory} holds the current plans. MFM makes use of searchable textual records to connect these different representations to the underlying multimodal episodes. The agents are able to find previous experiences by means of contextual cues and to examine the original observations in order to recover details that are missing from their textual descriptions. Through consolidation, the agents convert experience into higher-level knowledge and procedures while still keeping references to the original episodes. In the case of long-horizon Minecraft and computer-use tasks, MFM leads to improved performance with three base models. With GPT-6-Astra, MFM completes \emph{Mine Diamond from Scratch} and reaches 16 out of 24 milestones on the \emph{Ender Dragon} task, as against 12.7 for the best baseline. On CUABench-KiCad it attains a mean reward of 0.440, as compared to 0.400 for the best baseline and 0.267 in the case of no persistent memory.

§Introduction (from cached fulltext; cut at ~9000 chars)
Agents that are intelligent and capable of operating autonomously over long periods in complicated, open-ended environments need to remember what they have seen, discovered, and previously done ( Park et al., 2025 ; Wang et al., 2026 ) . A large part of this kind of memory will generally be visual or spatial in character, for instance the route by which one can get back to an object that it has seen before. It is not clear what the appropriate form of compact memory the agent should use to store such observations. If one stores everything directly then it becomes difficult to find relevant experiences as the amount of history increases. Conversely, summaries of the memory enable quicker retrieval, but may result in important details being discarded later ( Lu et al., 2026 ; Zou et al., 2026 ) . We represent memory as a multimodal filesystem (MFM) which simultaneously holds different types of memory. We organize the memory based on the distinctions between various human memory systems ( Tulving, 1972 ; Squire, 2004 ) . In the MFM, episodic memory preserves past observations and interactions, spatial memory connects experiences to locations in the environment, semantic memory records facts and relationships, procedural memory contains reusable methods of acting, and working memory holds the current plan and the immediate subgoals. The five memory functions are realised using three common storage elements: episodic records, an associative index, and agent-written memory. These elements are arranged as folders and files in a shared filesystem, with references that link knowledge, procedures, and plans to their supporting episodes. Previous work that has used a filesystem to store agent memory has shown the effectiveness of searchable textual records of interaction ( Fox et al., 2026 ) . With embodied agents, textual descriptions can fail to include important visual or spatial information. VISTA ( Han et al., 2026 ) keeps visual observations and allows frames to be revisited using a turn or frame identifier, thus holding on to information that goes beyond its textual summaries. Yet it can be difficult to find the relevant experience, particularly as the memory increases. MFM offers an explicit structuring of the memory in the form of a filesystem, which enables quick retrieval of context and the aggregation of skills and knowledge. As shown in Fig. 2 , associative indexing links these representations via searchable cues to the stored evidence. Text acts as an addressing layer for multimodal records: the agent begins by searching the descriptions of events, actions, and locations and then looks up the references in order to examine the corresponding observations. For instance, it can find a previous visit to a cave by means of its coordinates or by referring to an action that was attempted, check the recorded view, and then compare it with the current observation. The cues employed to locate an episode need not include a description of all the details of the episode. This enables us to navigate a long history of past episodes using compact records and at the same time retain detailed visual information which may only become relevant later. With increasing experience, MFM employs self-evolving consolidation in order to update its knowledge, skills, and current working plans. Specific observations can lead to the establishment of new facts or relationships, useful action sequences can be turned into reusable procedures, and new information discovered can cause the agent to alter its present plan. These updates link episodic experience to semantic, procedural, and working memory. For instance, the agent might connect a resource with a cave that has just been explored, record a reliable procedure for getting to it, and change its route if a subsequent observation indicates that the entrance is blocked. Since the memories written by the agent include references to the episodes that support them, the agent can go back and look at the original evidence whenever its interpretation becomes uncertain or is contradicted. The evolution of the memory is illustrated in Fig. 1 . Our work consists of three parts. Firstly, we propose a method for organising a multimodal agent’s memory within a single filesystem, covering episodic, spatial, semantic, procedural, and working memory. Secondly, we implement this organisation in MFM, which combines cue-based retrieval and visual inspection with consolidation into revisable knowledge and reusable procedures. Thirdly, we demonstrate through long-horizon Minecraft and computer-use tasks that MFM surpasses both memory-free and memory-augmented baseline methods when using three base models, and that it is able to reuse its memory across different tasks. Using GPT-6-Astra, our system manages to complete the MCU Mine Diamond from Scratch task in all instances and achieves 16 out of 24 milestones on Ender Dragon , whereas the best baseline achieves an average of 12.7.
