title: When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents
source: https://arxiv.org/abs/2611.14326

§Abstract
LLM agents increasingly operate in long-horizon, verifier-rich environments, but current self-improvement mechanisms often write episode-derived lessons directly into memory, making local success an unreliable signal for reusable and safe knowledge. This paper addresses the core question of when an experience-derived behavioral update should be admitted into persistent agent state. We propose Falsification-Gated Self-Evolution (FGSE), a verifier-grounded framework that represents each candidate lesson as a structured hypothesis with an explicit precondition, behavior change, expected effect, and verifier. FGSE applies the hypothesis only in a temporary state, tests it on target-transfer, falsification, and archived-regression probes, and then commits, refines, or rejects it according to measured gain and risk. Across web, app, tool-use, and long-term memory benchmarks, FGSE achieves strong task performance, including 39.8 WebArena success rate, 78.8 AppWorld average completion, and 0.724/0.487 Pass$^1$ on $τ$-Retail/$τ$-Airline, while reducing falsification failures to 5.0%, regression damage to 1.3%, and harmful committed updates to 3.6%. These results suggest that testing memory updates as hypotheses supports more reliable long-term adaptation.

§Introduction (from cached fulltext; cut at ~9000 chars)
Large language model (LLM) agents are increasingly expected to operate in long-horizon, interactive environments where they must reason, call tools, update internal context, and recover from mistakes ( Yao et al., 2023 ) . This capability supports web navigation, app-level tool use, and user-facing assistance ( Zhou et al., 2024 ; Trivedi et al., 2024 ; Yao et al., 2024 ) ; embodied interaction additionally requires grounding language in visual and gestural context ( Li et al., 2023 ) . Continual deployment requires agents to solve current tasks and safely learn reusable behavioral knowledge from experience. Recent work has made substantial progress toward self-improving agents through self-feedback and reflection ( Madaan et al., 2023 ) , verbal reinforcement from past failures ( Shinn et al., 2023 ) , reusable skill memory ( Wang et al., 2023 ; Li et al., 2026b ) , agentic long-term memory organization ( Xu et al., 2025 ) , and evolving symbolic contexts or playbooks ( Zhou et al., 2025 ; Zhang et al., 2026f ) . These methods show that storing lessons, memories, playbooks, or revised contexts can improve future performance without necessarily updating model weights. An episode-derived update may improve tasks that resemble the triggering episode while overgeneralizing to superficially similar but semantically different situations, conflicting with previously successful behaviors, or accumulating as stale persistent memory. Even in verifier-rich environments, where task success can often be checked after execution, existing self-evolution mechanisms lack a principled criterion for assessing an update’s transferability, retention value, and commitment risk. The central question is how to govern the transition from temporary experience to persistent agent state under transfer, safety, and regression constraints. We study when an experience-derived behavioral update should enter an LLM agent’s long-term memory. Our approach treats persistent updates as testable hypotheses. As shown in Fig. 1 , our approach temporarily applies each candidate update, evaluates its transfer beyond the source episode, robustness to targeted counterexamples, and preservation of archived successful behavior, and then commits, refines, or rejects it. We make the following contributions: ( i ) We identify a core failure mode of self-evolving agents: target improvement alone is an unreliable signal for persistent memory writing, because many apparently useful updates encode unsafe shortcuts or overly broad applicability conditions. ( ii ) We introduce Falsification-Gated Self-Evolution (FGSE), a verifier-grounded framework that treats candidate updates as testable hypotheses and performs structured commit–refine–reject triage before long-term retention. ( iii ) Across web, app, tool-use, and long-term memory settings, FGSE improves task performance while reducing falsification failures, regression damage, harmful committed updates, and post-commit violations compared with reflection-, memory-, and context-evolution baselines.
