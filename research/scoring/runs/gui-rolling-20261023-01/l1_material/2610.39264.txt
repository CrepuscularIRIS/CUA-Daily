title: Online Dense Reinforcement Learning with Planning-Grounding Agent for UI Navigation on Live IOS Apps
source: https://arxiv.org/abs/2610.39264

§Abstract
While frontier vision-language models demonstrate strong capabilities in user interface (UI) navigation, their high inference costs prohibit everyday use. Conversely, smaller models trained via supervised fine-tuning (SFT) or offline reinforcement learning often memorize static trajectories, leading to brittle execution and an inability to recover from errors. To address these limitations, we propose a novel online reinforcement learning framework that trains UI navigation agents directly on live iOS applications. Our framework decouples the agent into two specialized components: a Planning agent and a UI Grounding model. We rely on an LLM-as-a-Judge to provide comprehensive reward signals, combining dense, step-level feedback to evaluate intermediate progress with a terminal reward for overall task completion. To effectively leverage this dual reward structure, we optimize the agent using Proximal Policy Optimization (PPO) with step-level advantage estimation. Furthermore, we introduce GiGPPO, a novel neighbor-conditioned value estimation method that improves critic stability by leveraging reward signals from visually similar states across concurrent trajectories. To support this online training paradigm at scale, we introduce an efficient infrastructure that orchestrates hundreds of concurrent virtual iOS devices. Evaluations on rigorous benchmarks, including UINavBench, iOSWorld, and AndroidWorld, demonstrate that our online RL trained agents substantially outperform both SFT and terminal-only RL baselines while accelerating training convergence. Notably, our 8B RL agents achieve nearly a sevenfold improvement over the SFT baseline in out-of-distribution generalization to Android environments, while outperforming Gemini-3.5-Flash and tying with Gemini-3.1-Pro on real iOS applications.

§Introduction (from cached fulltext; cut at ~9000 chars)
UI Navigation agents, which are AI systems designed to perceive graphical user interfaces and autonomously execute sequences of actions to achieve user-specified goals, are gaining traction in both industry and academia. Their applications range from automatically completing tasks for users ( Qin et al., 2025a ; Gu et al., 2025 ) to A/B testing ( Lu et al., 2026 ) . While frontier models can be quite proficient at UI Navigation ( Jang et al., 2026 ; Agrawal et al., 2025 ) , they are expensive, often costing several dollars per task ( EasyClaw Research, 2026 ) , making them impractically expensive for frequent, everyday use. As a result, there has been a surge in interest for training small models for proficient UI navigation ( Yang et al., 2025 ; Chai et al., 2026 ) . However, current training methods suffer from significant weaknesses. Supervised Fine-tuning (SFT) tends to memorize training trajectories rather than learn generalizable strategies, resulting in brittle execution that struggles to recover from errors ( Zhou et al., 2025b ; Bai et al., 2024 ; Qi et al., 2024 ; Yan et al., 2025 ) . Existing Reinforcement Learning (RL) approaches largely rely on single-step RL that mirrors these same SFT limitations ( Yang et al., 2025 ; Yan et al., 2025 ) or rely on only a terminal reward at the end of a trajectory, providing a weak, sparse signal ( Bai et al., 2024 ; Wang et al., 2025 ; Qi et al., 2024 ; Zhou et al., 2025a ) . To address these challenges, we propose a novel framework, trained at a large scale on real iOS applications, that decouples the agent into two specialized components: a Planning Agent and a UI Grounding Model. Rather than training a single model to jointly handle planning and spatial localization, our architecture allows each component to be optimized for its specific objective. The Planning Agent observes the screen, maintains a history of past actions, and utilizes Chain-of-Thought reasoning to produce both an immediate step and a long-term plan. The immediate step is then passed to the Grounding Model, which translates it into a precise action and corresponding coordinates for on-device execution. Additionally, the Planning Agent’s action space includes an Ask_User primitive to handle underspecified tasks by requesting user preference specifications. Because grounding is a largely deterministic mapping problem effectively solved via SFT, this decoupling allows us to reserve computationally expensive RL for the Planning Agent, where open-ended reasoning and adaptation provide the most benefit. We optimize the Planning Agent in an online RL setting, centered on a robust LLM-as-a-Judge reward mechanism. To overcome the sparsity of terminal-only feedback, we combine two complementary signals. A Dense Reward evaluates whether each individual step makes meaningful progress while penalizing hallucinations and unproductive loops. A Terminal Reward assesses overall task completion. This dense, step-level feedback provides a rich signal throughout the trajectory, giving the model useful feedback even when terminal success is rare under the current policy. It further encourages exploration and explicitly teaches the agent to recover from unexpected states rather than failing when it deviates from a golden path. To effectively leverage this dense reward structure, we optimize the agent using Proximal Policy Optimization (PPO) with step-level Generalized Advantage Estimation (GAE). To prevent the agent from artificially prolonging trajectories to exploit step-level rewards, we use an asymmetric discounting strategy in our reward function that balances local process supervision with discounted dense rewards, combined with a terminal reward for successful task completion. Furthermore, we introduce GiGPPO, a novel neighbor-conditioned value estimation method that improves critic stability by incorporating reward signals from visually similar states across concurrent trajectories. Because online RL requires continuous interaction with real UI environments, we built a highly scalable device management system to support this training paradigm. By orchestrating a large pool of cloud-hosted iOS devices and utilizing rapid virtual machine snapshots, our infrastructure enables hundreds of parallel live trajectories. This allows the agent to generate fresh rollouts across concurrent environment instances without bottlenecking on sequential device interactions. To our knowledge, this work represents the first time UI navigation agents have been trained at-scale entirely on live iOS devices interacting with real iOS applications. We evaluated our trained agent system on public benchmarks, including UINavBench and iOSWorld, as well as AndroidWorld to test out-of-distribution performance. Our experiments demonstrate that our 8B online RL agents substantially improve upon the SFT baseline.
