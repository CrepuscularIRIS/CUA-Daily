title: State World Models: Execute the Rules, Generate the Pixels
source: https://arxiv.org/abs/2610.26811

§Abstract
Existing world models can generate action-conditioned video from a single image. Many focus on camera movement, allowing users to explore the generated scene. However, navigation alone does not ensure that an action follows persistent rules when its outcome depends on state that is invisible in the current frame. We present Stateful Harness, a framework that separates world evolution from video rendering to support stateful and rule-governed interaction. It maintains an evolving world state under specified rules, renders each resulting event with a frozen video model, and uses the generated clip to update the world state for the next turn. At each turn, the harness resolves the action selected by the user and compiles the resulting event into an instruction, while a preview clip from an editable 3D scene provides spatial and camera guidance. To evaluate rule compliance, we build WorldState-Bench, a benchmark of 50 counterfactual twin pairs that share an initial frame and action but differ in hidden state and required outcome. Under rule-only prompting, the best of the 11 evaluated video backends produces the required endings for both cases in 32% of pairs. For MiniMax-H3, specifying the required endings raises this rate from 32% to 64%, while the full harness reaches 92% with the same frozen model. These results support separating rule execution from video rendering for world interactions with hidden state.

§Introduction (from cached fulltext; cut at ~9000 chars)
Video generation has advanced rapidly, with recent models producing visually realistic videos with coherent motion ( Wan et al., 2025 ; Wu et al., 2025 ) . Building on this progress, interactive video world models condition generation on navigation signals, allowing users to move through and explore generated environments ( Parker-Holder and Fruchter, 2025 ; Wang et al., 2026 ) . Navigation control makes a generated scene explorable, but does not determine the consequences of interacting with it ( Parker-Holder and Fruchter, 2025 ; Wang et al., 2026 ) . Some video world models support richer interactions by conditioning generation on player or agent actions ( Valevski et al., 2025 ; Zhu et al., 2026a ) . However, a responsive video does not by itself ensure that an action has the outcome required by the world state and rules, or that its consequences persist across later interactions ( Ding et al., 2026 ; Xu et al., 2026a ) . For example, the same action should open a locked chest only when the player holds a key, even if the initial views are identical (Figure 2 ). Such distinctions require semantic state to record variables such as inventory and progress, together with an addressable spatial state to preserve scene layout and camera paths across turns. While prior systems incorporate explicit state through programmable engines, learned game variables, or reconstructed NPC state ( Huang et al., 2026 ; Lin et al., 2026 ; Deng et al., 2026 ) , their evaluations focus on selected mechanics and do not establish whether a frozen video model can render outcomes prescribed by newly specified rules involving hidden state. Explicit state alone does not ensure that the consequence required by its rules appears in the generated video. The central challenge is therefore to make state transitions authoritative and render their consequences faithfully. We present Stateful Harness , a framework that separates world evolution from video rendering to support stateful interaction under specified rules (Figure 1 ). It maintains an evolving world state under specified rules, renders each resulting event with a frozen video model, and uses the generated clip to update the world state for the next turn. Given a world description and an initial image, a coding agent defines the world state, available actions, and executable rules, while an editable 3D scene represents the spatial layout. The rules remain fixed as the world state evolves through user actions. At each turn, the user observes the current scene and selects an action, which the runtime resolves against the current state before rendering. The resolved event is compiled into a VisualScript instruction, and a preview clip from the updated 3D scene provides spatial and camera guidance. A frozen video model renders the event from these inputs and a visual anchor drawn from the initial image or preceding clip. A vision language model then interprets the generated clip and proposes updates to the semantic and spatial state based on the observed events. The runtime incorporates updates compatible with the fixed rules, and the resulting state determines the consequences of subsequent actions. Together, rule execution, video generation, and visual observation form a closed loop that yields state world models . To evaluate whether an action yields a visible event consistent with hidden state, we construct WorldState-Bench with a Change-to-Comply protocol. Change assesses whether the action produces a discernible event, and Comply assesses whether that event satisfies an executable rule. Each of the 50 cases comprises a counterfactual pair with the same initial frame, action, and rule program but different hidden values that require distinct outcomes. We introduce PairFollow and PairStrict as two metrics for joint evaluation of each counterfactual pair. PairFollow requires both clips to show their required endings, whereas PairStrict additionally requires the forbidden ending to be absent from both clips. Among eleven unwrapped video backends, the highest PairFollow score under the Rule-only condition is 32%. For MiniMax-H3, explicitly specifying the required ending increases PairFollow from 32% to 64%, although PairStrict reaches only 4%. With MiniMax-H3, the complete Stateful Harness framework achieves 92% PairFollow and 90% PairStrict on the same cases. Beyond the single-turn probe, the same closed loop carries state across longer episodes, as in the multi-turn duel of Figure 6 , and extends training-free to worlds whose custom rules and state are written as a new world definition.
