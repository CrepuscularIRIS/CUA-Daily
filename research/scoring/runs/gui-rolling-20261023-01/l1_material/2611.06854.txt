title: Visual Token Routing: Learning to keep tokens that matter
source: https://arxiv.org/abs/2611.06854

§Abstract
Computer-use agents (CUAs) have recently achieved superhuman performance on several long-horizon benchmarks. However, their computational cost limits their use in long-horizon tasks and real-time domains such as video games. A key bottleneck is representing each screenshot as thousands of visual tokens, which accumulate into long contexts as agents reason over extended interaction histories. We observe that most of these visual tokens are either semantically irrelevant to the agent's next action or temporally redundant across screenshots. Building on this observation, we introduce Visual Token Routing (VTR), a joint training framework for learning sparse visual representations that preserve the information needed for action prediction. In VTR, we train the vision-language model together with a lightweight spatio-temporal router that examines each image region in the current and previous screenshots and decides whether its visual token enters the language model. We optimize the router using an adaptive loss to keep the number of visual tokens as small as possible while minimizing performance degradation. With just 2,000 training steps, VTR matches the performance of the full-resolution model on OSWorld, CUA-World, and video game action prediction, while using 2.5-5.8x fewer visual tokens. These savings reduce inference cost by up to 3.3x and speed up prefill by up to 2.9x. VTR also outperforms lowering the image resolution and other baselines for dropping tokens, by up to 12.8 points on OSWorld. Overall, VTR enables computer-use agents to process only the visual tokens they need, allowing them to be used in long-horizon tasks and real-time domains at a fraction of the computational cost. Code and models are available at https://pranjal2041.github.io/vtr

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-use agents (CUAs), which operate software by observing screenshots and issuing mouse and keyboard actions, have recently achieved superhuman performance on several long-horizon benchmarks ( Xie et al., 2024 ; Aggarwal et al., 2026b ; Aggarwal et al., 2026a ) . However, their computational cost limits their use in long-horizon tasks and real-time domains such as video games ( Aggarwal et al., 2026a ; Abhyankar et al., 2026 ) . A key bottleneck is the representation of each screenshot as thousands of visual tokens, which accumulate into long contexts as agents reason over extended histories of interaction. For instance, Qwen3.5 ( Qwen Team, 2026 ) encodes a single 1080p screenshot into about 2,000 visual tokens, so an agent that keeps its full history on a 100-step task has over 200,000 visual tokens in its context by the final step. In video games, agents observe the screen many times per second, and even at a reduced resolution of 640\times 360 , one minute of play at 30 frames per second amounts to about 400,000 visual tokens. Furthermore, in real-time environments, speed is the primary bottleneck for frontier agents ( Aggarwal and Welleck, 2026 ) . Existing methods reduce the number of visual tokens by keeping the tokens that receive the most attention within each image ( Chen et al., 2024 ; Yang et al., 2025 ) , or by dropping tokens that remain unchanged across video frames ( Shen et al., 2025 ; Bagrov et al., 2025 ) . However, these hand-designed rules keep a fixed fraction of tokens or apply a fixed threshold to every input, regardless of what the agent needs for its next action. Other work learns which visual tokens to keep jointly with the model for single images in general visual question answering ( Huang et al., 2025 ; Ye et al., 2025 ) . However, computer-use agents face fundamentally new challenges, such as long histories of nearly identical screenshots, and actions that depend on small regions of the screen, like a cursor or a single spreadsheet cell. We observe that most visual tokens in an agent’s history are either semantically irrelevant to its next action or temporally redundant across screenshots. For instance, the taskbar and the empty parts of a document rarely affect the agent’s next click, and consecutive game frames share most of their background. Building on this observation, we introduce Visual Token Routing (VTR), a joint training framework for learning sparse visual representations that preserve the information needed for action prediction (§ 2 ; Figure 1 ). In VTR, a lightweight spatio-temporal router processes each image region across the current and previous screenshots and outputs a decision to keep the visual token or not. Dropped tokens are removed from the input sequence, so the language model processes only the kept tokens, which retain their original positional encodings. We train the router jointly with the language model to satisfy two objectives: (1) keeping as few visual tokens as possible, and (2) preserving the model’s accuracy in predicting the agent’s next action. However, training the router poses two challenges. First, dropping a token is a discrete decision that provides no gradient to the router, which we address by scaling each kept token by its keep probability, as in mixture-of-experts models ( Shazeer et al., 2017 ; Fedus et al., 2022 ) . Second, unlike mixture-of-experts models, where each token is processed by a fixed number of experts, the router must also decide how many tokens to keep. We therefore measure how much the screenshots help the model predict each action, using reference models trained with and without them, and adaptively weight the two objectives so that the model keeps this benefit while dropping tokens. In doing so, the router learns how many visual tokens each input needs while preserving the model’s performance, rather than relying on a fixed token budget. We use VTR to train vision-language models on computer-use trajectories and video game play, and evaluate them on OSWorld ( Xie et al., 2024 ) , CUA-World ( Aggarwal et al., 2026b ) , and video game action prediction. With just 2,000 training steps, VTR matches the performance of the full-resolution model in all three domains, while using 2.5-5.8 \times fewer visual tokens (Figure 4 ). These savings reduce inference cost by up to 3.3 \times and speed up prefill by up to 2.9 \times (Figure 5 ). In addition, VTR outperforms lowering the image resolution and hand-designed rules for dropping tokens, by up to 12.8 points on OSWorld. Furthermore, we find that learning visual token selection jointly with the model is crucial, improving performance by 13.2 points on OSWorld over the same router trained separately from the model. In summary, our contributions are three-fold.
