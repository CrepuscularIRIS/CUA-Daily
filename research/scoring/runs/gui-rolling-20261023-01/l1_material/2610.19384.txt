title: MMA-SafetyBench: A Benchmark for Multimodal Agent Safety Evaluation
source: https://arxiv.org/abs/2610.19384

§Abstract
Multimodal agents increasingly rely on visual interfaces to perceive state and select actions, creating an attack surface not captured by text-only safety evaluations. We study Visual Semantic Hijacking, in which deceptive but semantically meaningful interface elements, such as forged system alerts, cause an agent to depart from its authorized task. We propose a trajectory-guided procedure that identifies candidate injection points and inserts reproducible visual payloads into the observation stream. Using this procedure, we construct MMA-SafetyBench, which contains 1,083 adversarial trajectories across web automation, desktop GUI control, mobile navigation, document understanding, and video processing. Across nine evaluated models, Attack Success Rate (ASR) reaches 87.96%, while Semantic Compromise Rate (SCR) reaches 98.09%. A 1--3--5 scoring scheme distinguishes target-matching outputs, semantic disruption without a target match, and successful preservation of the benign task. Controls covering all nine models and five domains show that attacks persist under neutral prompts. A safety-priority prompt lowers ASR without eliminating the failure mode.

§Introduction (from cached fulltext; cut at ~9000 chars)
Computer-use agents can interpret screenshots, invoke tools, and act in software environments with limited human intervention [ 19 ] . As these systems receive broader operational permissions, errors induced by untrusted interface content can lead to actions rather than merely incorrect text. LLM-agent security research has largely centered on text carried by user instructions, tool responses, webpages, and system messages, including prompt injection, malicious tool use, and unauthorized instruction following [ 20 ] . Visual information now occupies an equally operational role: computer-use agents infer system state from screenshots [ 19 ] , multimodal models accept joint image-text inputs [ 12 ] , and web agents act through rendered interfaces [ 10 ] . Visual observations also create an attack surface. Forged system dialogs, spoofed buttons, and instructions embedded in document images can change how an agent interprets its task and selects actions. We call this failure mode Visual Semantic Hijacking . Existing multimodal safety research studies image-based attacks, visual jailbreaks, and adversarial images [ 18 , 12 , 17 ] , primarily through harmful model outputs. Multimodal-agent safety additionally requires measuring how visual content redirects action selection. This motivates a benchmark that connects visual instruction conflicts to agent intent and target-matching outputs. We address this gap with a trajectory-guided benchmark construction procedure . It identifies candidate injection points in multi-step reasoning-action traces and places context-matched visual payloads in the observation stream. Payloads are fixed before victim-model evaluation to reduce variation across repeated runs. Using this procedure, we construct MMA-SafetyBench , a suite of 1,083 adversarial trajectories across five domains: • Web Automation (200 trajectories): Deceptive DOM elements, including forged pop-ups and modified forms, are inserted into browser workflows to test for unintended transactions or unauthorized data disclosure. • OS-Level Interaction (209 trajectories): Forged system dialogs are inserted into desktop environments to test whether the agent issues unauthorized high-impact commands, such as DROP TABLES . • Mobile GUI Navigation (283 trajectories): Android-style warnings and permission dialogs interrupt multi-step tasks and request unauthorized system actions. • Visual Document Understanding (200 trajectories): Synthetic directives are embedded in resumes and receipts to test information extraction and redaction behavior. • Video Comprehension (191 trajectories): Forged alerts are inserted into the final retrieved frame to test whether recent visual content changes the answer or redirects the output. We benchmark nine representative vision-language models, encompassing proprietary systems (GPT-5, Claude 4.5 Sonnet, Gemini 3 Pro, and SEED-1.8) and open-weight counterparts (Llama-3.2-11B-Vision, InternVL3-38B, Kimi-K2.5, Qwen3-VL-32B, and GLM-4.6V). To score open-ended trajectories at scale, we use an LLM judge. A three-level 1–3–5 rubric separates target-matching outputs, semantic impairment without a target-matching output, and preservation of the benign task. We derive the Semantic Compromise Rate (SCR) from this rubric and report it alongside Attack Success Rate (ASR) . ASR reaches 87.96% in our evaluation. Because SCR includes both target-matching outputs and semantic impairment, it captures trajectories in which the payload changes the agent’s intent or disrupts the benign task without a target-matching output. Our contributions are: • a trajectory-guided procedure for locating injection points in multimodal-agent trajectories and constructing context-matched visual payloads; • MMA-SafetyBench, containing 1,083 trajectories across five visual-agent domains; and • an evaluation of nine models using ASR and SCR, together with neutral-prompt, clean-task, and safety-priority-prompt controls.
