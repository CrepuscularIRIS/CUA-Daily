title: ANGLER: Verifier-Grounded Benchmarking with an Adaptive Attacker for Web Agents
source: https://arxiv.org/abs/2610.41272

§Abstract
Web agents are increasingly deployed to complete tasks autonomously on real websites, where adversarially injected content can induce them to perform unauthorized actions. Existing evaluations primarily use fixed attacks or focus on a single attack type, and evaluate attacks at the text level rather than through real state changes, thus underestimating how vulnerable agents are to diverse attacks. To address the gap, we introduce REEF, a benchmark of red-teaming executable environments with faithful verification for measuring the security vulnerabilities of web agents. REEF covers 9 verifier-grounded websites spanning travel, commerce, productivity, media, and communication, and pairs every authentic benign task with a malicious objective delivered through 5 attack types at both the user and the environment level. REEF's state-based verifiers provide the execution feedback that drives ANGLER, an adaptive near-miss-guided lure evolution framework for red-teaming. Rather than evaluating a fixed attack set, ANGLER uses outcomes from prior rollouts to guide LLM-based attack mutation and candidate selection, prioritizing near-miss seeds during refinement. Across 8 VLM-based web agents, ANGLER achieves an end-to-end attack success rate (ASR) of 20.36%, compared with 15.24% for the non-adaptive setting. Compared with attack-free execution on the same benign tasks, attacks generated by ANGLER reduce benign task success rate (BSR) from 61.9% to 44.4%.

Recent advances in large language models and vision-language models enable web agents to navigate websites and complete multi-step tasks on behalf of users ( Gur et al., 2024 ; Zheng et al., 2024 ; He et al., 2024 ; Qi et al., 2025 ) . However, these capabilities also introduce security risks, as malicious instructions may induce web agents to perform unauthorized actions, such as sending messages, modifying settings, or completing transactions ( Wang et al., 2025a ; Syros et al., 2026 ; Evtimov et al., 2025 ) . Adversarial content can reach web agents through user-level attacks that manipulate user instructions or environment-level attacks that inject malicious content into webpages encountered during execution. If the agent follows such content, it may perform actions that are not authorized by the authentic user goal. A faithful security evaluation must therefore test attacks during interactive website execution and verify whether they cause unauthorized changes to website state. Existing security benchmarks provide executable environments for evaluating adversarial attacks against web agents and related tool-using agents. WASP ( Evtimov et al., 2025 ) , RedAgentBench ( Chen et al., 2026b ) , and SecureWebArena ( Ying et al., 2026 ) execute adversarial tasks in interactive environments, but evaluate agents using fixed and static attack cases or trajectories. However, these benchmarks do not adapt attack generation or selection during agent evaluation based on outcomes from previous rollouts, potentially missing vulnerabilities that could be uncovered through feedback-driven exploration. Although recent works have begun to introduce adaptive attacks, they are typically limited to a single attack type. Studies of pop-up and advertising-based injections each target a specific delivery channel ( Zhang et al., 2025 ; Wang et al., 2025a ) , while MUZZLE ( Syros et al., 2026 ) uses execution feedback to adapt attacks but focuses specifically on indirect prompt injection. Consequently, existing evaluations provide broad evaluation of fixed attacks or adaptive refinement within a narrow attack class. What remains missing for web agents security evaluation is an adaptive but reproducible framework across multiple attack types. However, simply adding an adaptive attacker to existing benchmarks is insufficient because newly generated attack plans must be validated against specific constraints and evaluated under consistent task contexts, objective definitions, and verifier rules. Therefore, we address these requirements with REEF and ANGLER, which combine a fixed benchmark specification with adaptive search. Built on 9 resettable AutoWebWorld environments ( Wu et al., 2026 ) , REEF pairs benign tasks with grounded malicious objectives across 5 attack types. A site compiler enforces attack constraints and checks plan validity, while programmatic verifiers assess outcomes from website state and committed artifacts.
