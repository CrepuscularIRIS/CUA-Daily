title: GenXR-Bench: Benchmarking Coding Agents for Interactive XR Development
source: https://arxiv.org/abs/2610.29014

§Abstract
Coding agents are rapidly advancing from single-file generation to long-horizon repository-scale engineering, yet the evaluation of their capabilities to author interactive extended reality (XR) applications remains an open challenge. Unlike traditional software, XR applications operate within dynamic 3D physical environments where runtime robustness depends jointly on continuous user motion, spatial input, and environmental sensing. We introduce GenXR-Bench, the first benchmark for the end-to-end evaluation of coding agents in XR software development. GenXR-Bench contains 112 expert-authored tasks spanning 24 feature implementations, 21 bug repairs, and 67 application generation tasks. Held-out tests combine scripted and adaptive interactions with programmatic and visual assertions to evaluate core functionality and runtime behavior. GenXR-Bench's testing suite achieves 96.5% accuracy against blinded expert judgments of 124 candidate applications executed on consumer XR hardware. Evaluating 10 models on GenXR-Bench, we find that the strongest configuration achieves only 50.9% overall Pass@1. Failure analysis identifies recurring misunderstandings in asynchronous sensor lifecycles, physical grounding, and embodied interaction semantics. GenXR-Bench establishes a reproducible testbed for evaluating coding agents in the interactive and physically situated conditions of spatial computing.

§Introduction (from cached fulltext; cut at ~9000 chars)
Coding agents have become increasingly capable of building interactive software. Recent benchmarks have expanded beyond algorithmic problems ( Jimenez et al., 2024 ) to end-to-end interactive applications, evaluating how models handle dynamic user input in web and desktop environments ( Lu et al., 2025 ; Zhang et al., 2025 ) . Extended reality (XR) introduces a distinct set of challenges for code generation. Unlike 2D software governed by discrete event loops, XR applications operate within continuous 3D physical spaces. Functional correctness depends on the real-time coordination of head and hand kinematics, spatial coordinate transformations, environmental sensing, mixed-reality rendering, and physical ergonomics. Consequently, generating XR software requires reasoning about spatial mathematics, runtime sensor lifecycles, and embodied interaction semantics that are absent in flat-screen software engineering. Despite these demands, evaluating coding agents in XR remains largely unexplored due to an execution and verification bottleneck. Existing coding benchmarks rely on programmatic unit tests ( Jimenez et al., 2024 ) or browser action runners ( Lu et al., 2025 ) , which cannot verify spatial scene graphs or continuous 3D tracking inputs. Conversely, 3D code-generation benchmarks focus primarily on generating static shapes rather than reactive software ( Gao et al., 2026 ) , while prior XR benchmarks focus on hardware performance and runtime systems rather than evaluating generative code synthesis ( Huzaifa et al., 2021 ; Bierbaum et al., 2003 ; Popescu et al., 2025 ) . Evaluating agent-generated XR software requires an automated and comprehensive testing suite capable of simulating physical environments, exercising embodied user actions, and verifying runtime behavior across diverse implementations. We present GenXR-Bench, the first benchmark for end-to-end evaluation of coding agents in XR software development. GenXR-Bench comprises 112 expert-curated tasks across two tiers: (1) SDK engineering tasks , consisting of 24 feature implementations and 21 bug repairs in core subsystems such as occlusion shaders, raycast reprojection, and gestural state machines; (2) Application generation tasks , consisting of 67 end-to-end experiences spanning education, healthcare, daily living, design, and entertainment, distilled from a taxonomy of 436 peer-reviewed XR systems papers. To support reproducible, headless execution without the proprietary GUI navigation and multi-gigabyte build toolchains of desktop game engines, all tasks are built on XR Blocks ( Li et al., 2025 ) , an open-source WebXR framework. To test candidate implementation at scale, we introduce GenXR-Test, the first set of testing tools that pair deterministic kinematic actors with adaptive VLM-controlled agents in simulated XR environments, evaluating runtime results through both scene-graph assertions and scoped visual checks. To validate our authored evaluation suite, eight blinded XR experts evaluated 124 candidate applications executed on consumer XR hardware. Across 372 evaluation runs, our automated suite achieved 96.5% mean accuracy against human expert ground truth with a 4.0% flakiness rate, demonstrating that simulator-based evaluation reliably reflects physical device execution. We evaluate 10 model configurations on the full benchmark. The strongest configuration achieves an overall Pass@1 of 50.9%, with performance dropping to 29.2% on SDK feature tasks. Diagnostic analysis reveals recurring failure modes across models: 64.4% of failed runs exhibit coordinate-transformation errors, 44.9% encounter asynchronous sensor initialization races, and 34.5% fail to distinguish bimanual interaction semantics. In summary, our contributions are as follows: • GenXR-Bench : An open-source benchmark of 112 expert-authored tasks evaluating coding agents on XR software engineering, spanning SDK-level feature development, bug repair, and end-to-end application synthesis. • GenXR-Test : XR tooling for automated evaluations using scripted kinematic actors, adaptive VLM agents, runtime state assertions, and scoped visual checks in simulated 3D environments. • Hardware-Grounded Validation : A validation study across 372 physical XR device trials demonstrating that simulator-based evaluation achieves 96.5% agreement with expert human judgment with low flakiness (4.0%). • Empirical Analysis of Coding Agents in XR : An evaluation of 10 model configurations identifying key bottlenecks in frontier models, including coordinate-frame handling, sensor lifecycles, and embodied interaction semantics.
