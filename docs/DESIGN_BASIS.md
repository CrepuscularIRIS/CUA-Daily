# 方法依据与适配边界

本项目借鉴 ResearchStudio 的问题定位、研究操作分析和 Reel 资产/画报流程，以及 Open Scientist 的领域模式归纳和有来源的审稿期望。

实际评分依据已经是本项目从领域论文中归纳的 patterns/main 与 patterns/sub。原 ResearchStudio 15＋31 仅保留作方法历史来源；它们不是本领域评分表，也不是每篇必做的分类层。

评分路径：具体操作 → 匹配领域模式 → 适用的成功条件/失败模式/审稿期望 → 论文证据 → G/M/X/E 汇总。不能先凭通用印象评分再贴卡片标签；不能按匹配卡数或满足条数直接加减分。

ResearchStudio IdeaQuality 的原评分面向没有实验的 idea，本项目不能直接套用其总分。当前领域权重为实用编辑规则，未声称从真实审稿或录用数据标定。真实 review、论文实践、作者局限与模型推测必须分开。

已有领域卡不重建；不对每篇运行新 idea 生成、全量 novelty 检索或完整 Open Scientist study。方法插件无需重新安装或探测，评分任务消费已有资产即可。

Reel 取用 paper2assets → paper2poster 的原文资产、内容选图和实际渲染核验思路；默认交付画报。显式运行原版插件时需遵循其真实输出要求，不能把本项目适配流程声称为原插件全流程完成。
