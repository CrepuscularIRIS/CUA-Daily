# 给 claude-kimi 的启动指令

以下文字在对应仓库根目录的 claude-kimi 会话中使用。三个项目各自执行；model type 已配置好，不再配置或探测。

> 请阅读并执行 docs/agents/LOCAL_SCORING_PROMPT.md，先核对本仓库范围与评分规则。
> 严格按 ResearchStudio Idea 原15张主卡＋31张子卡识别研究操作，再做本领域 pattern 映射、gap 分析、审稿期望与证据评分。
> 使用现有 model type 派 Subagent：6.1 Sol 和 Sonnet 5.5 对同批论文独立初评，Opus 5.5 逐篇聚合与处理分歧。
> 默认每批5篇、每轮并行2批；逐轮验收、保存进度、继续下一轮，完成后由总控汇总并本地提交。不要覆盖已有未提交工作。
> 先完成评分，再按动态阈值选出通常不足10篇；只有选中论文交给 GLM 5.3，按 docs/agents/REEL_PROMPT.md 制作并核验画报。
> 保留完整的两席判断、Opus裁决、最终分项和引用。缺材料与未解决分歧如实记录，不能按0分代替或伪称完成。
> 不重建模型配置或调度平台，不续跑旧分数/旧批次；按现有能力执行上述研究与评分流程。

这是后续执行指令；本次文档准备没有启动批量评分或 Reel。
