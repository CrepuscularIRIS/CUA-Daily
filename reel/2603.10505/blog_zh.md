# VeriEnv：在克隆网站里训练网页智能体，奖励直接从数据库读取

*CUA Radar 对 arXiv 2603.10505v1（Chae、Park、Ritter）的解读。本文是第三方对论文所报告内容的整理，并非作者背书。海报见 `poster.png`。论文：https://arxiv.org/abs/2603.10505v1 · 代码：https://github.com/kyle8581/VeriEnv（论文称代码和资源将在论文被接收后发布）*

## 问题：真实网站不适合做训练场

自我演化的网页智能体会自己生成任务、尝试执行，再从结果中学习。论文指出，在真实网站上这样做有三个障碍。第一，探索可能不安全或受限：动作可能影响其他用户、违反平台政策，或被 Cloudflare 和 CAPTCHA 拦截。第二，自生成的任务常常描述不充分，存在多个合理答案。第三，奖励通常由 LLM 担任评判（LLM-as-a-judge），作者认为它比基于验证的奖励更容易出错。VeriEnv 的做法是把训练从真实网站上挪开：先克隆网站，再用克隆站自己的数据库判断任务是否完成。

## VeriEnv 是什么

被训练的是一个网页智能体，它通过浏览器动作和观察与克隆网站交互（论文总览图中写有 BrowserGym 接口；正文没有说明观察是截图、无障碍树还是 DOM）。平台只有 web。在 CUA Radar 板上，这篇论文属于子模式 K13“从检查器/规范出发合成任务，使可验证奖励天然存在”，其上层主模式为“把奖励建立在可执行检查器上”。

机制分三部分。

1.  **环境克隆。** 一个编码智能体（GPT-5.2，通过 Cursor CLI 驱动）拿到真实网站的截图，构建一个合成环境 (C, D, P)：应用代码 C、数据库 D，以及一个 Python SDK P，用来受控地访问内部状态以查询和验证。它还会编写启动与重置脚本。随后编码智能体用 Playwright MCP 测试已部署的克隆站，写 bug 报告并修补，循环进行。作者说明克隆站与原站并不完全相同，但保留了训练所需的功能结构。
2.  **可验证的任务与判定器。** 由 LLM 为每个网站写约 50 个任务。每个任务附带一段使用 SDK 的验证程序。运行这段程序既能检查任务是否可执行，又能得到期望答案，该答案成为基于规则的判定器（例如要求答案 `must_include` 某个条目的名称和价格）。回合结束时，判定器查询数据库状态并返回二值奖励。
3.  **训练。** 论文以基于奖励的拒绝采样微调（rejection fine-tuning）作为示例方法：对每个任务采样轨迹，只保留通过验证器的轨迹，再用它们微调。新任务和新轨迹会持续并入训练。训练使用 LLaMA-Factory，两个 epoch，两张 NVIDIA A40。SDK 只供验证器使用，智能体始终无法访问；环境在沙箱中运行，外部网络被关闭。

论文报告的规模：149 个网站（参照 Mind2Web 与 Mind2Web-Online 的网站列表选取），共 7,400 个任务，其中简单 2,972 个（40.2%）、中等 2,900 个（39.2%）、困难 1,528 个（20.6%）。每个网站平均耗时 83.5 分钟、花费 \$3.6（含调试和任务生成）。训练实际使用其中 97 个网站。

## 论文报告的结果

## 论文自带的对照实验说明了什么

- **相同基座。** 每组中的基线都从同一个基座模型出发，因此比较的是训练数据，而不是不同模型。在 Qwen3-4B 上，Synatra 和 ADP 在 WebArena-Lite 上都低于或接近基座（3.64 和 6.06，对比 7.88）；作者报告说 ADP 混合数据损害了 Qwen 的动作格式。在 LLaMA 上，ADP 在 Mind2Web-Online 达到 24.09，VeriEnv 为 24.55；作者把 ADP 在那里的提升归因于其训练数据与评测分布的重叠。
- **留出网站。** 重叠网站已排除，因此论文称 WebArena-Lite 对于克隆训练站是完全域外（fully out-of-domain）的。
- **环境质量的人工检查。** 四名计算机背景的研究生对生成的网站与任务打分。功能正确率平均 90.3%（导航和表单 100%，搜索 81%），视觉质量 4.7（满分 5），任务可执行率 90%，判定器正确率 76%，平均 Cohen’s κ = 0.61。判定器最常见的错误来自数据库重置时没有保留随机种子；作者称重新运行验证程序即可检测并解决。
- **站点专精训练对比 PAE**（图 4，正文无数字）。在单个网站的克隆站内训练（WebArena 的网站，仅通过其克隆站使用），与使用真实网站和 VLM 评判的 PAE 比较。作者报告 VeriEnv 的提升更大、更稳定，在 CMS 和 Shopping 上最明显。
- **规模效应**（图 5，正文无数字）。随着训练环境比例增加，两个基准上的表现总体上升，而使用固定数据的基线大致持平。

## 证据较薄弱之处

- **没有组件消融。** 与 PAE 的比较同时改变了多件事（真实站 vs 克隆站、不可验证 vs 可验证任务、VLM 评判 vs 规则评判），因此无法分离出究竟是哪一部分起作用。
- **没有报告随机种子、标准差或置信区间**；每个格子只有一个数字。
- 绝对成功率仍然很低：Qwen3-4B 在 WebArena-Lite 上最好为 13.94，而报告的 GPT-4o 为 31.52。分站点结果有好有坏：Qwen3-4B 加 VeriEnv 后 GitLab 为 12.50，低于基座的 13.89；Mind2Web-Online 困难任务为 6.98，低于基座的 11.63。
- Mind2Web-Online 用 WebJudge-7B 这个模型评判器打分，因此即使训练奖励可验证，评测一侧并非规则验证。论文除上述描述外，没有说明拒绝采样微调的轨迹由哪个模型采样。
- 判定器正确率 76% 意味着部分训练奖励可能有误。从合成到真实的差距是被论证为“远小于机器人领域”，而不是被测量出来的，作者也说克隆站与原站并不相同。各节中的网站数量也不一致（表 1 为 149 个；筛选图中为 136 个候选、97 个通过验证）。
- 只尝试了拒绝采样微调；在这些环境上做强化学习留作未来工作。

## CUA Radar 的判断

CUA Radar 给这篇论文打 **74 分（★★★）**，证据等级 **transfer**。判定记录认可在线评测、留出网站、开源基线、成本报告，以及经过检验的验证器（任务可执行率 90%，判定器正确率 76%）；把方差和预算对齐标为不清楚，把组件消融标为未报告，代码为已宣布但尚未发布。判定还标记了一个反模式 AP2：把合成环境当作训练世界，却没有测量它与真实目标之间的差距。CUA Radar 没有复现任何实验，本文所有数字均来自论文（版本 v1）。
