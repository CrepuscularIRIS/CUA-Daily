# K25 — Augment action-only traces with generated reasoning
_parent: **Train the Policy on Own, Replayed and Corrected Trajectories** ([`trajectory_level_policy_training`](../main/trajectory_level_policy_training.md)) · status: candidate_pattern · source card: `K25-reasoning-augmentation-of-action-traces.md` (frozen domain `cua-agents/v1`)_

## Operation
prompt a VLM with the ground-truth action (or bootstrap from an early model and keep thoughts whose sampled action matches) to write per-step thoughts/low-level instructions, then train on mixtures of reasoning detail

- Status: candidate_pattern

## When it works
- Ground-truth trajectories available; offline closed VLM for augmentation (2412.04454#s2)
- Bootstrapped thoughts whose sampled action matches ground truth avoid superficial rationalisation (2501.12326#s2)

## When it fails
- Single-sample system-2 decoding is worse in-domain (irrelevant/hallucinated reasoning); better OOD and with Best-of-N (2501.12326#s2)
- Redundant actions in source trajectories yield wrong reasoning (7.8%) (2412.04454#s2)

## Counterexamples
- none found in the readings
