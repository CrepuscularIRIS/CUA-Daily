# K30 — Stratify online success by human reference length and audit failure causes
_parent: **Make Online Evaluation Discriminating** ([`online_evaluation_methodology`](../main/online_evaluation_methodology.md)) · status: candidate_pattern · source card: `K30-difficulty-stratified-online-evaluation.md` (frozen domain `cua-agents/v1`)_

## Operation
build or reuse tasks with human reference step counts, report success per length stratum and efficiency/budget-exhaustion, and audit failures

- Status: candidate_pattern

## When it works
- Validated, de-shortcut task set (47% of sampled Mind2Web tasks invalid/outdated; naive search agent 51% vs 22%) (2504.01382#s2)
- Fixed step budget and deterministic resettable apps (2609.07712#s3)

## When it fails
- Success falls monotonically with length for every agent (GPT-5 43.6 -> 14.1%) (2609.07712#s3)
- Live sites drift; harnesses and step caps differ across agents (2504.01382#s2)

## Counterexamples
- none found in the readings
