# K19 — Dense step-level process rewards for multi-turn GUI RL
_parent: **Reward with Learned Outcome and Process Judges** ([`learned_outcome_and_process_judges`](../main/learned_outcome_and_process_judges.md)) · status: case · source card: `K19-process-reward-dense-credit.md` (frozen domain `cua-agents/v1`)_

## Operation
score every step with a PRM trained on human step labels and use the scores as dense rewards (PPO with GAE) or as GRPO accept/reject reward

- Status: case

## When it works
- In-distribution PRM training data from the same environment; human labels (94.9% held-out accuracy) (2509.23738#s1)

## When it fails
- OOD apps and reward hacking not analysed; single run (2509.23738#s1)
- Below oracle reward on offline single-step GRPO (2509.23738#s3)

## Counterexamples
- none found in the readings
