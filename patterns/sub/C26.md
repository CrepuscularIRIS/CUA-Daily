# C26 — Single-step click-in-box grounding benchmarks
_parent: **Make Online Evaluation Discriminating** ([`online_evaluation_methodology`](../main/online_evaluation_methodology.md)) · status: candidate_pattern · source card: `K26-grounding-click-benchmark.md` (frozen domain `cua-agents-core/v1`, where it is K26) · domain: cua-agents-core_

## Operation

- collect screenshots with instructions and target boxes split by platform and text vs icon, and score whether a predicted point falls inside the box.
- Status: candidate_pattern (3 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Exposes that natural-image grounders fail on GUIs and that icons are harder than text. [2401.10935#s4, 2504.07981#s1]
- Expert-captured high-resolution professional screens expose a large gap (best 18.9%). [2504.07981#s1]
- Auditing removes ~11% annotation errors while preserving rankings. [2410.23218#s4]

## When it fails

- Single-step static screenshots measure no planning/execution; point-in-box ignores near misses; small English sets. [2401.10935#s4, 2504.07981#s1]
- Rewriting items changes difficulty so versions are not comparable. [2410.23218#s4]
