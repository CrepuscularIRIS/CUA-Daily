# C15 — Compress interaction history: recent steps at full fidelity, older steps as model-written text
_parent: **Structure the Prompted Agent Loop: Context, Hierarchy and Post-Action Reflection** ([`agent_loop_context_control`](../main/agent_loop_context_control.md)) · status: candidate_pattern · source card: `K15-history-summary-compression.md` (frozen domain `cua-agents-core/v1`, where it is K15) · domain: cua-agents-core_

## Operation

- keep only the last few screenshots/steps verbatim and replace older history by text (a running progress summary from a separate LLM, an executor-log summary returned to an orchestrator, episodic summaries, or action-only text).
- Status: candidate_pattern (4 full-text paper(s)).
- Transfer notes: n/a

## When it works

- A separate planning agent writing 'completed contents' gives the largest ablation drop when removed (SR 88.6 -> 59.1 basic) and removes late-sequence error concentration. [2406.01014#s1]
- Three recent screenshots plus L1 action text beats one screenshot; more screenshots give marginal gains at extra tokens; L2 text history adds nothing. [2508.09123#s4]
- Isolated executor memories with summaries keep each agent focused (author claim). [2508.03923#s2]

## When it fails

- Summaries returning only the final state hide intermediate mistakes from the orchestrator (mistyped cell scrolled out of view). [2508.03923#s2]
- Long-horizon tasks (>30-50 actions) still lose coherent context. [2508.09123#s4]
- Summary error propagation not measured; hierarchical memory unablated. [2406.01014#s1, 2509.02544#s2]

## Counterexamples

- Agents that keep actions but not their outcomes loop (endless scrolling). [2405.14573#s3]
