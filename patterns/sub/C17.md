# C17 — Decompose into a manager that plans subgoals and workers that execute them
_parent: **Structure the Prompted Agent Loop: Context, Hierarchy and Post-Action Reflection** ([`agent_loop_context_control`](../main/agent_loop_context_control.md)) · status: candidate_pattern · source card: `K17-manager-worker-hierarchy.md` (frozen domain `cua-agents-core/v1`, where it is K17) · domain: cua-agents-core_

## Operation

- have a manager (host agent, planner LLM, orchestrator) decompose the instruction into subgoals/subtasks (linear, DAG, or planning tree), hand each to a worker that acts on the GUI and reports completion, and re-plan between subgoals.
- Status: candidate_pattern (6 full-text paper(s)).
- Transfer notes: HTN/options analogy holds when subgoal termination is checkable; GUI workers self-declare completion, which is the weak link.

## When it works

- Separating planning from action decisions raises satisfaction on long mobile tasks (Mobile-Agent-E 75.1 vs 53.0) across three backbones. [2501.11733#s1]
- A manager passing subtask results through a communication hub matters for interdependent multi-app tasks (removal: SR 56% -> 12%). [2502.14282#s2]
- Proactive full replanning after each subgoal beats reactive replanning (+4.62 / +6.15 points), more with longer budgets. [2504.00906#s2]
- Agent-maintained plan trees (branch/prune) raise WebArena SR 38.2% -> 43.1% by abandoning failed strategies. [2410.13825#s5]
- Two-level host/app agents handle cross-application Windows requests (80% on 5 requests). [2402.07939#s1]

## When it fails

- No role-removal ablations for several systems, so gains cannot be assigned to the hierarchy alone; extra per-step cost. [2501.11733#s1, 2402.07939#s1, 2402.07456#s4]
- Weaker backbones degrade after decomposition (Qwen2.5-VL full framework below its single agent). [2502.14282#s2]
- Planning failures from noisy subtask information are the most frequent failure; no infeasibility prediction. [2504.00906#s2]
- Plan pruning resets only the agent's context, not the web state; multisite SR stays low. [2410.13825#s5]

## Counterexamples

- Agent S2 drops the manager on AndroidWorld because tasks are short. [2504.00906#s2]
