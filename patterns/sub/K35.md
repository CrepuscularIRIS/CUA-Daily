# K35 — Object-centric slot world model for relational dynamics
_parent: **Learn GUI Dynamics and Train in Them** ([`learn_and_train_in_gui_world_model`](../main/learn_and_train_in_gui_world_model.md)) · status: case · source card: `K35-object-centric-latent-world-model.md` (frozen domain `cua-agents/v1`)_

## Operation
encode frames into object slots and predict next slots with an action-conditioned transformer separating temporal and relational attention

- Transfer: Analogue for GUIs: element-level (DOM/a11y) structured state as the world-model latent (cf. K03/K04).

- Status: case

## When it works
- Simple synthetic scenes; continual encoder fine-tuning for unseen states (2410.08822#s1)

## When it fails
- Deterministic predictions; scaling to complex real data open (2410.08822#s1)
