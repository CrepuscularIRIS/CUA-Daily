# K33 — Reach otherwise unreachable app states via static analysis and runtime instrumentation
_parent: **Synthesise Tasks from Exploration and History** ([`exploration_driven_task_synthesis`](../main/exploration_driven_task_synthesis.md)) · status: case · source card: `K33-code-analysis-instrumented-state-reaching.md` (frozen domain `cua-agents/v1`)_

## Operation
infer activation conditions of unreached activities from decompiled code, generate and refine Frida hooks that fake external results, and expose them to a fuzzer

- Transfer: For GUI agent environments: a route to put real apps into hard-to-reach start states for task synthesis or twin calibration, at the cost of non-genuine state.

- Status: case

## When it works
- APK decompilable, Frida attachable, transition graph extractable (2601.21253#s1, 2601.21253#s2)

## When it fails
- Mocked values may not initialise realistic state; fuzzer may dismiss injected widgets (2601.21253#s2, 2601.21253#s3)

## Counterexamples
- none found in the readings
