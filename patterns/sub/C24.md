# C24 — Evaluate agents live on real apps/sites with human success judgement
_parent: **Make Online Evaluation Discriminating** ([`online_evaluation_methodology`](../main/online_evaluation_methodology.md)) · status: candidate_pattern · source card: `K24-human-judged-live-evaluation.md` (frozen domain `cua-agents-core/v1`, where it is K24) · domain: cua-agents-core_

## Operation

- run the agent on real live apps, websites or desktops and have humans judge success, rubric satisfaction, step correctness or failure category, sometimes also gating harmful actions.
- Status: candidate_pattern (5 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Captures multiple valid paths that offline replay misses and can reorder models. [2401.01614#s4]
- Rubric/subtask scoring exposes gaps such as subtask vs instruction success (GPT-4o 41.8% SSR vs 8.0% SR). [2502.14282#s4, 2501.11733#s4]
- Failure attribution (planning / action / critic) points to missing critic modules. [2411.10323#s3]

## When it fails

- Small task sets (20-90), no inter-annotator agreement, live drift prevents reproduction. [2401.01614#s4, 2401.16158#s4, 2501.11733#s4, 2502.14282#s4, 2411.10323#s3]
- Human gating and manual pop-up closing mean untrusted content is not tested. [2401.01614#s4]

## Counterexamples

- None recorded.
