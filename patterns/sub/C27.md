# C27 — Diagnose whether agents believe pixels or serialized structure when the two disagree
_parent: **Expose the Screen as Indexed Elements and Pruned Structure** ([`structured_screen_observation`](../main/structured_screen_observation.md)) · status: case · source card: `K27-channel-conflict-reliance.md` (frozen domain `cua-agents-core/v1`, where it is K27) · domain: cua-agents-core_

## Operation

- pair GUI state probes in which one channel (DOM/a11y text) is edited or naturally stale while pixels define the gold value, measure structure-following, sweep action-output formats, and test recovery after a first-step conflict.
- Status: case (1 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Measures over-trust of structure only when pixels are informative (PFG 0.30-0.75 despite 0.85-0.93 pixel accuracy). [2607.04334#s1]
- Naturally stale DOM snapshots and ghost a11y nodes are followed frequently (0.38-0.88; up to 0.99). [2607.04334#s2]
- Structure-following rises with how directly the action names the structured channel (coordinate 0.11 to text label 0.98). [2607.04334#s3]

## When it fails

- Coordinate actions resist swap hijack but have higher baseline error and still click phantom elements; neither binding is safe. [2607.04334#s3]
- Early conflict is unrecoverable in multi-step click episodes without reflection. [2607.04334#s5]
- Only discrete forced-choice variables, click tasks and 7B models. [2607.04334#s1, 2607.04334#s3]
