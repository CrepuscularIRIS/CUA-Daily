# C19 — Accumulate reusable app knowledge, tips, shortcuts or tools from the agent's own runs
_parent: **Retrieve Past Experience and Knowledge into Context** ([`experience_memory_retrieval`](../main/experience_memory_retrieval.md)) · status: candidate_pattern · source card: `K19-experience-library.md` (frozen domain `cua-agents-core/v1`, where it is K19) · domain: cua-agents-core_

## Operation

- explore apps or solve self-proposed tasks, have an LLM distil what worked into a persistent store (element-function documents, Tips, precondition-guarded Shortcut macros, code tools), and inject the relevant parts into later tasks.
- Status: candidate_pattern (3 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Exploration-derived element documents raise AppAgent SR 48.9% -> 73.3% (84.4% from demos) when element ids are stable. [2312.13771#s2]
- Tips/Shortcuts raise Mobile-Agent-E SS 75.1 -> 86.9 and reduce reasoning time with GPT-4o. [2501.11733#s3]
- A self-directed curriculum produces tools that solve SheetCopilot tasks (0% -> 60%). [2402.07456#s3]

## When it fails

- Gain small or absent with Gemini-1.5-pro; shortcuts misused on misperceived preconditions; flawed shortcuts propagate errors; reflectors saw future queries. [2501.11733#s3]
- Transfer to unseen apps / changed element ids untested; same apps for exploration and test. [2312.13771#s2]
- No gain on GAIA L3; learning explores the same benchmark's dev set; 20-task evaluation. [2402.07456#s3]

## Counterexamples

- None recorded.
