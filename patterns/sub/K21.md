# K21 — Semi-online RL: roll out over expert trajectories with own history and patched mismatches
_parent: **Train the Policy on Own, Replayed and Corrected Trajectories** ([`trajectory_level_policy_training`](../main/trajectory_level_policy_training.md)) · status: case · source card: `K21-semi-online-expert-replay.md` (frozen domain `cua-agents/v1`)_

## Operation
step through static expert trajectories conditioning on the policy's own generated history, patch mismatched actions with the expert action up to a budget, and use group-in-group step/episode advantages; evaluate with the same first-mismatch protocol (SOP)

- Status: case

## When it works
- Expert trajectories available; correctness defined by exact match (2509.11543#s1)
- SOP correlates with AndroidWorld success (R^2=0.934) (2509.11543#s3)

## When it fails
- Valid alternative actions are treated as mismatches; non-expert branches never see real next states (2509.11543#s1, 2509.11543#s3)
- Gains shrink with model size (2509.11543#s1)
