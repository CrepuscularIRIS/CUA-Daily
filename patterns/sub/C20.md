# C20 — Prompt a fixed observe-think-act schema at every step
_parent: **Structure the Prompted Agent Loop: Context, Hierarchy and Post-Action Reflection** ([`agent_loop_context_control`](../main/agent_loop_context_control.md)) · status: candidate_pattern · source card: `K20-structured-thought-loop.md` (frozen domain `cua-agents-core/v1`, where it is K20) · domain: cua-agents-core_

## Operation

- prompt the frontier model each step to describe the screen, reason about the goal/plan, then emit one action (plus optional history summary), terminating by a self-declared stop; optionally choose when to take screenshots.
- Status: candidate_pattern (5 full-text paper(s)).
- Transfer notes: n/a

## When it works

- CoT gives GPT-3.5 a modest WebArena gain (+2.34 points). [2307.13854#s4]
- Iterative self-planning completes simple-to-abstract mobile instructions on a small suite. [2401.16158#s2]
- A fixed CoT schema with a Computer API gives Navi's WindowsAgentArena baseline (19.5%) and SOTA Mind2Web over SeeAct. [2409.08264#s3]
- Selective screenshotting in a ReAct loop is claimed to lower cost. [2411.10323#s2]

## When it fails

- Observation bias, ignoring prior inputs, repeated actions to step limit, and the 'unachievable' hint causing early stopping. [2307.13854#s4]
- Visual-language misalignment between stated target and chosen id; weaker models hallucinate on long contexts. [2409.08264#s3]
- Premature plan changes, imprecise drags/double-clicks, and self-declared completion without checker. [2411.10323#s2, 2312.13771#s3]
- Small benchmarks with no baselines. [2401.16158#s2]

## Counterexamples

- Including an observation-description step (L3) at inference underperforms L2 in trained policies because irrelevant descriptions mislead. [2508.09123#s3]
