# C34 — Defend against injections inside the same model's context (prompts, delimiters, role hierarchy, paraphrase, detectors)
_parent: **Defend Agents Against Untrusted Observations: Prompting, Gating and Isolation** ([`injection_defense_isolation`](../main/injection_defense_isolation.md)) · status: candidate_pattern · source card: `K34-in-context-injection-defenses.md` (frozen domain `cua-agents-core/v1`, where it is K34) · domain: cua-agents-core_

## Operation

- add defensive system prompts or delimiters, place web content at lowest instruction-hierarchy privilege, paraphrase untrusted text, run injection detectors, or self-caption images for consistency checks.
- Status: candidate_pattern (5 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Specific per-step prompts reduce pop-up ASR but leave task success low. [2411.02391#s3]
- A self-captioning consistency check nearly removes captioner-attack ASR when the defender LM sees raw images. [2406.12814#s6]
- Defensive system prompts lower ASR somewhat for some models (roughly halve in RedTeamCUA; GPT-4o in WASP). [2504.18575#s4, 2505.21936#s3]

## When it fails

- Generic defensive prompts give no gain (pop-ups, EIA, captioner attack); malware scanners flag nothing. [2411.02391#s3, 2409.11295#s3, 2406.12814#s6]
- Instruction hierarchy did not prevent hijacking (>50% of cases still influenced). [2504.18575#s4]
- Detectors catch 0-30% of high-risk injections; consistency checks are attackable by CLIP attacks and costly. [2505.21936#s3, 2406.12814#s6]

## Counterexamples

- Human confirmation checks cut Operator ASR 30.89% -> 7.57%, but assume an attentive human. [2505.21936#s3]
