# K27 — Retrieve stored past experience into the agent's context
_parent: **Retrieve Past Experience and Knowledge into Context** ([`experience_memory_retrieval`](../main/experience_memory_retrieval.md)) · status: candidate_pattern · source card: `K27-experience-memory-retrieval.md` (frozen domain `cua-agents/v1`)_

## Operation
store summaries or raw trajectories of past episodes/subtasks keyed by task/state embeddings and retrieve the nearest ones into the context — as text summaries or compressed continuous embeddings — at planning or action time

- Status: candidate_pattern

## When it works
- Experience comes from the same applications/environments (self-supervised exploration on benchmark initial states) (2410.08164#s2)
- Continuous (Q-Former) memory scales log-linearly with memory size where text memory degrades beyond ~10 items (2510.09038#s1)
- Summaries rather than raw trajectories (removing self-evaluator summaries: 26.15 -> 18.46) (2410.08164#s2)

## When it fails
- OOD gains small (OSWorld 26.40 -> 26.73); retrieval drift under UI shifts (2510.09038#s1)
- Self-evaluator correctness unmeasured; held-out environment gains not isolated (2410.08164#s2)
- Reflector labels disagree with humans ~25% (2311.08649#s2)

## Counterexamples
- none found in the readings
