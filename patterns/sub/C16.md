# C16 — Let the agent nominate task-relevant content to retain for later steps
_parent: **Structure the Prompted Agent Loop: Context, Hierarchy and Post-Action Reflection** ([`agent_loop_context_control`](../main/agent_loop_context_control.md)) · status: candidate_pattern · source card: `K16-salient-content-retention.md` (frozen domain `cua-agents-core/v1`, where it is K16) · domain: cua-agents-core_

## Operation

- while acting, prompt the agent to list pivotal element ids or 'focus content' on the current screen; keep only those (plus tree neighbours) when replaying history or carry them in a memory unit.
- Status: candidate_pattern (2 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Pivotal-node history replay raised WebArena SR 37.1% -> 38.2% and cut steps 12.0 -> 8.6. [2410.13825#s4]
- A focus-content memory unit matters for cross-app information transfer (removal: SR 88.6 -> 77.3 basic). [2406.01014#s2]

## When it fails

- Hurts tasks with dense single-page content or multi-page navigation (Shopping, Reddit SR drop). [2410.13825#s4]
- Requires the agent to foresee what will be needed; memory stores untrusted screen text without filtering; multi-app evaluation tiny (8 instructions). [2406.01014#s2]

## Counterexamples

- None recorded.
