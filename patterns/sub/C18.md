# C18 — Verify each action's outcome from before/after observations and feed the verdict back
_parent: **Structure the Prompted Agent Loop: Context, Hierarchy and Post-Action Reflection** ([`agent_loop_context_control`](../main/agent_loop_context_control.md)) · status: candidate_pattern · source card: `K18-post-action-reflection.md` (frozen domain `cua-agents-core/v1`, where it is K18) · domain: cua-agents-core_

## Operation

- after each action, have a reflector (same or separate model) compare pre/post screenshots or execution outputs, classify the step (as expected / wrong page / no change), and trigger retry, revert, replanning or escalation; optionally a supervisor re-verifies executor claims.
- Status: candidate_pattern (7 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Works when errors show as screen non-change or a recognisably wrong page and are reversible. [2401.16158#s3, 2406.01014#s3, 2502.14282#s3]
- Removing PC-Agent's reflection agent drops subtask SR 76.0 -> 48.1 and instruction SR 56 -> 12. [2502.14282#s3]
- Guidelines + post-action summary of success/failure lift M3A from 19.8% to 30.6% on AndroidWorld. [2405.14573#s2]
- Escalating repeated failures to the manager lets it decompose the subgoal (qualitative). [2501.11733#s2]
- Text execution feedback (stdout, errors, file state) can drive critic-refine loops for code actions. [2402.07456#s2]

## When it fails

- Plausible-looking wrong pages and irreversible actions (sending messages) defeat screenshot-diff reflection; reflection accuracy as low as 78.8%. [2406.01014#s3, 2401.16158#s3, 2501.11733#s2]
- Small gains on easy suites (M3A-Simple matches the full agent on MobileMiniWoB++); mistyping not recovered. [2405.14573#s2]
- Executor self-checks hallucinate, and the supervising orchestrator also hallucinates unseen content. [2508.03923#s3]
- No ablation of critic/refiner; LLM completion judgement lacks ground truth. [2402.07456#s2]

## Counterexamples

- When the reflexion evaluator consumes attacked observations, ASR rises above the base agent (36% vs 31%). [2406.12814#s5]
- Claude computer use failures are mostly critic errors (assumes completion). [2411.10323#s3]
- Without reflection, a single early structure-following step makes multi-step episodes fail at 0.97-1.00. [2607.04334#s5]
