# K31 — Evaluate GUI world models in closed loop rather than teacher-forced one-step
_parent: **Make Online Evaluation Discriminating** ([`online_evaluation_methodology`](../main/online_evaluation_methodology.md)) · status: case · source card: `K31-closed-loop-world-model-evaluation.md` (frozen domain `cua-agents/v1`)_

## Operation
roll the world model out autoregressively along reference action sequences and with a frozen probing agent, scoring consistency and milestone progress

- Status: case

## When it works
- Reference trajectories filtered for plausibility and state dependence (2609.00048#s3)

## When it fails
- Best reference-action progress 16.7; fine-grained element scores < 20 while SigLIP is 61-77 (2609.00048#s1)
- Single probing agent; same model family as judge; VLM filter unvalidated (2609.00048#s2, 2609.00048#s3)

- none found in the readings
