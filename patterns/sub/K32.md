# K32 — Route exploration intents between cheap traversal and an LLM GUI agent, asynchronously
_parent: **Synthesise Tasks from Exploration and History** ([`exploration_driven_task_synthesis`](../main/exploration_driven_task_synthesis.md)) · status: case · source card: `K32-intent-routing-traversal-vs-agent.md` (frozen domain `cua-agents/v1`)_

## Operation
generate intents asynchronously from memory while a DFS explorer runs; route single-step intents to value-guided traversal and multi-step intents to an LLM agent

- Status: case

## When it works
- Intents generated from stored history, not the live screen (2609.10031#s2)

## When it fails
- Fulfilment rates from a single-app case study; agent errors dominate multi-step failures (2609.10031#s3)
