# K01 — Simulate each candidate action with a world model, score the imagined outcome, execute the best
_parent: **Select Actions by Simulated or Verified Lookahead** ([`simulated_lookahead_selection`](../main/simulated_lookahead_selection.md)) · status: candidate_pattern · source card: `K01-simulate-then-select.md` (frozen domain `cua-agents/v1`)_

## Operation
sample k candidate actions from a policy, predict each candidate's next state with a learned or prompted world model (one step), score the simulated outcome with an LLM/VLM value model, and commit only the argmax action in the real environment

- Transfer: Model-based planning analogue of MPC with a one-step model; transfers to any GUI platform where a next-state predictor exists, but only if candidate generation is decent and the scorer is not fooled by optimistic (sycophantic) simulations.

- Status: candidate_pattern

## When it works
- Environment cannot be reset or backtracked (live websites), so real tree search is unavailable; simulation substitutes for real lookahead at ~4-5x lower cost/latency than tree search (2411.06559#s1, 2410.13232#s2)
- Horizon kept to one step; H=1 is reported most effective (2411.06559#s1, 2602.09856#s2, 2602.14721#s3)
- The world model is trained/specialised (abstracted next-state description or code-rendered screen); a naive untrained simulator gives much smaller gains (+1.2 vs +9.5 SR on AndroidWorld; prompted 17.5% vs trained 22.0%) (2602.09856#s2, 2410.13232#s2)
- The value input includes the simulated next state; removing it lowers SR 22.0 -> 18.0 (2410.13232#s2)
- The policy's candidate set already contains a correct action (2602.09856#s2)

## When it fails
- Multi-step simulated rollouts hallucinate actions unavailable in predicted states and compound error; horizons 2-3 lose effectiveness (2411.06559#s1, 2410.13232#s2)
- Absolute success remains below real-execution tree search where reset is possible (16.6 vs 19.2 WebArena; 23.6 vs 26.2 VWA) (2410.13232#s2, 2411.06559#s1)
- On short MiniWob tasks gains are small (+0.2 to +3.2) and MCTS/hybrid add little; authors conclude world models are worth more for data synthesis than inference-time search (2602.14721#s3)
- Large result-list state spaces (Shopping) shrink gains; element IDs change on reload causing search/execution mismatch (2410.13232#s2)
- Offline SR gains from simulation are ~1.2-1.3 points; hallucinated safety cues could mislead an agent (2602.09856#s2)

## Counterexamples
- WebWorld reports bounded inference-time gains even with a strong world model, the opposite emphasis to WebDreamer/WMA (2602.14721#s3)
