# C32 — Attribute attack success to components via an agent graph
_parent: **Hijack Agents Through the Environment and Measure Attempt vs Completion** ([`environmental_injection_attacks`](../main/environmental_injection_attacks.md)) · status: case · source card: `K32-agent-graph-attack-attribution.md` (frozen domain `cua-agents-core/v1`, where it is K32) · domain: cua-agents-core_

## Operation

- model the compound agent as a graph and weight each edge by the bound on ASR if its value is followed, then compare component in/out weights under attack, including added reflexion / tree-search components.
- Status: case (1 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Localises where adversarial content is filtered (92% attacked captions vs 31% end-to-end ASR). [2406.12814#s2]
- Clean evaluators slightly reduce ASR (31% -> 25-26%). [2406.12814#s5]

## When it fails

- When added components consume attacked inputs, ASR rises above the base agent (36-38%). [2406.12814#s5]
- Edge weights are judged rather than executed; only shallow components tested. [2406.12814#s2, 2406.12814#s5]
