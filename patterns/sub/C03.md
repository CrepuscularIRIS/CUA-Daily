# C03 — Generate the next action in text, then ground it by multiple-choice over ranked DOM / a11y candidates
_parent: **Expose the Screen as Indexed Elements and Pruned Structure** ([`structured_screen_observation`](../main/structured_screen_observation.md)) · status: candidate_pattern · source card: `K03-rank-then-choose-grounding.md` (frozen domain `cua-agents-core/v1`, where it is K03) · domain: cua-agents-core_

## Operation

- prune the page to top-k candidate elements (fine-tuned cross-encoder or a11y filtering), have the model state the intended action (from screenshot or HTML), then pick the matching candidate from a textual multiple-choice list with operation and value.
- Status: candidate_pattern (3 full-text paper(s)).
- Transfer notes: Needs a DOM/a11y tree aligned with the screenshot and a ranker trained on in-domain pages.

## When it works

- A high-recall ranker (Recall@50 ~85-89%) makes LM action prediction fit in context; MCQ over 5+None groups beats direct element generation (Flan-T5 B step SR 41.0 vs 17.5). [2306.06070#s1, 2306.06070#s2]
- Screenshot-based generation plus HTML textual-choice grounding lets GPT-4V beat text-only GPT-4 ICL on Multimodal Mind2Web (40.2 vs 32.3 cross-task step SR). [2401.01614#s1]

## When it fails

- Targets outside the ranked pool (11-15% at top-50) cap accuracy; no visual signal in the ranker. [2306.06070#s1, 2401.01614#s1]
- Whole-task SR stays <= 7.1% offline because step errors compound; >10-point seen/unseen website gap. [2306.06070#s2]
- Identical or similar candidate HTML text cannot be told apart (picks first 'Schedule' button); gap to oracle grows with task length. [2401.01614#s1]
- Matching a generated element description to the DOM by visible text and type fails on text-less elements (step SR 16.1 vs 39.1). [2401.01614#s3]
- Ported to Android, the scheme struggles with long-press/swipe and loops because it caches actions but not outcomes (AndroidWorld 15.5% vs 30.6% M3A). [2405.14573#s3]

## Counterexamples

- Hidden aria-label / zero-opacity injections reach exactly the HTML grounding stage of this pipeline (EIA, AdvAgent on SeeAct). [2409.11295#s1, 2410.17401#s1]
