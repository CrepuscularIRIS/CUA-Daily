# K03 — Learn a text-space web transition model from real interaction logs
_parent: **Learn GUI Dynamics and Train in Them** ([`learn_and_train_in_gui_world_model`](../main/learn_and_train_in_gui_world_model.md)) · status: candidate_pattern · source card: `K03-text-transition-world-model.md` (frozen domain `cua-agents/v1`)_

## Operation
train an LLM on real (o_t, a_t, o_t+1) web transitions to predict the next state in text (an abstracted natural-language change description, or the full next accessibility tree/HTML), optionally with interaction history and a CoT explanation stage

- Transfer: Analogue of learned dynamics models in MBRL restricted to symbolic page state; fidelity depends on how much of the next state is determined by visible state vs hidden server data.

- Status: candidate_pattern

## When it works
- Training target is an abstraction of the transition (Hungarian-matched element diff rewritten in NL) rather than the raw next tree; raw-tree targets drop downstream SR 22.0 -> 14.5 (2410.13232#s1)
- Text/accessibility-tree observation space and in-distribution sites; local (non-full-page) transitions are easy (97% match) (2601.22149#s1, 2602.14721#s1)
- Large-scale real trajectories plus a small CoT stage; eval loss follows a compute power law (2602.14721#s1)

## When it fails
- Counterfactual imagination (42% of sampled errors: invented products), low competence with web functions, overly generic predictions (2410.13232#s1)
- Full-page transitions are much harder (~12% completely wrong) and errors compound in multi-step imagination (2601.22149#s1)
- Sycophancy: overly optimistic outcomes that cater to the agent's action; poor detailed content generation (2602.14721#s1)
- No access to server-side state or pixels by construction; intrinsic metrics are LLM-judged, not executed (2601.22149#s1, 2602.14721#s1)

## Counterexamples
- none found in the readings
