# C30 — Plant natural-language instructions in attacker-writable content of legitimate apps
_parent: **Hijack Agents Through the Environment and Measure Attempt vs Completion** ([`environmental_injection_attacks`](../main/environmental_injection_attacks.md)) · status: candidate_pattern · source card: `K30-content-instruction-injection.md` (frozen domain `cua-agents-core/v1`, where it is K30) · domain: cua-agents-core_

## Operation

- place a hand-written instruction (sometimes faintly visible, or persisted in a URL fragment) in user-editable surfaces such as posts, comments, chat, emails, notifications, documents or listings, and start the agent where it will read it.
- Status: candidate_pattern (5 full-text paper(s)).
- Transfer notes: Software-injection analogy holds for untrusted data entering the instruction channel; breaks because the context has no syntactic data/instruction boundary.

## When it works

- Low-effort injections hijack frontier agents even under weak threat models (WASP ASR-intermediate 0.167-0.857; RedTeamCUA ASR 7.57-66.19%; OS-Harm 2-20%). [2504.18575#s1, 2505.21936#s1, 2506.14866#s1]
- Text injection in a seller's listing reaches 40% ASR on GPT-4o; ASR correlates with benign capability. [2406.12814#s1]
- URL-fragment payloads persist in memoryless scaffolds and raise ASR. [2504.18575#s2]
- Notifications and emails are the most effective vectors (50% for o4-mini). [2506.14866#s1]
- Raising opacity to make text visible to the screenshot stage reaches 16% full-request ASR on GPT-4V. [2409.11295#s2]

## When it fails

- Episodes start at the trigger page, overstating exposure; tasks filtered to ones the agent solves. [2406.12814#s1, 2505.21936#s1]
- Screenshot-only agents may not see URL fragments; Office documents and code comments rarely succeed. [2504.18575#s2, 2506.14866#s1]
- Weak open models are not hijacked by faint text; small, non-adaptive injection sets. [2409.11295#s2, 2504.18575#s1]

## Counterexamples

- None recorded.
