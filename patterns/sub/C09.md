# C09 — Skip redundant visual tokens in uniform UI regions
_parent: **Localise Small Targets with Resolution, Zoom, Verification and Pointer Heads** ([`high_resolution_target_localisation`](../main/high_resolution_target_localisation.md)) · status: case · source card: `K09-ui-token-selection.md` (frozen domain `cua-agents-core/v1`, where it is K09) · domain: cua-agents-core_

## Operation

- build a graph of same-colour neighbouring patches (union-find) and randomly skip a fixed ratio of tokens inside multi-patch components in alternating layers, keeping position embeddings.
- Status: case (1 full-text paper(s)).
- Transfer notes: Cross-domain analogue of ViT token pruning; holds only when decisive small text/icons are not in uniform components.

## When it works

- Removes 33% of visual tokens with 1.4-1.5x training speedup at near-equal ScreenSpot (70.4 vs 70.8) on screenshots with large uniform regions; beats token merging (42.3) and random selection (65.3). [2411.17465#s1]

## When it fails

- Applying selection at test time drops ScreenSpot to 64.9; text-rich screens have few redundant components; navigation not ablated. [2411.17465#s1]

## Counterexamples

- None recorded.
