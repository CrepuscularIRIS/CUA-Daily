# C36 — Separate trusted planning from untrusted observations with information-flow labels and quarantined LLMs
_parent: **Defend Agents Against Untrusted Observations: Prompting, Gating and Isolation** ([`injection_defense_isolation`](../main/injection_defense_isolation.md)) · status: candidate_pattern · source card: `K36-information-flow-dual-llm.md` (frozen domain `cua-agents-core/v1`, where it is K36) · domain: cua-agents-core_

## Operation

- label data by confidentiality/integrity, hide untrusted results behind variables, query them only through a quarantined LLM with constrained typed outputs, and check tool/GUI calls against flow policies; for CUAs, compile a branching plan before any observation.
- Status: candidate_pattern (2 full-text paper(s)).
- Transfer notes: Privilege separation transfers to CUAs only if perception outputs can be typed narrowly and plans anticipate UI states.

## When it works

- Policy checks block almost all policy-relevant injections in AgentDojo (163 -> 9 / 0). [2505.23643#s1, 2505.23643#s3]
- Selective hiding + quarantined typed queries recover utility, best with reasoning models. [2505.23643#s2, 2505.23643#s3]
- Single-shot branching plans with quarantined perception give control-flow integrity at usable OSWorld utility (58.3% pass@3 on 60 tasks). [2601.09923#s1]
- Iterative variant exposing only booleans matches utility at much higher cost. [2601.09923#s2]

## When it fails

- Coarse tainting cuts task completion by up to 40%; data-dependent tasks remain largely unsolved; 2-3x tokens. [2505.23643#s1, 2505.23643#s2, 2505.23643#s3]
- Underspecified tasks with unknown start states explode branches; plans cannot adapt to observed failures. [2601.09923#s1]
- Boolean leakage accumulates; termination only via caps. [2601.09923#s2]

## Counterexamples

- Branch steering with fake cookie popups or optimised banner pixels routes the fixed plan down attacker-preferred valid branches. [2601.09923#s3]
- Text-to-text injections affecting final responses are outside tool-call policies. [2505.23643#s1]
