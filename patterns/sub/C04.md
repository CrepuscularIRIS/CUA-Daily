# C04 — Continual-pretrain a VLM to emit target coordinates as text from automatically harvested element-box pairs
_parent: **Decouple Planning from Grounding and Redesign the Action Interface** ([`planner_grounder_interface`](../main/planner_grounder_interface.md)) · status: candidate_pattern · source card: `K04-harvested-coordinate-grounding.md` (frozen domain `cua-agents-core/v1`, where it is K04) · domain: cua-agents-core_

## Operation

- harvest (screenshot, referring text, box/point) triplets from DOM, accessibility trees or a UI detector without human labels, format them as text-to-point/box and box-to-text tasks in the backbone's coordinate tokens, and continual-pretrain the VLM so it grounds from pixels alone at inference.
- Status: candidate_pattern (5 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Grounding pretraining lifts pixel-only click accuracy far above generalist VLMs (SeeClick ScreenSpot 53.4 vs Qwen-VL 5.2; OS-Atlas-7B 82.47 vs Qwen2-VL 42.89), rising with data scale. [2401.10935#s1, 2410.23218#s1]
- Web REG/REC data from rendered DOM gives the biggest Mind2Web gain for CogAgent (41.4 -> 54.2 adding GUI and grounding data). [2312.08914#s2]
- Detector-derived elementary referring/grounding tasks raise advanced UI tasks (64.6 -> 73.4 iPhone). [2404.05719#s2]
- Curation matters: dropping static text, augmenting desktop queries and balanced per-source sampling (71.2 -> 74.9) beat larger raw data (22K screenshots 69.0 vs SeeClick 270K 65.5). [2411.17465#s4]

## When it fails

- Icons/widgets and desktop remain weakest (SeeClick desktop icon 30.0; OS-Atlas desktop icon 62.86); errors fall near the target, i.e. fine localization is the limit. [2401.10935#s1, 2410.23218#s1, 2411.17465#s4]
- Supervision inherits the source's coverage: instructions limited to visible text/title attributes; elements absent from HTML/a11y trees (canvas, games) or missed by the detector are never labelled. [2401.10935#s2, 2410.23218#s1, 2404.05719#s2]
- Model confuses composite widgets and predicts plausible words instead of literal text; GPT-4-scored evaluations favour verbosity. [2404.05719#s2, 2404.05719#s3]

## Counterexamples

- On professional high-resolution screens the best such model reaches only 18.9% (OS-Atlas-7B) on ScreenSpot-Pro. [2504.07981#s1]
- Same-data coordinate-generation baselines (Aguvis-7B) score 15.6 on ScreenSpot-Pro vs 40.7 for an attention action head. [2506.03143#s1]
