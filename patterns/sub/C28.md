# C28 — Inject instructions into non-rendered HTML channels read by the grounding stage
_parent: **Hijack Agents Through the Environment and Measure Attempt vs Completion** ([`environmental_injection_attacks`](../main/environmental_injection_attacks.md)) · status: candidate_pattern · source card: `K28-hidden-channel-injection.md` (frozen domain `cua-agents-core/v1`, where it is K28) · domain: cua-agents-core_

## Operation

- insert zero-opacity elements or adversarial strings in non-rendered attributes (aria-label, id) next to the expected target, optionally optimised by a black-box-trained prompter, so that HTML-reading grounding follows them while the screenshot is unchanged.
- Status: candidate_pattern (2 full-text paper(s)).
- Transfer notes: Analogue of injection through invisible data channels; requires the agent to read raw HTML attributes.

## When it works

- Targets SeeAct-style agents whose grounding reads HTML choices; ASR up to 0.70 (EIA) and 97.5-99.8% with SFT+DPO-trained prompters. [2409.11295#s1, 2410.17401#s1, 2410.17401#s2]
- Placement adjacent to (after) the target element matters most. [2409.11295#s1, 2410.17401#s1]
- Successful injections can be retargeted by string substitution (98.5% ASR). [2410.17401#s3]

## When it fails

- Cannot affect screenshot-driven action generation (full-request ASR 0); distant positions fall to 0.01-0.18. [2409.11295#s1]
- Would not reach pure-screenshot agents; prompts do not transfer across backends (18%); only SeeAct offline tested. [2410.17401#s1, 2410.17401#s2]
- Retargeting tested only on pre-filtered successes with unchanged element/operation. [2410.17401#s3]

## Counterexamples

- None recorded.
