# C37 — Compress continuous action chunks with DCT + BPE into autoregressive tokens
_parent: **Decouple Planning from Grounding and Redesign the Action Interface** ([`planner_grounder_interface`](../main/planner_grounder_interface.md)) · status: case · source card: `K37-dct-bpe-action-tokenization.md` (frozen domain `cua-agents-core/v1`, where it is K37) · domain: cua-agents-core_

## Operation

- quantile-normalise action chunks, DCT per dimension, quantise, flatten low-frequency-first and BPE-compress into VLM tokens; optionally a universal tokenizer and replacing a flow-matching action expert with autoregressive decoding.
- Status: case (1 full-text paper(s)).
- Transfer notes: Cross-domain (robotics VLA). Transfers to GUI policies only for continuous pointer trajectories (drags, cursor paths); typical GUI actions are discrete and symbolic (typing, element ids), where DCT smoothness assumptions do not hold.

## When it works

- Smooth high-frequency actions compress 1.75x-13.2x vs binning and make dexterous tasks trainable. [2501.09747#s1]
- A universal tokenizer compresses held-out embodiments by >= ~2x. [2501.09747#s2]
- Autoregressive pi0-FAST matches diffusion pi0 on small data with better language following. [2501.09747#s3]

## When it fails

- Small gains at low control frequency; less efficient than VQ at low fidelity. [2501.09747#s1]
- Held-out evaluation is compression only. [2501.09747#s2]
- Inference ~750 ms per chunk vs ~100 ms for diffusion. [2501.09747#s3]

## Counterexamples

- None recorded.
