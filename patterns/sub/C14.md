# C14 — Simplify the prompted agent's action space toward what the LLM handles well
_parent: **Decouple Planning from Grounding and Redesign the Action Interface** ([`planner_grounder_interface`](../main/planner_grounder_interface.md)) · status: case · source card: `K14-action-space-simplification.md` (frozen domain `cua-agents-core/v1`, where it is K14) · domain: cua-agents-core_

## Operation

- remove rarely useful or embodiment-heavy actions (noop, tabs, hover, press, goto, scroll), collapse dropdown selection into a click, add workflow actions (note, stop, go_home), and replace scrolling with full-page observation.
- Status: case (1 full-text paper(s)).
- Transfer notes: n/a

## When it works

- WebArena SR 16.5% -> 25.9% from action pruning, then 25.9% -> 31.7% from removing scroll with full-page observations. [2410.13825#s1, 2410.13825#s2]

## When it fails

- Steps per task roughly double; removed hover/press/tabs would be needed on other sites (untested). [2410.13825#s1]
- Full-page observations double tokens and cannot reach scroll-triggered content (infinite scroll). [2410.13825#s2]

## Counterexamples

- None recorded.
