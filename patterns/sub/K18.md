# K18 — Verify outcomes with a tool-using agent that probes the preserved terminal environment
_parent: **Reward with Learned Outcome and Process Judges** ([`learned_outcome_and_process_judges`](../main/learned_outcome_and_process_judges.md)) · status: case · source card: `K18-agentic-environment-probing-verifier.md` (frozen domain `cua-agents/v1`)_

## Operation
progressively escalate from final screenshot to retrieved intermediate screenshots to read-only shell/Python and GUI probing of the live terminal state, early-stopping when evidence suffices

- Transfer: Bridges K16 (passive judges) and K12 (privileged checkers): it acquires privileged state on demand without per-task scripts.

- Status: case

## When it works
- Terminal environment kept alive; 'easy to verify, hard to solve' (verifier SR 83.1% vs actor 55.9%) (2602.00575#s1)

## When it fails
- Probing can alter state (sandboxing needed); outcome-only; mobile lacks shell tools (2602.00575#s1)
