# K17 — Emit a reward only when diverse judges unanimously agree, else abstain
_parent: **Reward with Learned Outcome and Process Judges** ([`learned_outcome_and_process_judges`](../main/learned_outcome_and_process_judges.md)) · status: case · source card: `K17-abstaining-judge-ensemble.md` (frozen domain `cua-agents/v1`)_

## Operation
query several VLM judges with different models/prompts (chosen for opposite precision/NPV biases) and label only unanimous cases

- Status: case

## When it works
- Ensemble members' errors not fully correlated; reliability valued over coverage (2510.18596#s1)

## When it fails
- Recall/specificity drop sharply; abstention may bias kept samples; not validated in an RL loop (2510.18596#s1)

## Counterexamples
- none found in the readings
