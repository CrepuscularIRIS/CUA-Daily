# K24 — Probe agent/grounder robustness with controlled environment perturbations
_parent: **Make Online Evaluation Discriminating** ([`online_evaluation_methodology`](../main/online_evaluation_methodology.md)) · status: candidate_pattern · source card: `K24-perturbation-robustness-probing.md` (frozen domain `cua-agents/v1`)_

## Operation
re-render or reconfigure the environment under one controlled change at a time (style, zoom, text size, window position/clutter, observation encoding, relational instructions) and measure matched-pair accuracy changes

- Transfer: Robotics domain randomisation as training augmentation did not transfer here; as an evaluation probe it works.

- Status: candidate_pattern

## When it works
- DOM/VM control to inject perturbations and recompute targets (2604.14262#s1, 2404.07972#s2)

## When it fails
- Relational instructions collapse accuracy (UI-TARS-1.5 91.0 -> 35.0); window perturbations drop 50.79% -> ~15% (2604.14262#s1, 2404.07972#s2)
- Domain-randomised LoRA SFT does not fix the brittleness and more data degrades (2604.14262#s2)
- Small web-only sets; one model lineage (2604.14262#s1)

## Counterexamples
- Domain randomisation (successful in robotics sim-to-real) did not improve GUI grounding under rank-8 LoRA SFT (2604.14262#s2)
