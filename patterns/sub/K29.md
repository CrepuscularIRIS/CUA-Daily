# K29 — Redesign the action interface between model and computer
_parent: **Decouple Planning from Grounding and Redesign the Action Interface** ([`planner_grounder_interface`](../main/planner_grounder_interface.md)) · status: candidate_pattern · source card: `K29-agent-computer-interface-redesign.md` (frozen domain `cua-agents/v1`)_

## Operation
change the action abstraction the agent emits — restrict actions to tagged accessibility/OCR elements with one bounded primitive per step, or add a library of programmatic tools alongside grounded GUI primitives — and train/prompt the agent to use it

- Status: candidate_pattern

## When it works
- Parseable accessibility tree plus OCR (element-tag ACI) (2410.08164#s3)
- Application-specific tool library exists and fits in context (881 tools, 32K) (2510.17790#s1)

## When it fails
- Element-ID grounding cannot target sub-element positions (grounding errors in 53% of failures) (2410.08164#s3)
- Tool gains modest at 7B (+1.9); small models rarely call tools; harmful tool calls before RL (2510.17790#s1)

## Counterexamples
- none found in the readings
