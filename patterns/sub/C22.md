# C22 — Executable benchmark with resettable environments and privileged final-state checkers
_parent: **Ground Reward in Executable Checkers** ([`verifiable_execution_reward`](../main/verifiable_execution_reward.md)) · status: candidate_pattern · source card: `K22-executable-state-checker-benchmark.md` (frozen domain `cua-agents-core/v1`, where it is K22) · domain: cua-agents-core_

## Operation

- package apps/sites/OS images as resettable containers or emulators with seeded task initialisation, and score each task by programmatic checks of privileged state (databases, files, settings, page locators) or answer matching, optionally across seeds.
- Status: candidate_pattern (4 full-text paper(s)).
- Transfer notes: n/a

## When it works

- Self-hosted Docker sites with container reset make comparison reproducible; state-locator checkers admit alternative paths. [2307.13854#s1, 2307.13854#s3]
- Seeded parameterised tasks with reusable state predicates give durable rewards on Android without app modification. [2405.14573#s1]
- Varying seeds exposes variance hidden by fixed seeds (SR 27.6-33.2% across seeds). [2405.14573#s4]
- Parallel containerised Windows VMs finish a full run in ~20 min. [2409.08264#s1]
- Visual-task checkers combine locators with VQA / image similarity primitives. [2401.13649#s3]

## When it fails

- Checker false-positive/negative rates largely unreported; must_include and GPT-4 fuzzy match can accept partially wrong content. [2307.13854#s3, 2401.13649#s3, 2405.14573#s1, 2409.08264#s1]
- Restricted to apps without login and with inspectable local storage; clones with sampled data; final-state reward only. [2405.14573#s1, 2307.13854#s1, 2409.08264#s1]
- Robustness trials limited to 5 tasks and one agent configuration. [2405.14573#s4]

## Counterexamples

- None recorded.
